Вход для учителя

Здесь вы добавляете разработки и отзывы — они публикуются на сайте автоматически. Для входа нужен ключ доступа (GitHub-токен). Он сохраняется только в этом браузере и никуда больше не передаётся.

Как получить ключ доступа (один раз, ~2 минуты)
  1. Войдите на github.com в аккаунт, у которого есть доступ к репозиторию сайта.
  2. Откройте Settings → Developer settings → Fine-grained personal access tokens → Generate new token.
  3. Repository access: Only select repositories → выберите репозиторий сайта.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Нажмите Generate и скопируйте ключ (начинается с github_pat_).
