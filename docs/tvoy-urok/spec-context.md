# Контекст: «Твой урок» — выжимка из ТЗ v2.0 и хендоффа (для синтеза)

## Что за продукт
Веб-сервис ИИ-генерации учебных материалов для учителей РФ (клон-конкурент obuchai.com).
Учитель за 30–90 сек генерирует: рабочие листы (70 типов заданий), конспекты, планы уроков,
ПРЕЗЕНТАЦИИ, картинки. Плюс чат-ассистент и проверка работ по фото. ФГОС-соответствие — ядро.

## Презентации в ТЗ (раздел 4.5)
- Генерация слайдов, экспорт PPTX и PDF, онлайн-редактор.
- Экран «Редактор презентации» `/presentation-edit/:id` — отрисован в прототипе.
- API: `POST /api/generate {type:"presentation", subject, grade, topic, wishes?}` → job_id → поллинг.
- PPTX-экспорт (python-pptx) — в бэкенде ещё НЕ реализован (этап 4 дорожной карты).
- Генерация по своим документам (ТЗ 4.9): загрузка PDF/DOCX/PPTX → парсинг → материалы на основе источника.

## Оркестратор генерации (ТЗ раздел 5)
1. Препроцессинг: файл→текст, класс→возрастной профиль (лексика/сложность/длина).
2. Выбор сценария под тип (шаблон из реестра типов; каждый тип = JSON-схема + промпт + правила валидации).
3. Сборка 5-слойного промпта: [РОЛЬ учителя] + [возрастной профиль] + [предмет/тема] + [требования ФГОС
   из детерминированной выборки по {предмет, класс}] + [structured output JSON-схема].
4. LLM-роутер: сложное → Claude Sonnet/GPT (прокси); простое → Haiku/DeepSeek/GigaChat (РФ нативно).
5. Валидация (дифференциатор): structured output strict + temp 0–0.1; Chain-of-Verification;
   LLM-судья по 5 критериям (уровень класса, педкорректность, факт. точность, уровень Блума,
   применимость), verdict одобрено/правки/отклонено; до 3 повторных попыток.
6. Рендер: PDF — WeasyPrint+Jinja2+KaTeX (7 CSS-стилей); PPTX — python-pptx + мастер-шаблон;
   картинки — Kandinsky / YandexART (легально РФ, дешевле DALL·E).
7. Сохранение → редактор BlockNote → экспорт/публикация.

## Ограничения/решения из ТЗ
- Хостинг Yandex Cloud (152-ФЗ), ПД учеников не уходят во внешние LLM.
- Шрифты кириллические free: PT Sans/Serif, Roboto, Noto, Inter — в Docker-образе.
- wkhtmltopdf запрещён; WeasyPrint ~4–5 PDF/сек/воркер.
- Картинки — главный переменный риск маржи → лимиты + дешёвые модели.
- Валидация качества — главный дифференциатор против оригинала (у того жалобы на орфо-ошибки).
