## Известные ограничения

- Notification API и service worker на телефоне по http локальной сети не
  работают (ограничение браузеров) — сигнал дублируется звуком, вибрацией
  и бейджем; уведомления полноценны на localhost (Д-20).
- Оценка токенов приблизительная (Д-10), помечена «≈».
- «Спросить Клода» требует Claude Code CLI и расходует лимиты — выключено
  по умолчанию.
