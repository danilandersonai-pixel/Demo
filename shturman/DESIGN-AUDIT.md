# DESIGN-AUDIT.md — что не так с внешним видом до редизайна

> Этап 0 задания 3. Панель поднята на живом проекте (`/home/user/Demo`,
> уровень A, 200+ событий в ленте) и пройдена целиком на двух ширинах:
> **1500×980** (компьютер) и **360×740** (телефон, эмуляция касаний).
> Ниже — что видно на каждом экране, список визуального мусора с числами и
> три места, где новичок теряется. Всё это стало чек-листом редизайна.

**Как повторить замеры:**

```bash
cd shturman
node server.js --project .. --port 4517 --quiet --no-open &
node tests/manual/design-shots.js     # снимки всех экранов на 1500 и 360
node tests/manual/design-probe.js     # контраст, кегли, зоны касания, инвентарь CSS
```

Снимки складываются во временную папку (`SHTURMAN_SHOTS` или системный temp) —
в репозиторий не кладём, чтобы не таскать мегабайты PNG; скрипт воспроизводит
их за полторы минуты.

## 1. Экраны: что видно

### 1.1 Компьютер, 1500px — главный вид

Три колонки: лента (широкая, слева), карта проекта и git (узкая, посередине),
пульс сессии (справа). Над ними липкая шапка 62px.

**Шапка слева направо:** эмодзи-компас, «Штурман», вертикальная линия, имя
проекта + путь моноширинным 11px, дальше пустота до правого края, два серых
чипа-таблетки («● Клод работает», «● уровень A · видно всё») и семь
одинаковых квадратных кнопок с эмодзи: 🔔 📱 📚 📄 🌗 🎓 ⚙️.

**Лента.** Заголовок «Что происходит», переключатель «Просто / Подробно»,
кнопка «Пауза». Ниже поле поиска на всю ширину. Ниже девять фильтров-таблеток
(«Всё», «📝 правки», «📖 чтение», «🔧 команды», «🔍 поиск», «⛔ ошибки»,
«💬 диалог», «🌿 git», «🤝 помощник») — при ширине колонки 420px они
переносятся в **три ряда** и занимают 150px. Только после этого начинаются
события: строка-эмодзи, заголовок, время справа, серая поясняющая строка под
ним, слева цветная полоска 3px (зелёная — правка, голубая — команда,
фиолетовая — реплика, красная — ошибка).

**Карта проекта.** Заголовок, кнопка «⟳», поле «Поиск по файлам…», дерево с
📁/📄 и размером справа, внизу серая строка-подпись «Свежие изменения
подсвечиваются и постепенно гаснут».

**Git.** Заголовок «Git» со значком «?», переключатель «Сейчас / История».
Внутри: подпись «ВЕТКА» капсом, имя ветки моноширинным в голубой плашке —
и **значок «?» переносится на следующую строку сам по себе**, повисая под
плашкой. Дальше объяснение ветки, серая строка про upstream, карточка
с большой цифрой несохранённых изменений.

**Пульс.** Четыре ячейки-плитки 2×2 с крупными числами (77 / 201 / 16 / 38 с)
и подписями КАПСОМ 11px, широкая ячейка с токенами, подраздел «КУДА СМОТРИТ
КЛОД» (граф/список), подраздел «ПРОШЛЫЕ СЕССИИ».

### 1.2 Компьютер — шторка «Подробности события»

Выезжает справа, 560px, поверх затемнения. Заголовок = эмодзи + первые ~50
символов заголовка события с многоточием. Внутри: строка-пояснение,
табличка фактов (Когда / Источник / Инструмент / Команда) на подложке,
секция «СЫРЫЕ ДАННЫЕ СОБЫТИЯ» капсом с JSON на 20 строк. Для команды с
длинным `cd … && git status …` табличка фактов и JSON дублируют друг друга
почти дословно.

### 1.3 Компьютер — словарь, настройки, подключение

- **Словарь:** поле поиска, «Терминов в словаре: 40.», плоский список
  «термин / объяснение», разделённый линиями. Все элементы одного веса.
- **Настройки:** восемь строк «заголовок + пояснение слева, управление справа».
  Управление разнокалиберное: две кнопки «Включено» (широкие, 100px),
  два сегментированных переключателя разной ширины, числовое поле 96px,
  кнопка «Открыть экран», и три строки вообще без управления — просто текст
  («Спроси Клода», «О наблюдении», «Горячие клавиши»). Читается как
  список настроек, в котором половина настроек не работает.
- **Подключение:** объяснение, блок с командой `shturman --share`,
  синяя кнопка «📱 Включить доступ с телефона».

### 1.4 Компьютер — сигнал «Клод ждёт»

Всплывает в правом нижнем углу: 430×90, жёлтая полоска слева, 🔔 28px,
заголовок, текст, кнопка «Понял». Шапка при этом слегка желтеет.

### 1.5 Телефон, 360px — лента

Сверху вниз: шапка 56px (компас, чип состояния, 🔔, ⋯) → ряд «Просто /
Подробно» + «Пауза» 56px → поле поиска 60px → лента фильтров 55px
(прокручивается вбок) → **и только на 230-м пикселе первое событие**.
Внизу вкладки 60px с эмодзи 📰 🗺 🌿 ❤️.

Карточка события на телефоне: эмодзи, заголовок 14.5px, пояснение 12.5px,
время 11px **под** пояснением (на компьютере оно справа сверху) — порядок
чтения меняется между форм-факторами.

### 1.6 Телефон — карта, git, пульс

У всех трёх вкладок шапка секции пустая: название спрятано (его дублирует
подпись вкладки), а полоса 48px осталась. На карте в ней живёт только «⟳»,
на git — переключатель, **на пульсе — ничего**: пустая полоса.

Git на телефоне: пустая полоса, «Сейчас / История», «ВЕТКА», плашка с
именем ветки во всю ширину, осиротевший «?» под ней, два абзаца серого
текста, карточка «0 · Чисто…» — и **380px пустоты** до вкладок.

Пульс на телефоне: плитки 2×2, строка токенов переносится в две строки и
съедает 90px, граф внимания 240px, в котором подписи файлов налезают друг
на друга (`offline.html` / `offline-screen…` / `sw.js` в одном углу).

### 1.7 Телефон — «⋯», шторка, сигнал, пустая лента

- **«⋯»** — список из шести строк, у каждой эмодзи + название + пояснение.
  Строки не выглядят нажимаемыми: ни стрелки, ни подсветки, ни разделения на
  зоны — только курсор меняется, а на телефоне курсора нет.
- **Шторка** снизу, 90vh, ручка-грип сверху, дальше как на компьютере.
- **Сигнал** растягивается на всю ширину минус 24px — здесь он заметен.
- **Пустая лента** (поиск, который ничего не нашёл): спутник-эмодзи 40px,
  «Пока тихо», и текст «Штурман подключился к сессии Клода и ждёт первых
  действий» — **при 200 событиях в ленте**. Ни кнопки, ни намёка, что дело
  в поиске.

### 2.2 Что при этом уже хорошо — и должно уцелеть

Чтобы редизайн не сломал того, что работает:

- Одна разметка на оба форм-фактора, раскладку целиком делает CSS.
- `[hidden] { display: none !important }` — правило, которое чинит оверлеи.
- Виртуализация ленты (распорки сверху и снизу) — на 1500 событий панель
  остаётся отзывчивой.
- Фокус видно (`:focus-visible` с обводкой 2px), в шторке работает ловушка
  фокуса и возврат фокуса.
- `prefers-reduced-motion` уважается общим сбросом в конце файла.
- Тёмная и светлая темы уже разведены переменными, а не дублированием правил.
- Тепловой след на карте и живая пульсация точки состояния — единственные
  постоянные анимации, обе фоновые.

## 3. Три места, где новичок теряется

Это главный вывод этапа 0. Не «некрасиво», а «непонятно, куда смотреть».

### Место 1. Главный вопрос — самым мелким шрифтом

Человек открывает Штурман, чтобы узнать одно: **Клод работает или ждёт
меня?** Ответ на этот вопрос сейчас:

- лежит в правом верхнем углу шапки, кеглем **12px** (самый мелкий текст
  на экране, контраст 3.57:1);
- оформлен ровно так же, как соседний чип «уровень A · видно всё» — та же
  таблетка, тот же размер, та же точка слева. Два серых овала подряд, и
  один из них — техническая диагностика, которая новичку не нужна вовсе;
- а в момент, когда состояние меняется на «ждёт», об этом сообщает
  **третий** элемент — карточка в противоположном, правом нижнем углу.

Одна мысль рассказана в трёх местах, ни одно из которых не выглядит главным.
С трёх метров не читается, на телефоне в темноте — тем более.
**Это и есть место для фирменного элемента.**

### Место 2. Пульт вместо содержимого

На телефоне до первого события — 230px управления (шапка, «Просто/Подробно»,
«Пауза», поиск, девять фильтров). Это **треть экрана**. На компьютере девять
фильтров переносятся в три ряда и отжимают ленту вниз на 150px.

Новичок пришёл смотреть, что делает Клод, а видит пульт. Хуже того, фильтры
подписаны теми же эмодзи, что стоят у событий: 📝 в чипе значит «показывать
только правки», 📝 в строке значит «правка произошла». Один символ, два
разных смысла, ничем не разделённые.

### Место 3. Пустой экран врёт и ничего не предлагает

Три разные ситуации показывают **один и тот же** текст «Пока тихо. Штурман
подключился и ждёт первых действий»:

1. событий действительно нет (честно);
2. включён фильтр, под который ничего не подходит (неправда);
3. в поиске набрано слово, которого нет (неправда — в ленте 200 событий).

Ни в одном случае нет кнопки, которая вернула бы человека назад. То же на
вкладке git при чистом дереве: зелёный «0», две строки текста и 380px
пустоты — ни «посмотреть историю», ни «что это значит».

Новичок в такой ситуации делает единственный доступный вывод: «сломалось» или
«я что-то сделал не так».

## 4. Чек-лист редизайна (что из этого следует)

1. **Фирменный элемент** — крупный, живой индикатор состояния Клода: одно
   место вместо трёх, читается с трёх метров, работает во всех состояниях.
2. **Палитра 4–6 цветов** вместо 37 хексов; цвет = состояние, не украшение.
3. **Одна шкала кеглей** (вместо 21 значения) и **одна шкала отступов**
   (вместо 54), обе — переменными в `tokens.css`.
4. **Один принцип разделения**: воздух и подложка, рамки — только там, где
   без них нельзя (поля ввода, дифф).
5. **Радиусы — три значения** вместо двенадцати.
6. **Свой набор значков** в одном стиле вместо эмодзи-зоопарка; фильтры и
   события перестают спорить символами.
7. **Никакого КАПСА с разрядкой** — вес и цвет вместо крика.
8. **Контраст ≥ 4.5:1 везде**, включая приглушённый текст; на телефоне
   минимум 15px и 44px под палец.
9. **Пустые экраны различают ситуации** и всегда дают следующий шаг.
10. **Иерархия на каждом экране**: главное — крупно и сверху, служебное —
    мелко и тихо; на телефоне пустые полосы шапок либо наполняются, либо
    исчезают.
11. **Все строки интерфейса — из общего словаря**, чтобы одно и то же
    называлось одинаково.
12. **Плотность на выбор**: «Просторно» и «Компактно».
