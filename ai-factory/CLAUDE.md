# CLAUDE.md — AI-Factory: Automation Sandbox

Браузерная игра-песочница (React 19 + Tailwind 4 + Framer Motion + Lucide,
TypeScript, Vite 8). Отдельный проект внутри репозитория: к свадебному сайту
в `yegor-diana-wedding/` отношения не имеет, у неё свои зависимости и сборка.

## Команды

```bash
npm install
npm run dev          # разработка, http://localhost:5173
npm test             # vitest: механики (engine.test.ts) + бот-симуляция баланса (balance.test.ts)
npm run typecheck    # tsc --noEmit
npm run build:play   # typecheck + vite build + копия dist/index.html → play.html
```

`play.html` — закоммиченная сборка одним файлом (vite-plugin-singlefile), её
открывают двойным кликом. После любых правок в `src/` пересобирайте её через
`npm run build:play` и коммитьте вместе с исходниками. `dist/` и
`node_modules/` в git не попадают.

## Архитектура

- `src/game/` — движок без React. Состояние `GameState` целиком сериализуемое
  (уходит в localStorage), генератор случайных чисел (mulberry32) хранится в
  самом состоянии, поэтому симуляция детерминирована.
  - `config.ts` — единственное место с балансом: здания, рецепты, исследования,
    рыночные события. `FEEDS`/`LINK_RES` задают бонус соседства и цвет лент.
  - `engine.ts` — `computeFlow()` считает потоки тика без мутаций (им же
    пользуется предпросмотр после действий игрока), `step()` применяет тик,
    действия (`build`, `upgrade`, `move`, `refactor`, `startResearch`, `sell`…)
    мутируют переданную копию и возвращают `ActionResult`.
  - Правило распределения: всё берётся из запасов на начало тика; дефицит
    делится пропорционально спросу. Данные делят кодеры и кластеры обучения,
    код — кластеры и лаборатория НИОКР, модели сначала забирает AGI, остаток —
    SaaS. Автопродажа сбывает только излишек выработки этого тика сверх
    резерва — старые запасы не трогает (иначе можно накрутить рекорд дохода).
  - `selectors.ts` — формулы и чтение состояния; `goals.ts` — контракты;
    `records.ts` — рекорды (хранятся отдельно от фабрики); `save.ts` —
    localStorage с try/catch и строгой проверкой загружаемых данных.
- `src/hooks/useGame.ts` — игровой цикл: авторитетное состояние живёт в ref,
  каждый тик — `structuredClone` + `step()`, затем `setState`. Побочные
  эффекты (тосты, рекорды, сохранение) выполняются вне апдейтеров React.
  Догонялка по реальному времени: пропущенные в фоновой вкладке тики
  досчитываются пачкой, больше 300 — с отчётом, как после офлайна (до 4 ч).
- `src/components/` — модули экрана, `src/ui/` — примитивы (Panel, Meter,
  Modal, Sparkline, AnimatedNumber) и иконки.

## Соглашения

- Весь текст интерфейса — на русском; числа форматируются через
  `src/game/format.ts` (ru-RU, «тыс/млн/млрд»).
- Цвета ресурсов — токены из `@theme` в `src/index.css`: данные — циан,
  код — фиолетовый, модели — розовый, вычисления — синий, энергия — жёлтый,
  кредиты — зелёный, техдолг — оранжевый, аварии — красный. Новые цвета вне
  палитры не вводить.
- Любая новая анимация должна выключаться при `prefers-reduced-motion`
  (`MotionConfig reducedMotion="user"` в `App.tsx` и блок в конце `index.css`).
- Меняете числа баланса — прогоняйте `npm test`: `balance.test.ts` падает,
  если темп прогресса уезжает за задуманные рамки (первая продажа, 8×8, AGI).
- Формат сохранения `v: 1`. При новых полях добавляйте значения по умолчанию в
  `deserialize()` (`save.ts`), а не ломайте старые сохранения.
