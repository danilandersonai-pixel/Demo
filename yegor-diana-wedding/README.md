# Егор & Диана — свадебное приглашение

Премиальный статичный сайт-приглашение (эдиториал-исполнение). Чистые HTML/CSS/JS —
без сборки, без npm-зависимостей и без бэкенда.

## Отложенные задачи (заметка по итогам QA, 12.06.2026)

Сайт прошёл аудит: критических ошибок нет. Два пункта отложены сознательно:

1. **RSVP в демо-режиме** — форма ничего не отправляет, пока в `assets/js/main.js`
   (строка ~6, `RSVP_ENDPOINT`) стоит плейсхолдер `YOUR_FORM_ID`. Включить —
   см. раздел «Настройка отправки RSVP» ниже (нужен Formspree endpoint).
2. **Внешние ассеты** — фото/видео/дресс-код/QR и `og:image` грузятся с живого
   домена `yegor.diana.yarover.ru`. При его недоступности гость увидит
   плейсхолдеры-градиенты. Чтобы сайт стал самодостаточным, файлы нужно
   скачать в репозиторий (например, в `assets/img/`) и заменить URL в
   `index.html`; `apple-touch-icon` при этом тоже заменить на локальную иконку.

## Как открыть превью

Вариант 1 — просто двойной клик по `index.html`.

Вариант 2 — локальный сервер:

```bash
cd yegor-diana-wedding
python3 -m http.server
```

и открыть http://localhost:8000

- `#hero` — имена и дата

## Настройка отправки RSVP (Formspree)

По умолчанию форма работает в **демо-режиме**: показывает сообщение
«Спасибо! (демо-режим, отправка не настроена)» и никуда ничего не шлёт.

Чтобы включить реальную отправку:

1. Зарегистрируйтесь на [formspree.io](https://formspree.io) (бесплатного тарифа достаточно).
2. Нажмите **New form**, укажите e-mail, на который будут приходить ответы гостей.
3. Скопируйте URL endpoint вида `https://formspree.io/f/xxxxyyyy`.
4. Откройте `assets/js/main.js` и вставьте URL в константу в самом начале файла:

   ```js
   const RSVP_ENDPOINT = "https://formspree.io/f/xxxxyyyy";
   ```

После этого форма будет отправлять ответы асинхронно (fetch + FormData),
с состояниями «Отправляем…» / «Спасибо! Ваш ответ получен» /
«Не удалось отправить, попробуйте позже». Клиентская валидация и
honeypot-поле `website` (антиспам) сохраняются: если honeypot заполнен,
отправка тихо не происходит.

### Альтернатива: Telegram-бот

Можно слать ответы себе в Telegram без сторонних сервисов:

1. Создайте бота у [@BotFather](https://t.me/BotFather) → получите `token`.
2. Напишите боту любое сообщение и узнайте свой `chat_id`
   (например, через `https://api.telegram.org/bot<token>/getUpdates`).
3. Отправляйте POST на `https://api.telegram.org/bot<token>/sendMessage`
   с параметрами `chat_id` и `text` (собрать текст из полей формы).

**Важная оговорка:** токен бота в статичном фронтенде виден любому, кто
откроет исходники страницы, — его могут использовать для спама от имени бота.
Поэтому для публичного сайта предпочтительнее Formspree (секретов на клиенте нет).

## Заметки

- **Карты** — виджет `https://yandex.ru/map-widget/v1/?text=<адрес>&z=16`
  в iframe c `loading="lazy"`; API-ключ не нужен.
- **«Добавить в календарь»** — событие 26.08.2026 10:00–23:00 МСК
  (в .ics указано в UTC: `20260826T070000Z`–`20260826T200000Z`);
  .ics генерируется на клиенте через Blob.
- **Лайтбокс** — фото галереи и Love Story открываются в оверлее;
  клавиши ←/→/Esc, клик по фону закрывает, фокус-ловушка и aria-атрибуты.
- **OG-превью** — теги Open Graph/Twitter в `<head>`; после деплоя подставьте
  итоговый `og:url` (см. TODO-комментарий в `index.html`).
- **Ассеты подгружаются с живого сайта** —
  `https://yegor.diana.yarover.ru/wp-content/themes/egor-diana-wedding/assets/`
  (фото, дресс-код, QR, интро-видео). При недоступности картинок показывается
  CSS-плейсхолдер, при недоступности видео — постер/градиент.
- Шрифты: Google Fonts (Cormorant Garamond + Inter), `display=swap`.
- Учтён `prefers-reduced-motion`: прелоадер скрывается мгновенно,
  parallax и reveal-анимации отключаются.
