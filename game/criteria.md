# Критерии приёмки
- К1 Телефон: портретный тач-UI, крупные цели, читаемость, один экран без зума.
- К2 Механики: осмысленные тактические решения, кубы/вероятности в духе настолки,
  внятный баланс, ИИ противника не тупит очевидно.
- К3 Контент среза: кампания 5–6 локаций с характером, 2 фракции, 6–8 юнитов,
  герои с прокачкой между миссиями.
- К4 Атмосфера: гримдарк-готика в духе ранних 40k, ОРИГИНАЛЬНЫЙ лор и нейминг,
  цельный визуал (CSS/SVG, без внешних ассетов).
- К5 Техника: статический билд без зависимостей, сохранения в localStorage,
  отсутствие ошибок в консоли, вменяемая производительность.
