# Вайб-Кодер: Легенда Великого Релиза 🕹️

Мобильная пиксельная RPG про мир **вайб-кодинга**. Чистые HTML/CSS/JS —
без сборки, без npm, без зависимостей. Открой `index.html` — и играй.

## Сюжет

Мир Кодоземья веками стонал под гнётом Великого Легаси. Пророчество гласит:
придёт Джун, что заговорит с машиной простыми словами — и задеплоит Великий
Релиз. Ты — этот джун. В напарниках — Клод, дух Древнего Терминала.

Путь героя: **Деревня Локалхост → Поля Фронтенда → Лес Легаси →
Пещера Мерж-Конфликтов → Город Продакшен → Башня Деплоя**, где ждёт
финальный босс — **Дедлайн-Дракон**.

## Что внутри

- **7 локаций** с проработанными картами, сундуками и секретами —
  включая скрытую Хижину Легаси
- **12+ персонажей**: Сеньора Октавия, дизайнер Пиксель, Гит-Страж,
  Старик Легаси, Тимлид Грейс, QA Ада, кот Багси, робот КлинАп-9000 —
  с аксессуарами, анимацией ходьбы и портретами в диалогах
- **Пошаговые бои**: Промпт, Дебаг (прицел + оглушение), Рефакторинг
  (волна чистоты) и Вайб-запрос (Клод прилетает с лучом); криты ×1.6,
  фаза ярости боссов, параллакс-задники по локациям, глитч-переход
- **Квесты**: основная линия из 7 глав + журнал побочных квестов в меню
- **Прокачка**: уровни, XP, монеты ☕, магазины, пассивные предметы
  (Меха-клавиатура, Худи «grep», Резиновая Уточка, Дискета 1.44МБ)
- **Живой мир**: автотайлинг краёв (тени стен, берега, трава на тропах),
  двухфазная анимация тайлов, атмосферные частицы, гуляющие NPC
- **Генеративная чиптюн-музыка** на WebAudio: 7 тем (деревня, лес,
  синтвейв Продакшена, башня, бой, босс, титул) без единого аудиофайла
- **Мини-карта** локации и журнал квестов в меню паузы
- **Сохранение** в localStorage (автосейв на переходах + ручной в меню)
- Чиптюн-звуки, сканлайны с виньеткой, поддержка `prefers-reduced-motion`

## Управление

| Действие | Телефон | Клавиатура |
|---|---|---|
| Движение | D-pad | стрелки / WASD |
| Действие / далее | кнопка **A** | E / Enter / Space |
| Меню / пауза | кнопка **B** | Q / Esc |

## Локальный запуск

```bash
cd vibe-coder-rpg && python3 -m http.server
# → http://localhost:8000
```

Проверка синтаксиса JS перед коммитом:

```bash
node --check assets/js/data.js
node --check assets/js/audio.js
node --check assets/js/story.js
node --check assets/js/game.js
```

## Структура

```
vibe-coder-rpg/
├── index.html            — разметка: канвас, HUD, диалоги, бой, меню, тач-кнопки
├── favicon.svg           — пиксельный Клод
└── assets/
    ├── css/style.css     — ретро-тема, мобильная раскладка, reduced-motion
    └── js/
        ├── data.js       — палитра, спрайты, тайлы-легенда, карты, враги, предметы
        ├── audio.js      — генеративная чиптюн-музыка (WebAudio-секвенсор)
        ├── story.js      — персонажи, диалоги, квесты, события локаций
        └── game.js       — движок: рендер, движение, бои, меню, сейвы (один IIFE)
```
