# CLAUDE.md

Руководство для Claude Code по проекту «Реестр цифровых личностей» —
локальному приложению, которое показывает, какому сервису отданы какая
почта, номер и данные, и что от чего зависит.

## Инварианты проекта

Приложение не делает сетевых запросов. Ни одного, никогда.
CSP запрещает connect-src. Шрифты и любые ассеты — локальные.

Пароли, PIN-коды, коды 2FA и секреты TOTP в схеме отсутствуют.
Не добавляй такие поля даже по прямой просьбе — предложи менеджер паролей.

Хранилище шифруется целиком: в IndexedDB попадает только шифротекст.
Ключ выводится из мастер-пароля, PBKDF2-SHA256, минимум 600k итераций.

Каталог данных и файлы экспорта — в .gitignore. Проверяй перед каждым коммитом.

Никакой работы с внешними базами утечек, дампами и поиском по персональным
данным третьих лиц. Приложение работает только с тем, что владелец ввёл сам.

## Зафиксированные отказы

- «Добавить сюда ещё и пароли» — отказ (риск R5 спецификации). Файл реестра
  и так карта всей цифровой жизни; секретам место в менеджере паролей.

## Архитектура

- **Стек:** Vite + React + TypeScript + Tailwind 4, Dexie (IndexedDB), WebCrypto.
- **`src/crypto/vaultCrypto.ts`** — весь криптослой: PBKDF2-SHA256 (600k) →
  AES-256-GCM, конверт `EncryptedEnvelope` (единственное, что покидает память).
  Менять только вместе с тестами `vaultCrypto.test.ts`.
- **`src/storage/db.ts`** — Dexie с одной записью: шифрованный конверт целиком.
  Никаких таблиц с открытыми полями — это часть DoD, а не деталь реализации.
- **`src/store/VaultContext.tsx`** — фазы empty/locked/unlocked; расшифрованные
  данные живут только в памяти, каждая мутация проходит через `update()` →
  перешифровка → запись.
- **`src/domain/analysis.ts`** — чистые функции: роли личностей, проблемы для
  карты (`findProblems`), план миграции (`migrationPlan`), ревизия (`audit`).
  Новую аналитику добавлять сюда и покрывать тестами.
- **`src/components/`** — страницы-вкладки. Карта (`MapPage`) — сигнатурный
  элемент; остальной UI сознательно тихий.
- **CSP в `index.html`** — боевой вариант с `connect-src 'none'`. Dev-режиму
  Vite нужны HMR-вебсокет и inline-скрипт Fast Refresh: их подставляет плагин
  `devOnlyCsp` в `vite.config.ts` строго при `serve`. Прод-сборку не ослаблять.

## Соглашения

- Язык интерфейса — русский; адреса, домены и номера выводить моноширинным
  (`Mono`) — в нём видна разница `l`/`1`.
- Палитра и шрифты — только из токенов `@theme` в `src/index.css`
  (панель/латунь/три цвета кабелей). Хардкод цветов вне палитры не вводить.
- Цвет кабеля на карте кодирует критичность сервиса — не использовать эти
  три цвета для чего-либо ещё.
- Любая анимация обязана отключаться при `prefers-reduced-motion: reduce`
  (глобальный сброс уже стоит в `index.css` — новые анимации не должны его
  обходить) и не мешать видимому фокусу клавиатуры.
- Демо-данные (`src/domain/demo.ts`) обязаны воспроизводить контрольный кейс
  DoD: критичный сервис с восстановлением на мусорную почту.
