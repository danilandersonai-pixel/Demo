# Дарья Сергеевна — сайт учителя

Статический одностраничный сайт-визитка учителя начальных классов и
английского языка. Чистые HTML/CSS/JS — без сборки, без npm, без бэкенда.
Реализация макета «Дарья Пронина — сайт (превью для заказчика)» из
Claude Design.

## Локальное превью

```bash
cd darya-pronina-site && python3 -m http.server   # → http://localhost:8000
```

## Структура

- `index.html` — вся разметка; якорные секции `#top`, `#works`, `#about`,
  `#tvoyurok`, `#reviews` (отзывы — последняя секция перед футером)
- `assets/css/styles.css` — дизайн-система (светлая/тёмная темы через
  CSS-переменные), секции, адаптив, reduced-motion
- `data/site-data.json` — ДАННЫЕ САЙТА: разработки и отзывы. Из него
  рендерятся карточки; его же правит кабинет учителя
- `data/auth.json` — доступ в кабинет: почта + GitHub-токен, зашифрованный
  паролем учителя (PBKDF2-SHA256 310k + AES-256-GCM)
- `login.html` / `assets/js/login.js` — страница входа (почта + пароль).
  `login.html?setup` — служебный генератор `auth.json` (всё в браузере)
- `admin.html` / `assets/js/admin.js` — кабинет учителя: список разработок
  (добавить/изменить/удалить, PDF + обложка), отзывы (загрузка скриншотов),
  кнопка «Опубликовать на сайт» → коммит в репозиторий через GitHub Contents API
- `assets/js/main.js` — один IIFE: рендер карточек и отзывов из
  `site-data.json`, переключение темы (localStorage `daria-theme`), фильтры
  раздела «Разработки» (категория + предмет с плашек героя), «Показать ещё»
  (видно 4 карточки, `WORKS_LIMIT`), карточка товара, год в футере
- `assets/photos/` — фотографии из макета
- `assets/materials/` — PDF-презентации; `covers/` — JPEG-обложки из первых
  слайдов (карточки раздела «Разработки», категория «Наглядно-учебный
  материал к урокам»)
- `favicon.svg` — логотип-галочка

## Кабинет учителя

Вход: `login.html` (ссылка «Вход для учителя» в футере) → почта и пароль →
`admin.html`. Пароль расшифровывает GitHub-токен из `data/auth.json`; сам токен
в открытом виде нигде не хранится, сессия живёт в `sessionStorage`
(или `localStorage` при галочке «оставаться в системе»).

Публикация: кнопка «Опубликовать на сайт» коммитит файлы (PDF, обложки,
скриншоты отзывов) и обновлённый `data/site-data.json` в ветку
`claude/darya-pronina-site-fitjjh` через GitHub Contents API. Сайт подхватывает
изменения сам — пересборка не нужна.

### Как выдать доступ учителю

1. Создать fine-grained GitHub PAT: доступ только к этому репозиторию,
   права **Contents: Read and write**.
2. Открыть `login.html?setup`, ввести почту учителя, придуманный пароль и токен —
   получить содержимое `auth.json`.
3. Заменить им `data/auth.json` и запушить. Сейчас там демо-доступ
   (`teacher@example.com` / `demo1234`) — кабинет открывается в режиме
   просмотра, публикация отключена.

Настройки репозитория (owner/repo/branch) — в начале `assets/js/admin.js`, `CFG`.
