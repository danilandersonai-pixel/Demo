# CHANGELOG.md

## 2.0 — «Арена Сунь-Цзы 2.0: ремонт, претенденты и генетика»

### Этап 0. Аудит и ремонт
- Полный аудит итерации 1: тесты, воспроизводимость всех артефактов,
  Definition of Done задания 1 — зелёный целиком (журнал — `AUDIT.md`).

### Блок 1. Лига претендентов
- `sim/challenge.js` пишет агрегаты пар (`roundRobinPairs`) — из них
  собираются персональные логи авторов.
- Круг 1: закрытый турнир претендентов против чемпиона; каждому из четырёх
  субагентов-авторов выданы только его собственные логи и место.
- Круг 2: каждый автор доработал свою стратегию по логам (блок `round2`
  в досье); выжившие введены в основную лигу, эталонные прогоны 7/42/2026
  пересчитаны для лиги 2.0. Глава «Война претендентов» — в `REPORT2.md`.

### Блок 2. Генетическая эволюция
- `sim/evolve.js`: геном памяти-2 (21 ген), популяция 64, 150 поколений,
  коэволюционный фитнес, турнирный отбор (k=3), равномерный кроссовер (0.9),
  мутация 0.02/ген, элита 2 (обоснование — D-15). Детерминизм по сиду.
- Канонический прогон `--seed 42` генерирует `strategies/evolved/nameless.js`
  — «Безымянный» вступает в основную лигу.

### Блок 3. Пространственный режим (обязательный)
- Тор 20×20, матчи с четырьмя соседями, захват клетки лучшим соседом;
  `results/spatial-<seed>.json` для всех эталонных сидов, пересчитан для
  лиги 2.0; сравнение «пространство против арены» — в `REPORT2.md`.

### Блок 4. Визуализатор 2.0
- Вкладки: Битва / Территория / Аналитика / Сыграй сам.
- Инспектор дуэлей: браузерная пересимуляция любого матча турнира
  (`viz/league.js`, порт тех же исходников с проверкой паритета — D-19),
  лента ходов, метки предательств, покадровый прогон, сверка с записью
  реплея, клик по дорожке битвы открывает пару.
- Таймлайн-скраббер с миниатюрой распределения долей.
- Звук: WebAudio-синтез без файлов (сеча, предательства, гибель фракций,
  фанфары, захваты клеток), кнопка mute, по умолчанию выключен.
- Полировка: траектории юнитов, стадии разрушения башен, статистика
  кампании на экране победы.
- Панели «Аналитики»: area-график, лидерборд, тепловая карта свипа,
  зал славы ELO (`sim/elo.js`), сводка генетики, досье.
- Режим «Сыграй сам»: 20 раундов против любой стратегии, разбор ошибок
  в духе Сунь-Цзы, сравнение с базлайном Зеркала.

### Блок 5. Стенд устойчивости
- `sim/sweep.js`: шум 0/5/10/20 % × длина 50/200/500 × матрица
  classic/goldrush (T8 R5 P1 S0, обоснование — D-17) →
  `results/sweep-42.json`; тепловая карта «условия × стратегии» в
  визуализаторе. Матрица выплат стала параметром движка (дефолтные байты
  не изменились).

### Качество
- `ARENA_DATA` версии 2: секции `sweep`, `elo` поверх реплеев и территорий.
- Новые тесты: генетика (детерминизм, кроссовер, мутации, «Безымянный»),
  свип, схема v2; суммарно ≥ 50.
- `sim/bench.js` — замер времени всех режимов; числа — в `AUDIT.md`.
- `sim/run.js`/`sim/spatial.js`: защита эталонных файлов суффиксами имён
  при нестандартных параметрах, валидация флагов CLI.

- 10 стратегий с досье (6 классических + 4 авторских по Сунь-Цзы).
- Репликаторная эволюция, CLI `sim/run.js`, эталонные сиды 7/42/2026.
- Визуализатор «Clash Royale lanes» + вкладка «Территория» (тор 20×20).
- Закрытый чемпионат претендентов (4 стратегии от изолированных субагентов).
- 58 тестов, `REPORT.md`, `LORE.md`, `DECISIONS.md`.
