# Арена Сунь-Цзы

Эволюционный турнир стратегий повторяющейся дилеммы заключённого с
визуализатором битвы на дорожках. Семнадцать фракций сражаются каждая с каждой,
между поколениями работает репликаторная динамика: доля стратегии в популяции
растёт, если её счёт выше среднего, и падает, если ниже. Побеждает не самый
агрессивный, а самый хитрый.

Лига собрана в два сезона: двенадцать рукописных стратегий первого,
четверо претендентов, прошедших два круга закрытого турнира, и «Безымянный» —
стратегия, которую никто не писал: её вывел генетический алгоритм.

Чистый Node.js ≥ 18 и чистый браузерный JavaScript. Ни одной зависимости,
ни одного шага сборки, ни одного сетевого запроса — всё работает офлайн.

## Запуск в три команды

```bash
node sim/run.js --all     # прогнать эталонные сиды 7, 42, 2026
npm test                  # 147 тестов
open viz/arena.html       # или просто двойной щелчок по файлу
```

`viz/arena.html` открывается прямо с диска, без сервера: данные приходят не
через `fetch`, а присваиванием `window.ARENA_DATA` в `viz/replay.js`, который
пишет симуляция.

## Правила

| | |
| --- | --- |
| Выплаты | R=3 (оба сотрудничают), P=1 (оба предают), T=5 (предал доверчивого), S=0 (тебя предали) |
| Матч | 200 раундов, длина стратегиям неизвестна |
| Шум | 5%: ход искажается на противоположный и в таком виде наблюдается обеими сторонами |
| Турнир | каждый с каждым, включая матч с собственной копией; счёт — средние очки за раунд |
| Эволюция | 30 поколений, репликаторная динамика, вымирание при доле ниже 0.5% |
| Победа | доминация свыше 60% популяции либо вымирание остальных |

## Вкладки визуализатора

### Битва

Фракции с приспособленностью не ниже средней идут в левую коалицию,
остальные — в правую, и сводятся попарно: верхняя дорожка — чемпион против
сильнейшего из отстающих. Линия фронта в дорожке стоит там, куда её ставит
очная разница очков в матрице, и переезжает на новое место по ходу поколения.
Размер армии — доля популяции, полоска под башней — её прочность относительно
исторического максимума фракции. При сшибке всплывают набранные очки и процент
потерянной доли. Верхняя полоса «ПОПУЛЯЦИЯ» — непрерывный якорь: она показывает
весь расклад одной строкой и не зависит от того, как разбиты дорожки.

Под скраббером — миниатюра распределения долей: видно, куда тащишь ползунок.

Стоит поймать: поколения 5–8, когда одна за другой рушатся башни Пацифиста,
Агрессора, Хаоса, Мстителя и «Безымянного», и поколения 20–29, где верхнюю
дорожку прочно занимает Контрразведка.

### Территория

Пространственный режим: сетка 20×20, каждая клетка играет с четырьмя соседями
по замкнутой сетке и перенимает стратегию сильнейшего в округе, а при равенстве
очков сохраняет свою. Победа здесь устроена иначе, чем в перемешанной
популяции: масштаб превосходства вырастает до монополии — разбор
в [REPORT2.md](REPORT2.md), глава 3.

### Аналитика

* **Доли популяции** — area-график по поколениям, рисуется на canvas вручную.
  Пунктир — порог доминации 60%; за 30 поколений его никто не достигает.
* **Таблица лидеров** — доля, счёт и прирост за поколение. Строка кликабельна
  и ведёт на карточку досье.
* **Инспектор дуэлей** — сетка всех пар последнего поколения. Клик по клетке
  разворачивает покадровый реплей матча: ленты ходов обеих сторон, бегущий
  счёт, предательства подсвечены красным, искажённые шумом ходы — жирным.
* **Стенд устойчивости** — тепловая карта «условия × победители» по 24 мирам.
* **Генетический режим** — хромосома «Безымянного», полная таблица его ответов
  и сходство с классиками.
* **Зал славы** — рейтинг Эло по 78 636 матчам всех режимов: лига на трёх
  сидах, два круга претендентов, территория, 24 мира стенда. Исход двоичный,
  матч с собственной копией не учитывается. Отдельной строкой — расхождение
  рейтинга с эволюцией: Агрессор первый по очной ставке и последний по
  размножению.
* **Претенденты** — итоги закрытого турнира в два круга.
* **Досье** — карточка на каждую из семнадцати фракций: принцип из трактата,
  механика, сильные и слабые стороны, против кого рассчитана.

### Сыграй сам

Двадцать раундов вручную против любого из семнадцати участников. Противник —
не пересказ стратегии на клиенте, а её настоящий код: `sim/bundle.js` переносит
исходники стратегий и движка в `viz/strategies.js` дословно, и в браузере
играет тот же `playMatch`, что и в турнире. Правила те же: та же матрица, тот же
5-процентный шум, длина боя противнику неизвестна.

После двадцатого раунда — разбор. Он не «оценивает стиль», а меряет: каждая
найденная ошибка переигрывается тем же движком на том же жребии, и рядом стоит
цена в очках. Разбираются три вещи, каждая со своим контрфактом:

* **удар без повода** — тот же список приказов, но без ударов по мирному;
* **милость к безнадёжному** — союз тому, кто бил три хода подряд;
* **месть призраку** — ответ на удар, которого противник не отдавал: его
  приказ исказил шум, а ты этого знать не мог.

Плюс таблица «как сыграли бы классики» — пять канонических стратегий против
того же противника на том же жребии, — и переломный раунд: место, с которого
простое Зеркало взяло бы больше. Удар в последнем раунде за ошибку не считается
и объясняется отдельно: ответить на него уже нечем.

Жребий боя показан числом. Тот же противник в тот же по счёту раз даст ту же
полосу помех — бой воспроизводим, «Реванш» идёт по новому жребию.

### Управление

Пробел — пуск и пауза, стрелки — по поколениям, кнопки ×1 / ×4 / ×16 —
скорость, «сид 7 / 42 / 2026» — переключение прогонов. На вкладке «Сыграй сам»
клавиши <kbd>C</kbd> и <kbd>D</kbd> отдают приказ. Кнопка звука включает
синтез на WebAudio — лязг сшибки, обвал башни, фанфары победы; файлов нет,
всё собирается осцилляторами на лету, по умолчанию выключено.

## Структура

```
engine/          ядро игры, ничего не знает о турнире
  rng.js         mulberry32 и вывод сида матча из (seed, поколение, i, j)
  payoff.js      матрица выплат (передаётся параметром, не глобалом)
  history.js     история матча глазами игрока — единственный канал наблюдения
  match.js       матч на N раундов с шумом в канале
  genome.js      хромосома на 21 локус: память на два раунда
strategies/      по файлу на стратегию, досье в шапке файла
  index.js       реестр: замороженное ядро (12) + принятые (5)
  challengers/   претенденты, прошедшие два круга закрытого турнира
  evolved/       nameless.js — генерируется генетикой вместе с досье
sim/
  tournament.js  круговой турнир и приспособленность
  evolution.js   репликаторная динамика и вымирание
  simulate.js    полный прогон: поколения, башни, дорожки, ленты дуэлей
  spatial.js     пространственный режим 20×20
  challengers.js закрытый турнир претендентов и личные донесения авторам
  evolve.js      генетический режим
  sweep.js       стенд устойчивости: 24 мира
  bench.js       замер производительности
  bundle.js      сборка кода стратегий для браузера (режим «Сыграй сам»)
  elo.js         рейтинг очной ставки по матчам всех режимов
  replay.js      сборка ARENA_DATA и запись viz/replay.js
  run.js         CLI
viz/
  arena.html     визуализатор целиком: разметка, стили, отрисовка
  replay.js      данные прогонов (генерируется, в редактировании не нуждается)
  strategies.js  код стратегий для браузера (генерируется)
tests/           180 тестов на node:test
results/         прогоны в JSON; results/v1/ — архив первого сезона
```

## CLI

```bash
node sim/run.js --seed 42                      # один прогон
node sim/run.js --all                          # сиды 7, 42, 2026 и территория
node sim/run.js --all --noise 0                # прогоны сравнения для отчёта
node sim/run.js --all --league core            # архив первого сезона, results/v1/
node sim/run.js --help                         # справка

node sim/challengers.js --round 2              # закрытый турнир претендентов
node sim/evolve.js --seed 42                   # генетика и «Безымянный»
node sim/sweep.js --seed 42                    # 24 мира стенда устойчивости
node sim/bench.js --repeat 3                   # замер производительности
node sim/bundle.js                             # код стратегий для браузера
node sim/elo.js --seed 42                      # рейтинг Эло по всем режимам
```

`--league core` прогоняет двенадцать стратегий первого сезона и кладёт результат
в `results/v1/` — именно на эти файлы опирается [REPORT.md](REPORT.md).
Ядро лиги заморожено, поэтому архив воспроизводится байт-в-байт и после того,
как лига выросла до семнадцати.

`sim/challengers.js` пишет `results/challengers.json`; чтобы результат попал
в визуализатор, после него нужно пересобрать реплей (`node sim/run.js --all`).

Прогон с шумом по умолчанию пишет `results/<seed>.json` и перестраивает
`viz/replay.js`, всегда оставляя в нём все три эталонных прогона. Прогон
с изменённым шумом — исследовательский: он пишет
`results/<seed>-noise<X>-gen<N>.json` и реплей не трогает, чтобы визуализатор
показывал три прогона в одинаковых условиях.

## Детерминизм

Один сид — байт-в-байт одинаковый результат. Весь недетерминизм проходит через
`engine/rng.js`; `Math.random()` не вызывается нигде, и это проверяется тестом,
который подменяет его ловушкой. Сид каждого матча выводится из
`(seed, поколение, i, j)`, поэтому результат пары не зависит от порядка
перебора. В выгрузке нет ни одного изменяющегося поля — временных штампов
в том числе.

Проверка воспроизводимости — часть тестов: `results/*.json` сравниваются
со свежим пересчётом побайтово.

## Как добавить свою стратегию

Положи файл в `strategies/` и добавь его **в конец массива `admitted`** в
`strategies/index.js`. Ядро (`core`) трогать нельзя: индекс стратегии входит
в сид каждого матча, и любая перестановка обесценит все прогоны первого сезона.

```js
module.exports = {
  id: 'myStrategy',        // должен совпадать с именем файла
  latin: 'MyStrategy',
  name: 'Моя стратегия',
  color: '#38bdf8',        // уникальный hex
  glyph: '兵',
  family: 'authored',      // classic | authored | challenger
  tagline: 'Одной строкой',
  dossier: {
    principle: 'Принцип из трактата',
    philosophy: 'Как она устроена и почему',
    strengths: ['…', '…'],
    weaknesses: ['…', '…'],
    targets: 'Против кого рассчитана'
  },
  create: function (api) {          // вызывается один раз на матч
    return {
      move: function (h) {          // h — история текущего матча, только чтение
        if (h.length === 0) return 'C';
        return h.lastOpp() === 'D' ? 'D' : 'C';
      }
    };
  }
};
```

Что доступно из `h`: `length`, `mine(i)` и `opp(i)` (отрицательный индекс —
с конца), `lastMine()`, `lastOpp()`, `oppDefections()`, `oppCooperations()`,
`myDefections()`, `oppCoopRate()`, `count(мой, его)`,
`oppCoopAfter(мойХод, априор)`, `oppSamplesAfter(мойХод)`, `moves(n)`.
Длина матча не сообщается. Нужна случайность — только `api.random`, иначе
прогон перестанет воспроизводиться.

Тесты подхватят новую стратегию автоматически: реестр проверяется на полноту
досье, уникальность цвета, соответствие имени файла и отсутствие обращений
к `Math.random`.
