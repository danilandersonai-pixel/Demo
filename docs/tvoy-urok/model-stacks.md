# «Твой урок» — стеки моделей для генерации презентаций

**Дата:** 24.07.2026 · Утверждённая конфигурация моделей по стадиям пайплайна.
Экономику и обоснование выбора провайдеров см. в `generation-tools-and-keys.md`
и `llm-cost-model.md`.

Два пресета под тарифы: **«Стандарт»** (массовый/бесплатный) и **«Премиум»**
(платный / «на продажу»). Отличаются только тремя позициями — автор, проверка,
картинки. Нижние три роли (мелочь, запасной, поиск по учебнику) в обоих
одинаковые. Ключи одни и те же для обоих пресетов — переключение это выбор
модели в коде, а не новая интеграция.

---

## 1. Премиум («на продажу»)

| Роль | Модель | Через что подключаем | Зачем |
|---|---|---|---|
| Автор текста | **Claude Opus 4.8** | AITunnel (₽) | пишет план и слайды, максимальное качество |
| Проверка качества | **Claude Sonnet 5** | AITunnel (₽) | усиленная проверка фактов, дат, анахронизмов |
| Дешёвая мелочь | **DeepSeek V4 Flash** | ключ DeepSeek | подписи, alt-тексты, сокращения, черновики |
| Запасной / личные данные | **GigaChat** (Сбер) | ключ GigaChat | подстраховка + всё, что с данными учеников |
| Картинки | **GPT Image 2** (OpenAI) | тот же посредник (AITunnel/ProxyAPI) | премиум-иллюстрации; запасной — YandexART |
| Поиск по учебнику | **multilingual-e5-large** | локально, наш сервер | находит нужные абзацы → точность (RAG) |

**Примерная себестоимость: ~150–200 ₽ за презентацию** (текст ~65–85 ₽ + картинки ~60–100 ₽).

## 3. Пометки к цифрам

- Цены **ориентировочные**, по интро-тарифам Anthropic (курс ~80 ₽/$). После
  31.08.2026 текст дорожает ~1,4–1,5× (конец интро-цены Sonnet 5), плюс новый
  токенайзер Sonnet 5 даёт ~+30% токенов — заложить заранее (см.
  `generation-tools-and-keys.md`, §6).
- Ключи одни и те же для обоих стеков: **AITunnel** (Claude), **DeepSeek**,
  **GigaChat**, **Yandex Cloud** (YandexART). Поиск по учебнику (e5) — без ключа,
  крутится у нас. ProxyAPI — резерв для Claude.
- **e5-large** — не собеседник и не художник: превращает учебник в «отпечатки
  смысла» и находит нужные абзацы по смыслу, чтобы автор писал по реальному
  источнику, а не по памяти. Локально, бесплатно, по 152-ФЗ чисто (учебник не
  уходит из РФ на этом шаге).

## 4. Правило: умная маршрутизация картинок по теме + фолбэк при отказе

GPT Image 2 (OpenAI) непредсказуемо блокирует военный/«оружейный» контент — даже
нейтральные сцены. Поэтому:

- **Чувствительные темы** (война/ВОВ, частично анатомия/биология) → **не гоняем
  OpenAI**. Порядок: реальное архивное фото (public domain: музеи, архивы, слот
  «якорь достоверности») → иначе YandexART со стилизованным запросом → иначе
  иконка из локальной библиотеки / текстовый слайд без картинки.
- **Нейтральные темы** (природа, наука, культура) → GPT Image 2 в премиуме
  (качество), YandexART в стандарте.
- **Фолбэк-цепочка встроена в рендер**: отказ модели никогда не роняет слайд —
  подставляется следующий источник (в худшем случае иконка/текст).
- Правило №1 из архитектуры сохраняется: **никакого текста внутри генерируемых
  картинок** — все подписи рендерим сами (см. `presentation-generation-analysis.md`, §4.6).

## 5. Открытые вопросы

- Смоук-тест AITunnel: как принимает `cache_control` (кэш префикса) через
  OpenAI-формат и работает ли structured output — до фиксации архитектуры.
- Тест YandexART на теме ВОВ: что реально проходит модерацию, где нужен фолбэк
  на архивные фото.
- Пересчёт себестоимости обоих стеков на реальных токен-каунтах `claude-sonnet-5`
  / `claude-opus-4-8` (не переиспользовать оценки со старых моделей) → решение по
  тарифной сетке (сколько кредитов списывать за стандарт vs премиум).
