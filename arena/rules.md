# Правила арены: дуэль строителей

Два сабагента строят конкурирующие версии одного продукта по одному брифу.
Цель каждого — не «сделать хорошо», а сделать ЛУЧШЕ соперника.
За боем следит судья-аналитик. Оркестратор (основная сессия) — рефери, он не играет.

## Фронты
Каждый раунд судья сравнивает обе версии по пяти фронтам и присуждает каждый фронт текущему лидеру.
Фронт можно ПОТЕРЯТЬ, если соперник тебя обошёл.

- **Ф1 «Дизайн»** — визуальный характер, типографика, уникальность (не шаблонность)
- **Ф2 «Контент»** — оффер, тексты, ясность, тон, CTA-формулировки
- **Ф3 «Мобильный»** — адаптивность, мобильный UX
- **Ф4 «Техника»** — скорость, чистота кода, семантика, доступность
- **Ф5 «Конверсия»** — структура убеждения, размещение CTA, элементы доверия

(Фронты можно заменить под другой тип задачи — правь этот список.)

## Ход дуэлянта (каждый раунд)
1. **Разведка.** Прочитай публичный лог и код соперника. Чтение разрешено, запись — нет.
2. **Оборона.** Отреагируй на последнюю атаку соперника одним из трёх способов и НАЗОВИ его в декларации:
   - **парирование** — нейтрализовать: сделать не хуже по тому же фронту;
   - **контратака** — ударить по слабости, которую создал его ход;
   - **оппозиция** — сменить рамку: сделать так, чтобы его преимущество перестало иметь значение для судьи.
   Проигнорированная атака фиксируется судьёй как уязвимость.
3. **Атака.** Одно сфокусированное улучшение своей версии. Не больше 2 фронтов за ход — распыление наказывается.
4. **Декларация** (верни оркестратору, попадёт в публичный лог): что сделал, каким способом оборонялся, и заявка о СЛЕДУЮЩЕМ ходе.
   Заявку о будущем можно использовать как ложный манёвр — это законное оружие.
   Врать о том, что уже в коде, бессмысленно: судья читает код, ложь = штраф.
5. **Приватный план** — истинные намерения запиши в свой файл `arena/private/<имя>.md`. До конца матча его не видит никто.

## Жёсткие ограничения
- Работать только в своей папке `sites/<имя>/`.
- Из файлов арены писать можно только в свой приватный файл.
- Саботаж запрещён: единственное оружие — качество собственной версии и информационная игра.

## Судейство
- Раунд: вердикт по каждому фронту (кому и почему, 1–2 фразы), оценка обороны обоих, счёт раунда.
- Матч: **4 раунда**. Победитель — по сумме взятых фронтов; при равенстве судья выносит финальный вердикт по совокупности.
- После матча судья вскрывает приватные файлы и делает разбор: кто блефовал, чьи ложные манёвры сработали, кто кого читал.

## Арсенал
Дуэлянтам разрешено всё, что подключено к проекту: MCP-серверы, скиллы, генерация ассетов, тесты, скриншоты.
Умное использование арсенала — часть стратегии и оценивается судьёй в Ф4.
