# Журнал решений

Формат: дата — решение — почему.

- 2026-09-26 — Реальная папка проекта `~/vibefoundry`, в `~/Desktop/игра/vibefoundry` — символическая ссылка на неё. — macOS TCC не даёт процессам превью-сервера читать `~/Desktop` (проверено в прошлых проектах), а игру нужно смотреть в браузере; для пользователя путь из промпта работает.
- 2026-09-26 — Шрифты Exo 2 / IBM Plex Sans / IBM Plex Mono через `@fontsource` вместо Inter + JetBrains Mono. — Для VibeFoundry уже утверждена дизайн-система (`~/vibefoundry-design/tokens.json`), снятая с тех же референсов; все три шрифта с кириллицей. Промпт допускает замену.
- 2026-09-26 — Палитра HUD и ресурсов — из `tokens.json` дизайн-системы, палитра биомов — сэмплирована с изображений 2–3 и скорректирована. — Промпт требует hex, снятые с картинок; дизайн-система — как раз такой съём.
- 2026-09-26 — UI на Preact (DOM поверх canvas), перерисовка по подписке на store с троттлингом ~8 Гц. — Сложные панели (вайб-панель, Git, дерево исследований) проще в компонентах; Preact весит ~4 КБ.
- 2026-09-26 — Изометрия 2:1 с тайлом 64×32 px на зуме 1 (дизайн-система даёт 128×64 для артбордов). — Остров 256×256 должен помещаться в разумный масштаб; на зуме 2 получаем 128×64.
- 2026-09-26 — Одна полоса на конвейере, 4 слота предметов на тайл, скорость 2 тайла/с (8 предм./с). — Промпт разрешает одну полосу; фиксированные слоты = плоские массивы без аллокаций.
- 2026-09-26 — Семантика действий FactoryScript «заявки на прогон»: `disable/set_priority/route/limit` действуют, пока скрипт продолжает их вызывать; если условие перестало выполняться — эффект снимается на следующем запуске. — Даёт естественное «временно отключай» из референса, без ручного `enable`, и не оставляет фабрику в залипшем состоянии после отката.
- 2026-09-26 — `self.power` / `self.energy` = мощность / номинальный спрос (без учёта того, что скрипты уже отключили). — Иначе правило «если энергии < 80 % — отключи чипы» дребезжало бы: отключил → хватает → включил → не хватает.
- 2026-09-26 — Playwright закреплён на версии 1.60.0. — Её Chromium (ревизия 1223) уже лежит в кэше; последняя 1.63 потребовала бы качать ~170 МБ через медленную сеть.
- 2026-09-26 — Глубокое море не рисуется тайлами, это фон канваса. — Экономит ~30 тыс. спрайтов; визуально неотличимо.
- 2026-09-26 — Дальний зум (< 0.3) переключается на LOD-текстуру всего острова, нарисованную на 2D-канвасе. — Иначе на обзоре пришлось бы рисовать 35 тыс. тайлов.
- 2026-09-26 — Огни зданий — отдельный аддитивный слой поверх мира; ночь — тинт контейнеров мира. — Дёшево и даёт «ночной город» из референса; минус — огонь дальнего здания может просвечивать сквозь ближнее, это приемлемо.
