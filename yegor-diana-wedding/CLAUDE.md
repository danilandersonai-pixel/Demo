# CLAUDE.md — Свадебный сайт «Егор & Диана»

Этот файл описывает сайт-приглашение на свадьбу Егора и Дианы и служит
руководством для Claude Code при работе с его кодовой базой.

> Документ составлен по результатам анализа продакшен-версии сайта
> **https://yegor.diana.yarover.ru** (HTML, CSS-переменные, ресурсы темы).

## Обзор

Одностраничный сайт-приглашение (landing) на свадьбу **26 августа 2026 года**
в Санкт-Петербурге. Язык интерфейса — русский (`<html lang="ru-RU">`).

- **Title:** `Приглашение на свадьбу`
- **Description:** `Приглашение на свадьбу Егора и Дианы, 26 августа 2026 года.`
- **Хэштег события:** `#EgDiDa`

## Стек и платформа

| Компонент | Значение |
|-----------|----------|
| CMS | WordPress 7.0 (`<meta name="generator">`) |
| Кастомная тема | `egor-diana-wedding` (версия `style.css?ver=1.3.0`) |
| Формы | Плагин **Contact Form 7** `6.1.6` |
| Локализация | GlotPress 4.0.3, локаль `ru-RU` |
| Обработка RSVP | Кастомный AJAX-экшен `egor_diana_rsvp` (через `admin-ajax`, защита nonce `egor_diana_rsvp_nonce`) |

Тема — кастомная, поэтому почти весь стиль и разметка живут в
`wp-content/themes/egor-diana-wedding/`. Контент-секции свёрстаны вручную,
а не блоками Gutenberg.

Якорная навигация ведёт к секциям:

| Детали | `#details` | Дресс-код, подарки, фото/видео, хэштег |

| Цветы | `#flowers` | Подписка на цветы вместо букетов |

### Программа дня
- **10:00** — Регистрация в ЗАГСе (Петроградский р-н, ул. Большая Монетная, 17-19)
- **17:00** — Сбор гостей во дворце (дворец Кваренги, Казанская ул., 7а лит. А)
- **17:30** — Торжественная часть
- **23:00** — Завершение вечера

### Форма RSVP (`#guestForm`)
Поля: `guestName` (ФИО), `attendance` (подтверждение), `plusOne` (+1 гость),
`meal` (рыба/мясо/птица), предпочтения по алкоголю, `comment` (комментарий).
Поле `website` — honeypot-антиспам. Отправка через AJAX-экшен `egor_diana_rsvp`
с nonce `egor_diana_rsvp_nonce`; результат выводится в `#result`.

### Типографика
- **Заголовки / акцент:** `Georgia, serif`
- **Основной текст:** `Inter, Manrope, system-ui, -apple-system, BlinkMacSystemFont, …`
- Внешние шрифты (Google Fonts и т.п.) **не подключаются** — используются
  системные и serif-стек.

### Декор
Лёгкие повороты элементов через `--r` (`-2deg…2deg`) для «живого» вида карточек.

## Заметки для работы с кодом

- Это **WordPress-сайт**; разработка ведётся в кастомной теме
  `egor-diana-wedding`. Версионируй `style.css` (`?ver=`) при изменениях стиля.
- Контент жёстко зашит в шаблонах темы (не редактируется через админку как
  блоки) — текст программы, дат и адресов правится в файлах темы.
- Цвета и отступы — только через CSS-переменные из палитры выше; не вводи
  новые хардкод-цвета вне дизайн-системы.
- Форму RSVP обрабатывает кастомный серверный хук `egor_diana_rsvp`
  (WordPress action) — при изменении полей формы синхронизируй и PHP-обработчик,
  и проверку nonce, и honeypot `website`.
- Интро-видео должно оставаться `muted` + `playsinline` для автоплея в мобильных
  браузерах; сохраняй оба источника (`.mp4` и `.m4v`) и постер.
- Язык контента — русский; сохраняй `lang="ru-RU"` и кодировку UTF-8.
