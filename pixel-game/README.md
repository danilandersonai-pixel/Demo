# Клодик и Вайб-кодинг 🎮

Милая пиксельная мини-игра про вайб-кодинг. Клодик — коралловый пиксельный
персонаж в наушниках — сидит за кодом и ловит вайб.

## Как играть

- **Лови** хорошее: ☕ кофе, 💡 идеи, 🎵 лоу-фай нотки, ♥ сердечки (лечат).
- **Уворачивайся** от 🐛 багов — три бага, и «баги победили».
- Заполни шкалу **ВАЙБ** до конца — включится режим **ПОТОК**: очки ×2,
  Клодик светится и слушает нотки.
- Комбо за серию пойманных предметов даёт бонусные очки. Рекорд хранится
  в `localStorage`.

## Управление

- Клавиатура: `←` `→` или `A` `D`; `Space`/`Enter` — старт.
- Тач/мышь: зажми и веди пальцем по полю — Клодик побежит за пальцем.

## Запуск

Чистые HTML/CSS/JS, без сборки и зависимостей:

```bash
cd pixel-game && python3 -m http.server   # → http://localhost:8000
```

Или просто открой `index.html` в браузере.

## Технически

- Логическое разрешение 240×160, канвас масштабируется с
  `image-rendering: pixelated`.
- Все спрайты — пиксель-арт из текстовых карт, рисуются кодом
  (см. `makeSprite` в `game.js`), картинок нет.
- Звук — крошечный WebAudio-синт (пентатоника), есть кнопка мьюта.
- `prefers-reduced-motion` уважается: без тряски, частиц и покачиваний.
