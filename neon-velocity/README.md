# Neon Velocity: Rhythm & Dodge

Неоновая аркада на рекорд в стиле Retro Synthwave / Cyber Arcade. Корабль летит
над бесконечной перспективной сеткой к ретро-солнцу, сверху на огромной скорости
несутся кубы, лазерные стены и циркулярные пилы, а препятствия выпадают в такт
синтвейв-саундтреку, который синтезируется прямо в браузере. Уворачивайтесь,
собирайте энергетические сферы, раскручивайте комбо до ×10 и бейте свой рекорд.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev            # игра на http://localhost:5173
```

Другие команды:

| Команда | Что делает |
| --- | --- |
| `npm run typecheck` | проверка типов TypeScript |
| `npm run build` | продакшен-сборка в `dist/` |
| `npm run build:single` | вся игра одним HTML-файлом в `dist-single/index.html` — открывается двойным кликом, без сервера и интернета |
| `npm run preview` | локальный просмотр продакшен-сборки |

## Управление

| Действие | Клавиатура | Мышь / касание |
| --- | --- | --- |
| Лететь влево / вправо | `←` `→` или `A` `D` | корабль плавно следует за курсором или пальцем |
| Играть | `Enter` / `Space` в меню | кнопка «Играть» |
| Пауза / продолжить | `Esc` или `P` | кнопка паузы в правом верхнем углу |
| Заново (на паузе) | `R` | «Заново» |
| В меню (на паузе) | `M` | «В меню» |
| Ещё раз (Game Over) | `Enter` / `Space` / `R` | «Ещё раз» |
| Магазин / рекорды / меню (Game Over) | `S` / `L` / `Esc` | кнопки на экране |

Горячие клавиши работают и в русской раскладке. При сворачивании вкладки игра сама
встаёт на паузу.

## Правила

- **Препятствия.** Неоновые кубы (самые частые), циркулярные пилы и, со 2-го уровня,
  лазерные стены во всю ширину поля с одним проходом. Генератор гарантирует, что
  проход есть всегда.
- **Энергетические сферы.** Дают очки и валюту: обычная — 1 кристалл, редкая
  (крупнее и другого цвета) — 5 кристаллов и ×5 очков.
- **Комбо.** Каждые 3 сферы подряд поднимают множитель: ×1 → ×2 → ×3 … до ×10.
  Множитель умножает все очки. Столкновение или пропущенная сфера сбрасывают его до ×1.
- **Уровни скорости.** Каждые 15 секунд: скорость падения растёт, темп музыки
  ускоряется, сетка меняет цвет, экран встряхивает. Со 2-го уровня препятствия
  начинают вилять зигзагом, и чем дальше, тем шире и чаще.
- **Near miss.** Пролетите впритирку к препятствию — получите бонус.
- **Рекорд.** Как только счёт обгоняет лучший результат, вспыхивает «NEW RECORD!».
  Пять лучших забегов с датой и достигнутым уровнем скорости попадают в таблицу рекордов.

## Магазин

Кристаллы, заработанные в забегах, тратятся в магазине главного меню. Для старта
дарится 150 кристаллов. Покупка сразу надевает предмет.

**Корабли**

| Корабль | Цена | Что даёт |
| --- | ---: | --- |
| Neon Core — Неоновое ядро | бесплатно | стартовый корабль |
| Neon Trail — Неоновый шлейф | 300 | хвост из светящихся частиц, +10 % к очкам |
| Magnet — Магнит | 450 | слегка притягивает сферы |
| Ghost Shield — Щит-призрак | 650 | прощает одно столкновение за забег |
| Singularity — Сингулярность | 2500 | шлейф, магнит и щит сразу, +15 % к очкам |

**Темы:** Neon Cyberpunk (бесплатно), Retrowave Gold (400), Toxic Acid (400),
Arctic Pulse (700). Тема перекрашивает небо, солнце, сетку, препятствия, сферы и
акценты интерфейса.

**Улучшения** (по 3 уровня): «Кристальный резонатор» (+20 % кристаллов за уровень),
«Усилитель поля» (+30 % к радиусу магнита), «Призма удачи» (+4 % к шансу редкой сферы).

## Сохранение

Прогресс, кристаллы, покупки, настройки и таблица рекордов автоматически
сохраняются в `localStorage` браузера под ключом `neon-velocity/save/v1` и
загружаются при следующем запуске. Повреждённые данные игра не роняют: каждое поле
проверяется при загрузке. Сбросить всё можно в «Настройках» → «Сбросить прогресс».
Если хранилище недоступно (например, в приватном окне), игра работает, но
предупреждает, что прогресс не сохранится.

## Как устроено

React отвечает за меню, магазин, HUD и оверлеи, а игровой цикл живёт вне React:
`requestAnimationFrame` → движок с фиксированным шагом симуляции → рендер на
Canvas 2D. HUD получает данные через внешний стор не чаще 30 раз в секунду, так
что интерфейс не мешает 60 FPS.

```
src/
├── game/            движок, генератор препятствий, столкновения, частицы,
│   ├── render/      рендер на Canvas (фон, сетка, корабль, препятствия, эффекты)
│   ├── audio*.ts    синтезатор музыки и звуков на Web Audio
│   ├── config.ts    баланс и стартовые пресеты — все числа игры здесь
│   └── types.ts     общие типы — контракт между модулями
├── state/           сохранение, магазин и рекорды (чистые функции + React-хук)
└── components/      App, холст, HUD, меню, магазин, рекорды, настройки, оверлеи
```

Подробное описание модулей, контрактов и поведения — в [ARCHITECTURE.md](ARCHITECTURE.md).

**Стек:** React 19, TypeScript, Tailwind CSS 4, Framer Motion, Lucide React,
HTML5 Canvas 2D, Web Audio API, Vite 8. Шрифты JetBrains Mono и Orbitron
подключены локально — игре не нужен интернет.
