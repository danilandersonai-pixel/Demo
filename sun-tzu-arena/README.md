# ⚔ Арена Сунь-Цзы 2.0

Эволюционный турнир стратегий в повторяющейся дилемме заключённого:
лига из 15 ботов (10 рукописных + 4 претендента от изолированных
субагентов + «Безымянный», выведенный генетическим отбором), шум 5 %,
репликаторная динамика, пространственный режим на торе 20×20, стенд
устойчивости и визуализатор в четыре вкладки. Чистый Node.js ≥ 18, без
зависимостей, офлайн, всё детерминировано по сиду.

## Запуск в 3 команды

```bash
cd sun-tzu-arena
node sim/run.js --all        # эталонные сиды 7, 42, 2026 → results/ + viz/replay.js
node --test tests/*.test.js  # 73 теста
```

Третья команда — открыть `viz/arena.html` двойным кликом (все данные вшиты
в `viz/replay.js` и `viz/league.js`, сервер не нужен).

## Остальные команды

```bash
node sim/evolve.js --seed 42   # генетика: 64 генома × 150 поколений → «Безымянный»
node sim/spatial.js --all      # территории 20×20 для эталонных сидов
node sim/challenge.js          # закрытый турнир претендентов против чемпиона
node sim/sweep.js --seed 42    # стенд устойчивости: 24 условия → тепловая карта
node sim/bundle.js             # пересборка браузерного порта лиги (viz/league.js)
node sim/bench.js              # замер времени всех режимов
```

Произвольный прогон: `node sim/run.js --seed N [--generations 30] [--noise 0.05] [--rounds 200]`.
Любое отклонение параметров от умолчаний пишется в файл с суффиксом
(`42-noise0.json`, `42-gen5.json`) и не затирает эталоны.

## Структура

```
engine/     ядро: mulberry32 + свёртка сидов (rng.js), матч с шумом и
            параметризуемой матрицей выплат (game.js)
strategies/ по файлу на стратегию, в шапке — досье; index.js — реестр
            (порядок = индексы в данных)
  challengers/  4 претендента от субагентов (в досье — блок «Круг 2»)
  evolved/      nameless.js — «Безымянный» (автогенерируется evolve.js)
sim/        tournament, evolution (репликатор), simulate, run (CLI),
            challenge (два круга претендентов), evolve (генетика),
            spatial (тор 20×20), sweep (стенд), elo, bundle, bench
viz/        arena.html + replay.js (данные, ARENA_DATA v2) + league.js
            (браузерный порт лиги для инспектора и «Сыграй сам»)
tests/      node:test — 73 теста
results/    воспроизводимые байт-в-байт артефакты всех режимов
```

## Что смотреть в визуализаторе

- **Битва** — поколение как волна: армии трёх главных фронтов, река, башни
  с прочностью и стадиями разрушения, всплывающие выплаты (+3/+3, +5/0,
  +1/+1), анонсы падений, экран победы со статистикой кампании. Клик по
  дорожке открывает эту пару в инспекторе. Скраббер в тулбаре несёт
  миниатюру распределения долей.
- **Территория** — тор 20×20: клетка играет с четырьмя соседями и перенимает
  стратегию лучшего; вспышки захвата, счётчики площадей. Спойлер: здесь
  царит совсем не тот, кто на арене.
- **Аналитика** — area-график долей, живой лидерборд, **инспектор дуэлей**
  (покадровый реплей любого матча турнира, пересимулированного в браузере
  тем же сидом, с метками предательств и сверкой с записью), тепловая
  карта стенда устойчивости, зал славы ELO (и парадокс Аксельрода), сводка
  генетики, досье всех 15 стратегий.
- **Сыграй сам** — 20 раундов против любой стратегии; после матча — разбор
  ошибок в духе Сунь-Цзы и сравнение с тем, что взяло бы Зеркало.
- **Звук** — WebAudio-синтез (сеча, предательства, падения фракций, фанфары);
  по умолчанию выключен, кнопка 🔇 в тулбаре.
