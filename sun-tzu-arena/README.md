# ⚔ Арена Сунь-Цзы

Эволюционный турнир стратегий в повторяющейся дилемме заключённого:
10 ботов, шум 5 %, репликаторная динамика на 30 поколений и визуализатор
битвы в стиле «Clash Royale lanes». Чистый Node.js ≥ 18, без зависимостей,
полностью офлайн, детерминирован по сиду.

## Запуск в 3 команды

```bash
cd sun-tzu-arena
node sim/run.js --all        # прогнать эталонные сиды 7, 42, 2026 → results/ + viz/replay.js
node --test tests/*.test.js  # 58 тестов
```

Третья команда — открыть `viz/arena.html` двойным кликом (данные уже вшиты
в `viz/replay.js`, никакой сервер не нужен).

Произвольный прогон: `node sim/run.js --seed 42 --generations 30 [--noise 0.05] [--rounds 200]`.
Результат при нестандартном шуме пишется в `results/<seed>-noise<v>.json`.

## Структура

```
engine/     ядро: mulberry32 + свёртка сидов (rng.js), матч с шумом (game.js)
strategies/ по файлу на стратегию, в шапке каждого — досье;
            index.js — реестр (порядок = индексы в данных, не переставлять)
  challengers/  стратегии-претенденты, написанные субагентами вслепую
sim/        tournament.js (каждый с каждым), evolution.js (репликатор),
            simulate.js (оркестратор прогона), run.js (CLI),
            challenge.js (закрытый турнир претендентов),
            spatial.js (территории: тор 20×20, node sim/spatial.js --all)
viz/        arena.html (визуализатор, открывается с диска) + replay.js (данные)
tests/      node:test: движок, репликатор, поведение стратегий, схема ARENA_DATA
results/    <seed>.json — эталонные прогоны, воспроизводимые байт-в-байт
```

Правила игры: R=3, P=1, T=5, S=0; матч 200 раундов (длина стратегиям
неизвестна); с вероятностью 5 % фактический ход искажается на противоположный.
Эволюция: доля стратегии растёт пропорционально её успеху против текущей
популяции; доля < 0.5 % — вымирание.

## Что смотреть в визуализаторе

- **Поле боя.** Каждое поколение — волна: армии трёх самых весомых пар
  поколения (вес = произведение долей) маршируют к реке, сталкиваются,
  линия фронта сдвигается к проигравшему. Размер армии = доля популяции,
  прочность башни = доля к порогу доминации 60 %. Всплывающие числа — исходы
  раундов: +3/+3 мир, +5/0 предательство, +1/+1 война. Падение фракции —
  анонс, тряска экрана и череп на башне.
- **Управление.** ▶/пауза (или пробел), скорость ×1/×4/×16, перемотка
  слайдером и стрелками ←/→, клик по графику — прыжок к поколению,
  переключатель прогонов: сид 7, 42, 2026.
- **Панели.** Area-график долей по поколениям, живая таблица лидеров
  (доля, тренд, фитнес), карточки-досье всех стратегий с их принципами из
  трактата; павшие отмечаются черепом и поколением гибели.
- **Финал.** Экран победы: условие (доминация > 60 % / истребление / победа
  по доле), пьедестал и кнопка «смотреть снова».
- **Вкладка «Территория».** Пространственный режим: тор 20×20, клетка играет
  с четырьмя соседями и перенимает стратегию лучшего. Вспышки — захваты
  клеток; легенда показывает живой баланс сил. Спойлер: здесь побеждают
  совсем не те, кто на арене.
