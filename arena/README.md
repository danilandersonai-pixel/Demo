# Арена сабагентов — каркас для Claude Code

Два дуэлянта строят конкурирующие версии одного продукта, каждый ход — атака,
которую соперник обязан парировать, контратаковать или обойти оппозицией.
Судья-аналитик присуждает фронты, оркестратор ведёт матч.

## Установка
Распакуй содержимое в корень проекта Claude Code (папка `.claude/` может уже
существовать — просто добавь файлы внутрь):

```
твой-проект/
├── .claude/
│   ├── agents/
│   │   ├── duelist-alpha.md   ← дуэлянт, доктрина «Натиск»
│   │   ├── duelist-beta.md    ← дуэлянт, доктрина «Туман»
│   │   └── arena-judge.md     ← судья-аналитик
│   └── commands/
│       └── arena.md           ← команда /arena (оркестратор)
└── arena/
    └── rules.md               ← правила: фронты, ходы, судейство
```

## Запуск
```
/arena лендинг для студии свадебной флористики, стиль — ботанический люкс
```
Дальше всё само: 4 раунда, параллельные симультанные ходы, вердикты судьи,
финальный разбор со вскрытием приватных планов.

## Что настраивать
- **Фронты** — в `arena/rules.md` (сейчас заточены под лендинг; для другой
  задачи замени пять фронтов).
- **Доктрины** — в файлах дуэлянтов (сделай их одинаковыми — получишь чистый
  симметричный бой).
- **Число раундов** — в `.claude/commands/arena.md` и `arena/rules.md`.
- **Арсенал** — дуэлянты наследуют все инструменты сессии, включая MCP-серверы
  и скиллы проекта: что подключено к проекту, тем они и воюют.

## Предупреждение
Матч — это 2 строителя × 4 раунда + 5 вызовов судьи, каждый в своём контексте.
Это дорого по токенам. Для пробы можно сократить до 2 раундов.
