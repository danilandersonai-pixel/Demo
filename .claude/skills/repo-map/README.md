# repo-map

Скилл для Claude Code: собирает карту твоих GitHub-репозиториев и показывает её
двумя способами — компактным деревом прямо в чате и визуальной HTML-страницей,
которую можно открыть по ссылке и держать в закладке.

Нужен, когда репозиториев стало больше, чем помещается в голове, и вопрос «а где
я вообще остановился» возникает чаще, чем хотелось бы.

## Как пользоваться

```
/repo-map                  # все репозитории
/repo-map Demo             # только Demo, дерево глубже
/repo-map --fast           # без деревьев файлов: список, ветки, PR
/repo-map --depth 4        # своя глубина обхода
```

## Что показывает

- список репозиториев с однострочным описанием каждого — чтобы не вспоминать,
  что такое `warp-loader`;
- дерево файлов внутри, до 3 уровней, без `node_modules` и прочего шума;
- ветки и открытые pull request'ы;
- незакрытые хвосты: ветки без PR, PR, которые висят неделями, спящие
  репозитории.

## Установка

### Глобально — работает во всех сессиях

Для десктопного приложения и CLI. Скопируй папку скилла в домашний каталог
Claude Code:

```bash
mkdir -p ~/.claude/skills
cp -r .claude/skills/repo-map ~/.claude/skills/
```

После этого `/repo-map` доступен в любом проекте на этой машине.

### В конкретный репозиторий — для веб-сессий

В Claude Code на вебе контейнер каждый раз создаётся заново, и `~/.claude` не
переживает перезапуск. Там скилл виден только если он лежит в самом
репозитории, с которым идёт работа. Чтобы добавить его в новый проект:

```bash
mkdir -p <проект>/.claude/skills
cp -r .claude/skills/repo-map <проект>/.claude/skills/
```

Закоммить — и в следующей веб-сессии по этому репозиторию скилл будет на месте.

## Важное ограничение

Список репозиториев скилл получает всегда. А вот заглянуть **внутрь**
репозитория он может только если тот подключён к текущей сессии. Если не
подключён, скилл попробует подключить его сам — это запросит твоё
подтверждение. Откажешь — репозиторий всё равно попадёт в карту, просто без
дерева файлов, с пометкой о недоступности.

Поэтому первый запуск в новой сессии может попросить доступ к нескольким
репозиториям сразу. Это нормально и происходит один раз за сессию.

## Устройство

```
repo-map/
├── SKILL.md              процедура целиком
├── reference/
│   ├── collect.md        какие вызовы, глубина, фильтры, схема данных
│   └── render.md         формат дерева в чате и работа с шаблоном
└── assets/
    └── template.html     страница карты: стили и рендерер внутри
```

Страница не сочиняется заново на каждом запуске — в шаблоне уже лежит вся
вёрстка, а агент подставляет туда только данные. Поэтому карта выглядит
одинаково от раза к разу: глаз привыкает, где что находится, и читать её
становится быстрее. Если хочется поменять внешний вид — правь
`assets/template.html`, это единственное место.
