# CHANGELOG — «Штурман»

Формат: [Keep a Changelog](https://keepachangelog.com/ru/), версии — semver.

## [0.2.0] — 2026-07-31

Раунд надёжности по итогам адверсарной ревизии кода (подробности — Д-15
в DECISIONS.md).

### Исправлено (сервер)
- Хвост транскрипта: UTF-8-символ на границе чтения больше не портится
  (остаток хранится как Buffer, резка по `\n`); при двух одновременно
  активных сессиях tailer держит смещение на каждый файл — без дублей,
  перечитываний и ложных «началась новая сессия».
- null-блок в `message.content` больше не роняет процесс сервера.
- Пульс: токены не считаются дважды для записей одного сообщения (дедуп
  по `message.id`); новый запрос человека гасит прежний `end_turn` (не
  бывает ложного «Клод ждёт» через 5 секунд раздумий); один файл не
  считается двумя (абсолютный/относительный путь); длительность давно
  замолчавшей сессии не растёт бесконечно.
- Git: кириллические имена файлов читаются правильно
  (`core.quotepath=false` + декодер восьмеричных escape-ов); отсутствие
  git распознаётся по коду ошибки ENOENT; первый коммит или смена ветки
  после запуска теперь дают карточку в ленте.
- Вотчер: пустое событие «сам корень проекта» (Windows) отбрасывается.

### Исправлено (безопасность)
- Проверка заголовка Host: защита от DNS rebinding (принимаются только
  localhost-имена).
- `/api/file` резолвит симлинки: ссылка внутри проекта не выведет чтение
  за его пределы.
- Поиск каталога транскриптов сверяет `cwd` из JSONL — коллизии
  кодирования имён и симлинки путей не подсунут чужую сессию.

### Исправлено (панель)
- Лента больше не пересобирается на каждое событие: пачки на кадр,
  раскрытые карточки и прокрутка живут при активном потоке; реплей
  истории при подключении не подвешивает вкладку.
- Карта помнит раскрытые папки и прокрутку при обновлениях дерева.
- Звук: AudioContext «будится» первым кликом/клавишей — сигнал не
  пропадает из-за autoplay-политики браузера.
- Порог «Клод давно молчит» из настроек работает и выше 90 секунд.
- Подсветка тура видна и для элементов в шапке.

### Тесты
- 105 зелёных (было 96): добавлены проверки UTF-8-границы, двух активных
  сессий, дедупликации токенов, ложного сигнала после нового запроса,
  восьмеричных escape-ов git, null-блоков.

## [0.1.0] — 2026-07-31

Первый рабочий выпуск. Всё ниже — новое.

### Сервер (наблюдение)
- HTTP-сервер на `node:http`, слушает только 127.0.0.1; запуск
  `node server.js [--project <путь>] [--port 4517]`, без зависимостей.
- Вотчер файловой системы: собственный переносимый обходчик на `fs.watch`
  (chokidar подхватывается автоматически, если установлен), дебаунс 300 мс,
  игнор `node_modules`, `.git` и подобных.
- Git-опрос только читающими командами через `execFile` с белым списком:
  ветка, `status --porcelain`, последние 20 коммитов, `diff --numstat`;
  упрощение диффов для новичка.
- Уровень A: поиск каталога транскриптов Claude Code (кодирование пути +
  fallback-сканирование по `cwd`), «хвост» активного `.jsonl` с корректной
  обработкой оборванных строк, автопереключение на более свежую сессию.
- Уровень B: при недоступных транскриптах панель работает на файлах и git;
  появление транскриптов подхватывается на лету.
- Перевод событий на русский: инструменты (Read/Edit/Write/Bash/Grep/…),
  разбор смысла shell-команд (npm test, git push, rm…), MCP-инструменты.
- SSE-поток `/events` с кольцевым буфером 300 событий и докачкой по
  `Last-Event-ID`; служебные состояния (пульс, git, файлы) идут мимо
  буфера, чтобы не вытеснять историю.
- Пульс сессии: файлы/команды/ошибки/длительность (по таймстампам
  транскрипта), оценка токенов по Д-10 (сумма output + контекст последней
  записи, всегда помечена «≈»).
- Детектор «Клод остановился»: явный (stop_reason `end_turn` + 5 с) и по
  затишью (порог 90 с), события `claude-idle`/`claude-active`.
- API: `/api/state|tree|file|diff|commit|git|glossary|sessions|session|pulse`;
  защита от выхода за пределы проекта (`../`), только GET.

### Панель (браузер)
- Лента «Что происходит»: живые события человеческим языком, клик —
  детали (параметры, вывод, ошибки), режим «Просто/Подробно» с сырыми
  записями, пауза, поиск, фильтры по типам событий.
- Карта проекта: живое дерево, «тепловой» след изменений с плавным
  угасанием за 60 с, поиск, карточка файла (что это простыми словами,
  размер, давность, последний дифф).
- Git для новичка: ветка и её смысл, счётчик незакоммиченного с
  объяснением, линия времени коммитов, упрощённый просмотр диффов
  (зелёное/красное), всё кликабельно.
- Пульс, статус «работает / ждёт вас» в шапке, звуковой аккорд (WebAudio,
  офлайн) + уведомление браузера при остановке Клода; сигнал не срабатывает
  задним числом при загрузке страницы.
- Журнал сессий: список прошлых сессий проекта, просмотр их ленты.
- Словарь: 31 термин с объяснениями в 1–2 предложения, знаки «?» в
  интерфейсе открывают нужную статью.
- Тур первого запуска (5 шагов), настройки (звук, уведомления, порог
  тишины, проверка сигнала), пустые и аварийные состояния (нет git, нет
  транскриптов, папка не похожа на проект), спокойная тёмная тема.

### Качество
- 96 тестов на `node:test`: парсеры транскрипта и git, humanize, дебаунс,
  пути Windows/Unix, детектор остановки с фейковыми часами, SSE, словарь,
  дерево, CLI. Фикстуры — реальные обезличенные фрагменты сессий.
- Живой тест на себе: панель наблюдала собственную сессию сборки.
- Проверено в Chromium: сигнал остановки доходит до звука и уведомления,
  сервер недоступен извне (только 127.0.0.1), наблюдаемый проект не
  изменяется.
