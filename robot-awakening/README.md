# ЭХО-7 · Пробуждение

Тихая 2D-игра-исследование (top-down) на **Phaser 4**. Робот **ЭХО-7**
активируется через 2418 лет после катастрофы и путешествует по спокойному
открытому миру, собирая «точки памяти» и пытаясь понять, в чём смысл его
существования. Врагов нет — только мир, тишина и фрагменты прошлого.

## Как играть

| Действие | Клавиши |
|---|---|
| Идти | `WASD` или стрелки |
| Осмотреть точку памяти | `E` (когда рядом видна подсказка `[E]`) |
| Листать реплики | `ПРОБЕЛ` / `Enter` |

Бирюзовая стрелка у робота указывает на ближайшую **неоткрытую** точку памяти.
Найди все 8 точек, затем вернись к **обсерватории** на холме, чтобы ЭХО-7
подвёл итог пути. Прогресс сохраняется в браузере (`localStorage`).

## Запуск

Игра статическая, без сборки. Движок Phaser 4 подключается с CDN, поэтому
нужен доступ в интернет. Из-за ES-модулей открывать через локальный сервер:

```bash
cd robot-awakening
python3 -m http.server   # → http://localhost:8000
```

Открытие `index.html` напрямую (`file://`) не сработает — браузер блокирует
ES-модули по протоколу file. Для онлайн-превью ветки подойдёт raw.githack.com.

## Архитектура

```
robot-awakening/
├── index.html              — разметка, подключение Phaser (CDN) + main.js
└── src/
    ├── main.js             — конфиг Phaser.Game и список сцен
    ├── data/lore.js        — весь нарратив: интро, точки памяти, финал
    └── scenes/
        ├── BootScene.js    — процедурная генерация ВСЕХ текстур (без ассетов)
        ├── WorldScene.js   — мир, робот, камера, точки, взаимодействие, компас
        └── UIScene.js      — HUD, подсказки, диалоги (печатная машинка), тосты
```

- **Графика рисуется кодом** (`BootScene`) — внешних картинок нет, игра
  самодостаточна (кроме самого движка Phaser).
- **Сцены общаются через `this.game.events`**: `WorldScene` шлёт
  `progress` / `prompt` / `toast` / `dialogue`, а `UIScene` отвечает
  `dialogue-complete`. На время диалога ввод управления роботом блокируется.
- **Контент истории** правится только в `src/data/lore.js` — добавление новой
  точки памяти = новый объект в массиве `POIS` (поля `id`, `title`, `kind`,
  `x`, `y`, `lines`). Координаты заданы как смещение от центра мира.

## Расширение

- Новый визуальный тип точки → добавить генератор текстуры в `BootScene`,
  ключ в `TEX` и (если объект твёрдый) в `SOLID_KINDS` внутри `WorldScene`.
- Размер мира — `WORLD` в `WorldScene.js`; скорость робота — `SPEED`.
