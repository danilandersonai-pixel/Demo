# Дарья Сергеевна — сайт учителя

Статический одностраничный сайт-визитка учителя начальных классов и
английского языка. Чистые HTML/CSS/JS — без сборки, без npm, без бэкенда.
Реализация макета «Дарья Пронина — сайт (превью для заказчика)» из
Claude Design.

## Локальное превью

```bash
cd darya-pronina-site && python3 -m http.server   # → http://localhost:8000
```

## Структура

- `index.html` — вся разметка; якорные секции `#top`, `#works`, `#about`,
  `#tvoyurok`, `#reviews` (отзывы — последняя секция перед футером)
- `assets/css/styles.css` — дизайн-система (светлая/тёмная темы через
  CSS-переменные), секции, адаптив, reduced-motion
- `assets/js/main.js` — один IIFE: переключение темы (localStorage
  `daria-theme`), фильтры раздела «Разработки» (категория + предмет с плашек героя),
  «Показать ещё» (видно 4 карточки, `WORKS_LIMIT`), карточка товара
  (модалка перед скачиванием PDF), год в футере
- `assets/photos/` — фотографии из макета
- `assets/materials/` — PDF-презентации; `covers/` — JPEG-обложки из первых
  слайдов (карточки раздела «Разработки», категория «Наглядно-учебный
  материал к урокам»)
- `favicon.svg` — логотип-галочка

## Кабинет учителя (admin.html)

Страница для заказчицы: добавление/правка разработок и скриншотов отзывов
без программиста. Вход по fine-grained GitHub-токену (Contents RW на этот
репозиторий; токен хранится только в localStorage браузера). Изменения
коммитятся через GitHub Contents API в ветку сайта: файлы — в
`assets/materials/` и `assets/reviews/`, данные — в `data/site-data.json`,
из которого `main.js` рендерит карточки и отзывы.

## Что осталось заглушками (по макету)

- Обложки части работ и скриншоты отзывов — пунктирные плейсхолдеры;
  при появлении материалов заменить `div.slot` на `img`.
- Ссылки «Посмотреть прототип», «Telegram» и «Вход для учителя» — неактивны
  (`aria-disabled="true"`), появятся вместе с сервисом «Твой урок».
