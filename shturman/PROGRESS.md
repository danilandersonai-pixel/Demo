## Известные ограничения

Не баги, а осознанные границы — каждая пояснена в `DECISIONS.md`:

1. **Подписи в графе внимания — 10px.** Это подписи к диаграмме, а не текст
   интерфейса; рядом есть «Список» с текстом 15px и зонами касания 44px.
2. **Переключатель проектов на телефоне** живёт в списке «⋯»: картушка заняла
   место шапки. Ничего не потеряно, путь на одно нажатие длиннее.
3. **Ключ доступа не шифрует трафик.** `--share` работает по http.
4. **QR-кодировщик узкий**: байтовый режим, уровень M, версии 1–10.
5. **Статистика правок из транскрипта приблизительная**, когда Claude Code не
   положил `structuredPatch`.
6. **Оценка токенов не равна биллингу** — только суммы из `usage`.
7. **Тепловой след живёт в браузере**: перезагрузка страницы его сбрасывает.
8. **Граф внимания без физической симуляции** — раскладка радиальная;
   подписи на плотном кольце иногда налезают.
9. **`--app` зависит от наличия Chromium-браузера.**
