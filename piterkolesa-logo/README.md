# PITERKOLESA — векторный логотип (SVG)

Производственный векторный логотип «PITERKOLESA», восстановленный из растрового
PNG как **чистый SVG** — только `<path>` (математически точные окружности, дуги и
прямые), без embedded-битмапов, без `clip-path`/`mask`/`filter`, без следов
автотрассировки.

## Файлы

- **`piterkolesa-logo.svg`** — итоговый логотип (`viewBox="0 0 2000 440"`,
  ~4 КБ). Прозрачный фон; все негативные участки (отверстия под болты, центр
  ступицы, контрформы букв, внутренняя часть «O», диагональный разрез шины) —
  настоящие вырезы (`fill-rule="evenodd"`), а не белая заливка.
- **`build.js`** — параметрический генератор на чистом Node.js (без зависимостей),
  который строит SVG из геометрии. Доказывает, что контуры — настоящий вектор, и
  позволяет править логотип параметрами (толщина обводки, наклон, кернинг, радиусы).

## Состав

**Колесо** — построено из геометрических примитивов: внешняя шина (две дуги с
тонким диагональным разрезом), сегментированный протектор (штрихованная дуга),
оранжевая дуга-кольцо, пять конических спиц, ступица с центральным отверстием и
пятью отверстиями под болты, диагональная оранжевая «молния».

**Надпись** — тяжёлый наклонный гротеск (~12°) с угловыми срезами; буква `K` —
с оранжевой нижней диагональю, буква `O` — кольцо с внутренней оранжевой дугой
(мини-колесо).

## Палитра

- Чёрный — `#111111`
- Оранжевый — `#F26522`

## Пересборка

```bash
node build.js   # → piterkolesa-logo.svg
```

## Примечание о шрифте

Точный фирменный шрифт надписи невозможно восстановить из растра без файла
шрифта, а автотрассировка запрещена техзаданием. Поэтому буквы перестроены
геометрически вручную — с сохранением пропорций, веса, наклона, кернинга и
фирменных деталей (`K`, `O`). Результат — чистые контуры, пригодные для печати
любого размера, плоттерной/лазерной резки, фрезеровки и нанесения на одежду.
