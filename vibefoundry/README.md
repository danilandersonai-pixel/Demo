# VibeFoundry

> **Build · Automate · Vibe Code · Repeat**
> «Ты не просто строишь фабрику. Ты создаёшь ИИ, который строит её сам.»

Браузерная изометрическая игра: Factorio, в котором главный инструмент — не руки, а ИИ. Вы высаживаетесь на процедурный остров с базой и примитивным «ИИ в терминале», тянете конвейеры, строите плавильни и цеха, а потом поручаете AI-агентам автоматизацию **обычными словами**. Агенты пишут код на встроенном языке FactoryScript, изменения проходят через **Git фабрики** и **песочницу** — и иногда ломают всё из-за галлюцинаций, техдолга и нехватки контекста. Финал — автономная AI-колония и Шпиль Колонии.

Вся графика и звук генерируются кодом (PixiJS v8 + WebAudio). Игра работает офлайн; режим «Настоящий ИИ» подключает Claude по вашему ключу.

## Запуск

```bash
npm install
npm run dev          # http://localhost:5178
```

Другие команды:

```bash
npm run build        # production-сборка в dist/
npm run typecheck    # TypeScript strict
npm test             # Vitest: симуляция, FactoryScript, движок намерений, вайб-цикл, демо, прогрессия, стресс-тест
npm run e2e          # Playwright: бот играет 20 минут, проверяет вехи, снимает скриншоты в docs/screenshots/
```

В главном меню: **Новая игра** (сид, размер острова, мирный режим), **Продолжить**, **Загрузить**, **Демо-сценарий** (за 2 минуты показывает все ключевые механики), **Настройки**, **Об игре**.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки / перетаскивание (ЛКМ без инструмента, ПКМ или средняя кнопка) | Камера |
| Колесо | Зум |
| ЛКМ | Поставить / выбрать здание или тайл |
| ПКМ | Снести здание (материалы вернутся) / отменить инструмент |
| R | Повернуть |
| Q | Пипетка (взять здание под курсором как инструмент) |
| B | Строить |
| M | Стратегическая карта |
| Tab | Вайб-панель (код) |
| T | Исследования |
| G / X | Группа рамкой / снос рамкой |
| Alt | Оверлей: рецепты над зданиями, узкие места (жёлтые — без входа, красные — без энергии) |
| Пробел | Пауза |
| 1 / 2 / 3 / 4 | Скорость ×1 / ×2 / ×4 / ×8 |
| Ctrl+C / Ctrl+V | Копировать область в чертёж / вставить (после исследования «Чертежи») |
| F3 | Оверлей производительности |
| Esc | Закрыть окно / меню паузы (сохранение, загрузка, экспорт) |

Конвейеры и трубы тянутся мышью линией. Здания ставятся призраками — строительные дроны прилетают с базы и строят, забирая материалы со складов.

## Первые шаги

1. **Строить → Добыча → Сборщик ресурсов** на рыжее или серое месторождение (стрелка показывает выход).
2. Протяните **конвейер** от бура. **Робот-манипулятор** кладёт руду в **плавильню**, второй — забирает пластины.
3. Лента, упирающаяся в **Базу** или **Склад**, сдаёт туда предметы. Здания рядом с базой питаются от неё; дальше — **столбы ЛЭП**.
4. Нажмите **Tab** и опишите задачу словами — задачи слева подскажут дальше.

## Вайб-кодинг

Вайб-панель: слева чат («Ты»), в центре ответ агента со сгенерированным кодом, диффом, стоимостью в токенах и уверенностью, справа Git фабрики, активные агенты и ресурсы ИИ. Кнопки: **Принять** (коммит), **Редактировать** (встроенный редактор, код проверяется парсером), **Отклонить**, **Прогнать в песочнице** (клон фабрики симулируется 90 с вперёд и показывает прогноз).

10 примеров запросов (работают офлайн):

1. «Сделай так, чтобы медная руда автоматически доставлялась на переработку, приоритет отдавался аккумуляторам, а если энергии не хватает — временно отключай производство микросхем.»
2. «Если железных пластин больше 1000 — останови плавильни железа.»
3. «Держи запас аккумуляторов на уровне 500.»
4. «Когда энергия ниже 20%, выключи химзавод.»
5. «Ночью отключай всё, кроме серверов.»
6. «Уведоми меня, если производство чипов упадёт ниже 50 в минуту.»
7. «Переключи сборщики группы line_b на модули памяти.» (группу создайте рамкой: G)
8. «Отправь дрона исследовать ближайшую неизвестную область.»
9. «Распредели медные пластины поровну между двумя линиями.»
10. «Make batteries top priority when power is low.»

Ещё: «Построй линию микросхем на 60 в минуту» (Architect ставит чертёж), «Найди баги» (Debugger), «Отрефактори скрипты» (Optimizer снижает техдолг), «Найди узкие места», «Что происходит на фабрике?», «Добавь тест: микросхем ≥ 100 в минуту» (CI-станция).

Пример FactoryScript:

```python
class CopperRouter(Agent):
    every = 2          # запускать каждые 2 секунды игрового времени
    def run(self):
        if self.power < 0.8:
            self.disable("chip_production")
        self.set_priority("batteries", 1)
        self.route("copper_ore", "smelter")
```

Полный справочник по языку, API и группам — в игре: **Кодекс → FactoryScript**.

### Боли ИИ, которые делают игру честной

- **Токены**: каждый запрос стоит токенов (длина + контекст фабрики). Их даёт терминал базы и инференс-узлы.
- **Контекст**: если фабрика не помещается в память агента, он «видит» её частично и ошибается чаще. Ставьте модули памяти в AI Core.
- **Галлюцинации**: неверное имя предмета, инвертированное условие, дребезг, несуществующая группа, забытый else — баг не подсвечивается, а проявляется в фабрике.
- **Техдолг**: принятие без песочницы копит долг → больше багов и дороже операции. Песочница + зелёные CI-тесты = без долга. Optimizer рефакторит.
- **Катастрофы**: если после коммита производство упало на 40 %, коммит помечается «Катастрофа» и предлагается «Rollback».

## Режим «Настоящий ИИ»

**Настройки → Режим «Настоящий ИИ»**: включите, вставьте ключ Anthropic API, выберите модель (по умолчанию Claude Haiku 4.5 — быстрая и дешёвая; также Sonnet 5 и Opus 5) и нажмите «Проверить». Запросы к агентам уходят в Claude Messages API прямо из браузера через официальный `@anthropic-ai/sdk`. Системный промпт содержит грамматику FactoryScript, API мира и сводку фабрики; ответ обязательно проходит парсер, при ошибке — одна попытка самоисправления, затем офлайн-движок.

Ключ хранится **только** в `localStorage` этого браузера: не попадает в сохранения, экспорт, логи и чат. Игра полностью играбельна без этого режима.

## Структура

```
src/
  core/     RNG, шум, изометрия, события
  world/    генерация острова, туман войны
  sim/      симуляция: ленты, манипуляторы, машины, энергия, трубы, дроны, враги, квесты, статистика
  script/   FactoryScript: лексер, парсер, AST, интерпретатор, API мира, группы, рантайм
  vibe/     движок намерений, кодогенерация, Git фабрики, песочница, LLM-клиент
  ai/       агенты, эры, галлюцинации, контекст, Architect
  render/   Pixi: процедурные текстуры, террейн, здания, юниты, частицы, день/ночь
  ui/       Preact-HUD и окна
  data/     предметы, рецепты, здания, исследования, квесты, биомы
tests/      Vitest
e2e/        Playwright
docs/       GDD, арт-библия, план, решения, прогресс, отчёт, скриншоты
```
