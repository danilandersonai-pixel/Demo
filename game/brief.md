# Бриф: мобильная стратегия «в духе ранних Warhammer 40k»
Полноценная пошаговая стратегия для игры в мобильном браузере (портрет, тач).
Оригинальный гримдарк-сеттинг (готика в космосе, фанатичная империя, ксеносы) —
БЕЗ использования IP Games Workshop (никаких имён/фракций/текстов из W40k).
Дух ранней настолки: отряды, кубы, вероятности, жёсткие потери.
Вертикальный срез: кампания 5–6 локаций, 2 фракции, 6–8 типов юнитов,
герои с прокачкой, сохранения. Чистые HTML/CSS/JS, без библиотек и сборки.
Процесс: 2 концепта → судья → одна сборка по победителю → доводка критиком.
