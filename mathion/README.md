# Mathion: Числовой Алхимик

Математическая RPG-стратегия в браузере. Заклинания творятся решением примеров: чем быстрее и точнее вы считаете, тем сильнее удар. Эссенции, добытые в боях, идут на апгрейды и зелья в лаборатории. Башня из 10 боссов и режим «Блиц» проверяют, насколько вы выросли.

**Стек:** React 19 + TypeScript (strict), Tailwind CSS v4, Framer Motion, Lucide React, Vite. Бэкенда нет: прогресс автоматически сохраняется в `localStorage`.

## Запуск

```bash
cd mathion
npm install
npm run dev            # http://localhost:5173
```

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Dev-сервер |
| `npm run typecheck` | Проверка типов |
| `npm run build` | Production-сборка в `dist/` |
| `npm run build:single` | Вся игра одним файлом `dist-single/index.html` |

## Как играть

**Школы магии** (выбираются прямо в бою):

| Школа | Примеры | Базовый урон | Доп. время |
| --- | --- | --- | --- |
| Земля | сложение и вычитание (с 10-й сложности — три числа) | 10 | +0 с |
| Огонь | умножение (с 10-й — двузначное на однозначное) | 14 | +1 с |
| Вода | деление нацело | 14 | +1 с |
| Пустота (с 3 уровня) | уравнения с x, включая отрицательные корни и `x ÷ a + b = c` | 21 | +4 с |

Сложность примеров равна уровню врага. Ответ вводится встроенным Numpad или с клавиатуры: цифры, `−` для знака, Backspace, Esc очищает, Enter применяет.

**Урон** = база школы × (1 + 10% за уровень героя) × скорость (до ×1.4 за быстрый ответ) × комбо (+5% за каждый верный подряд, до +50%) × уязвимость врага (×1.5, стойкость ×0.5) × крит (12%, при комбо от 5 — 18%; сила ×1.5 + 0.25 за уровень Философского камня). Щит врага поглощает урон первым.

**Ошибка или истёкший таймер** — враг атакует, комбо сбрасывается, выдаётся новый пример. Сменить школу можно в любой момент, но таймер при этом не сбрасывается.

## Модули

1. **Арена.** Охота трёх уровней риска (враг слабее, равный или сильнее на 2 уровня), экран боя «герой — Горн — враг», пояс с зельями и заклинаниями, пауза. Пауза ставится сама, если уйти с арены или свернуть вкладку, и при этом пример скрывается.
2. **Лаборатория.** Дерево из трёх ветвей по два узла: Философский камень → Кодекс эссенций, Магические линзы → Кристалл маны, Ментальный щит → Амулет жизни. Нижний узел открывается после первого уровня верхнего. Книга рецептов: Зелье здоровья, Зелье заморозки времени, Бомба-автоответ, Эликсир маны.
3. **Башня Испытаний.** 10 этажей с уникальными боссами: Жар (−2 с), Ледяной панцирь, Яд, Близнецы Чётности (только чётные ответы, нечётный ввод — ошибка), Ярость, Отражение, Пожиратель времени, Регенерация, Печать Пустоты с двумя фазами. **Блиц:** 60 секунд, +3 секунды за верный ответ, сложность растёт каждые 4 ответа, таблица из 10 личных рекордов.
4. **Инвентарь.** Экипированные артефакты и их итоговые бонусы, сумка зелий, книга заклинаний (Руна восстановления, Дробитель щитов, Числовой метеор), эссенции, статистика точности по школам, сброс игры.

Внизу экрана — «Свиток битв»: журнал всех событий в виде пергамента.

## Архитектура

```
src/
├── types.ts               — модель данных (GameState, Battle, Blitz, события)
├── game/
│   ├── constants.ts       — баланс: школы, формулы, апгрейды, рецепты, заклинания
│   ├── problems.ts        — генератор примеров, разбор и нормализация ввода
│   ├── enemies.ts         — бестиарий охоты и 10 боссов башни
│   ├── engine.ts          — движок: бой, таймер, зелья, заклинания, лаборатория, блиц
│   ├── storage.ts         — загрузка с валидацией и сохранение
│   └── seed.ts, utils.ts
├── hooks/useGame.ts       — игровые часы, автосохранение, визуальные эффекты
└── components/
    ├── arena/             — лобби, бой, Горн, Numpad, карточки бойцов, блиц
    ├── lab/, tower/, inventory/
    ├── layout/            — шапка с вкладками, свиток битв
    └── ui/                — кнопки, панели, шкалы, иконки, модалки
```

Движок не знает о React и таймерах: каждое действие — чистая функция `(state, …) → { state, events }`, время приходит через `tick(state, dt)`, случайность — через `rng`. Хук `useGame` тикает часы 10 раз в секунду (только когда открыта арена и вкладка видима), сохраняет прогресс не чаще раза в секунду и сразу при уходе со страницы, а события превращает в анимации: фиолетовые цифры урона, тряску героя при ошибке, полёт заклинания и вспышки зелий.
