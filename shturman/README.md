# 🧭 Штурман

**Панель-наставник для тех, кто только осваивает Claude Code.**

Вы запустили Claude Code, он что-то делает в терминале — быстро, много и не
всегда понятно. Штурман открывает рядом окно в браузере и простым русским
языком рассказывает: что происходит прямо сейчас, какие файлы в проекте и что
только что менялось, что творится в git, и — главное — **звонит, когда Клод
остановился и ждёт вашего ответа**. Можно спокойно уйти за чаем.

Штурман только смотрит. Он ничего не меняет в вашем проекте, вызывает git
исключительно на чтение и доступен только с вашего компьютера.

---

## Запуск в три команды

```bash
cd путь/к/вашему/проекту          # 1. перейти в папку проекта
node путь/к/shturman/server.js    # 2. запустить Штурман
# 3. открыть в браузере http://127.0.0.1:4517
```

Всё. Ни `npm install`, ни сборки, ни интернета — зависимостей у Штурмана
нет вообще. Нужен только **Node.js версии 18 или новее**
(проверить: `node --version`).

Дальше в соседнем окне терминала запускаете `claude` как обычно — и смотрите
в панель.

### Если что-то мешает

```bash
node server.js --project ~/мойпроект   # следить за другой папкой
node server.js --port 5000             # если 4517 занят
node server.js --open                  # сразу открыть браузер
node server.js --help                  # все флаги
```

## Что показывают панели

### 📰 Лента «Что происходит»

Каждое действие Клода — отдельной строкой, человеческим языком:

```
🔧 Клод запустил npm test — проверяет, работают ли тесты
📝 Клод изменил engine/game.js (+42 −7)
📖 Клод читает README.md
⛔ Ошибка: команда в терминале не сработала
🙋 Вы написали Клоду
```

- **«Просто / Подробно»** — переключатель в шапке ленты. В подробном режиме
  под каждой строкой видны сырые данные события: какой инструмент, с какими
  аргументами, что вернулось.
- **Клик по строке** открывает подробности справа: дифф файла (зелёное —
  добавлено, красное — удалено), вывод команды, сообщения об ошибках.
- **Пауза** останавливает прокрутку, чтобы успеть прочитать. Новые события
  копятся и показываются, когда вы нажмёте «Показать».
- **Фильтры и поиск** — по типам событий (правки, чтение, команды, ошибки,
  диалог, git) и по тексту.

### 🗺 Карта проекта

Живое дерево файлов. Только что изменённые подсвечиваются жёлтым, и подсветка
плавно гаснет за полторы минуты — сразу видно, где кипит работа. Клик по файлу
открывает карточку: **что это за файл простыми словами**
(«package.json — паспорт проекта: зависимости и команды»), размер, когда
менялся, последний дифф. Есть поиск по имени.

### 🌿 Git

- Текущая ветка и **что она означает** одной строкой.
- Счётчик несохранённых изменений с объяснением, почему это важно.
- Список изменённых файлов — клик открывает дифф.
- Вкладка «История»: коммиты как линия времени с человеческими подписями
  («Исправление: что-то работало не так и это починили»).
- Значки **«?»** по всему интерфейсу открывают словарь: 40 терминов, каждый
  объяснён в одном-двух предложениях. Полный список — кнопка «📚 Словарь».

Если git в проекте нет — Штурман скажет об этом и продолжит работать без него.

### ❤️ Пульс сессии

Сколько файлов затронуто, сколько команд выполнено, сколько ошибок встретилось,
сколько длится работа, приблизительный расход токенов. Рядом — «Куда смотрит
Клод»: последние файлы, которые он читал и правил.

### 🔔 Сигнал «Клод остановился»

Главная функция. Когда в работе Клода наступает тишина дольше 45 секунд
(порог настраивается) и он при этом договорил — Штурман:

1. показывает карточку в углу экрана,
2. подаёт короткий звуковой сигнал,
3. шлёт уведомление браузера (видно, даже если вкладка свёрнута),
4. меняет заголовок вкладки на «🔔 Клод ждёт».

Сигнал приходит **один раз** на каждую остановку — он не повторяется, пока
Клод не заработает снова.

> **Нажмите «🔔 Сигнал» в шапке при первом запуске.** Браузеры не дают
> проигрывать звук и слать уведомления, пока вы явно чего-нибудь не нажали.
> Эта кнопка одновременно разблокирует звук, спросит разрешение на
> уведомления и покажет, как сигнал выглядит.

### 🕰 Прошлые сессии

Список предыдущих запусков Claude Code в этой папке: когда, сколько длилась,
с какого вопроса началась. Клик открывает ленту старой сессии — можно
разобрать вчерашнюю работу спокойно.

### 📄 Итоги дня

Кнопка «📄 Итоги» собирает дневник в markdown: что вы просили, какие файлы
изменились, какие команды выполнялись, что пошло не так, какие новые слова
встретились. Можно скачать файлом.

## Штурман видит сам себя

Это не фигура речи, а способ проверить, что всё работает. Штурман целиком
написан в Claude Code — и по ходу работы он показывал в ленте собственную
сборку: как Клод читает `transcript-parse.js`, правит `humanize.js`, запускает
`node --test`, ловит красный тест и чинит его.

Проверить у себя: запустите Штурман в любой папке, откройте панель, а в другом
окне терминала попросите Клода что-нибудь сделать в этой же папке. Через пару
секунд его действия начнут появляться в ленте. Если появились — значит,
Штурман нашёл транскрипт и работает на полную (см. ниже про уровни).

## Два уровня работы

В шапке справа написано, на каком уровне сейчас панель.

**Уровень A — «видно всё».** Штурман нашёл транскрипт вашей сессии Claude Code
(`~/.claude/projects/…/*.jsonl`) и читает его в реальном времени. В ленте видны
все чтения, правки, команды и их результаты.

**Уровень B — «файлы и git».** Транскрипт не найден. Лента показывает
изменения файлов и события git, карта проекта, git-панель, словарь и пульс
работают как обычно — просто действия Клода в ленту не попадают.

Уровень выбирается сам и **переключается на лету**: если Клод запустится
позже, Штурман это заметит и перейдёт на A, сказав об этом в ленте.

Обычная причина уровня B — Штурман и Claude Code запущены в разных папках.
Сверьте путь в шапке панели с тем, откуда запущен `claude`.

## FAQ

**1. Штурман может что-нибудь испортить в моём проекте?**
Нет. Он не создаёт, не меняет и не удаляет файлы в наблюдаемой папке. Все
вызовы git проходят через белый список читающих команд (`status`, `log`,
`diff`, `show`, `rev-parse` и подобные) — `commit`, `add`, `checkout` и прочие
пишущие команды отвергаются самим кодом, а не полагаются на права доступа.
Это проверяется отдельным тестом: после полного прогона панели `git status`
в тестовом проекте остаётся пустым.

**2. Кто-то из локальной сети сможет увидеть мою панель?**
Нет. Сервер слушает только `127.0.0.1` — этот адрес недоступен снаружи
компьютера. Флага «слушать наружу» в Штурмане нет намеренно: панель показывает
содержимое ваших файлов и вывод команд. Если нужен доступ с другой машины —
пробросьте порт через `ssh -L 4517:127.0.0.1:4517 пользователь@машина`.

**3. Почему сигнал молчит, хотя Клод явно остановился?**
Три обычные причины. Во-первых, вы ещё не нажали «🔔 Сигнал» — до первого
нажатия браузер не разрешает звук. Во-вторых, панель может быть на уровне B:
без транскрипта не по чему определять затишье. В-третьих, порог по умолчанию
45 секунд — если Клод замолчал на полминуты, это ещё не остановка. Порог
меняется в «⚙️ Настройки».

**4. Точный ли счётчик токенов?**
Нет, и он честно подписан как приблизительный. Числа берутся из поля `usage`
в транскрипте — это то, что модель сообщила про свои ответы. С фактическим
счётом в вашем тарифе они могут расходиться, поэтому Штурман не показывает ни
денег, ни процентов от лимита: врать про чужие расходы хуже, чем промолчать.

**5. Панель пустая, в шапке «уровень B». Что делать?**
Сначала сверьте путь: в шапке панели написано, за какой папкой Штурман
следит, — он должен совпадать с папкой, где запущен `claude`. Если пути
совпадают, проверьте, что каталог `~/.claude/projects/` существует и в нём
есть подкаталог с файлами `.jsonl` (на Windows — `C:\Users\Вы\.claude\projects\`).
Если Claude Code настроен на другой каталог, укажите его переменной
`CLAUDE_CONFIG_DIR` перед запуском Штурмана. И в любом случае панель остаётся
полезной: карта проекта, git и словарь работают без транскриптов.

## Флаги командной строки

| Флаг | Что делает |
| --- | --- |
| `--project <путь>` | папка, за которой следим (по умолчанию — текущая) |
| `--port <номер>` | порт панели (по умолчанию 4517) |
| `--idle <секунды>` | через сколько тишины считать, что Клод ждёт (45) |
| `--debounce <мс>` | склейка событий файловой системы (220) |
| `--poll <мс>` | период пересканирования в резервном режиме (3000) |
| `--tail-only` | читать транскрипт с момента запуска, без истории |
| `--force-poll` | не пользоваться системным наблюдением за файлами |
| `--ask` | включить кнопку «Спроси Клода» (расходует ваши лимиты) |
| `--open` | открыть браузер сразу после запуска |
| `--quiet` | не печатать баннер |
| `--help` | справка |

### Необязательно: мгновенный сигнал через хук

Штурман определяет остановку по затишью в транскрипте — это работает без
всяких настроек, но с задержкой в несколько десятков секунд. Если хочется
получать сигнал в ту же секунду, можно добавить хук **вручную** в
`.claude/settings.json` вашего проекта (сам Штурман туда не пишет — он не
трогает ваши файлы):

```json
{
  "hooks": {
    "Stop": [{
      "hooks": [{
        "type": "command",
        "command": "curl -s -X POST http://127.0.0.1:4517/api/hook -d '{\"hook_event_name\":\"Stop\"}'"
      }]
    }]
  }
}
```

Панель примет сигнал и зазвонит немедленно. Без этого хука всё работает
по-прежнему — просто чуть позже.

### Необязательно: «Спроси Клода»

С флагом `--ask` в карточке события появляется кнопка «🤔 Спроси Клода»: она
отправляет контекст события в `claude -p` и показывает короткое объяснение
прямо в панели. **По умолчанию выключено** — функция расходует ваши лимиты, и
включать её за вас Штурман не станет.

## Как это устроено

Без зависимостей и без сборки: сервер на стандартной библиотеке Node.js,
клиент — один HTML-файл плюс ванильные JS и CSS.

```
shturman/
├── server.js              — точка входа: HTTP, маршруты, сборка приложения
├── lib/
│   ├── args.js            — флаги командной строки
│   ├── paths.js           — кроссплатформенные пути
│   ├── ignore.js          — что не показывать (node_modules, .git и т.п.)
│   ├── debounce.js        — склейка частых событий
│   ├── watcher.js         — наблюдение за файлами (fs.watch, резерв — опрос)
│   ├── transcript.js      — поиск и чтение транскриптов Claude Code
│   ├── transcript-parse.js— разбор JSONL, склейка вызов→результат
│   ├── git.js             — только читающие вызовы git
│   ├── git-parse.js       — разбор status, log, diff, numstat
│   ├── humanize.js        — перевод событий на человеческий русский
│   ├── filetypes.js       — «что это за файл» простыми словами
│   ├── glossary.js        — словарь терминов
│   ├── tree.js            — карта проекта
│   ├── bus.js             — шина событий и кольцевой буфер
│   ├── sse.js             — поток событий в браузер
│   ├── idle.js            — детектор «Клод остановился»
│   ├── stats.js           — пульс сессии
│   └── digest.js          — дневник в markdown
├── public/
│   ├── index.html         — разметка панели
│   ├── styles.css         — тёмная тема
│   └── app.js             — вся клиентская логика
└── tests/                 — 150+ проверок на node:test
```

Почему принято именно так — подробно в [DECISIONS.md](DECISIONS.md).
История изменений — в [CHANGELOG.md](CHANGELOG.md).

## Тесты

```bash
npm test          # или: node --test "tests/**/*.test.js"
```

Проверяются: разбор JSONL на реальных обезличенных фрагментах транскриптов,
разбор вывода git, перевод на человеческий язык (включая русские окончания
числительных), дебаунс, пути Windows и Unix, детектор остановки, дедупликация
событий, а также интеграционно — вотчер, git, HTTP и обещание «в проекте
ничего не изменено».
