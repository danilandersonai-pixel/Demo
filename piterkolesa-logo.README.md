# PITERKOLESA — SVG-логотип

Векторная версия логотипа, переведённая из растровых исходников (PNG) в SVG.
Внешний вид полностью соответствует оригиналу: те же формы, пропорции и цвета,
но края теперь идеально ровные и масштабируются без потери качества.

## Файлы

| Файл | Описание |
|------|----------|
| `piterkolesa-logo.svg` | Основной логотип, **прозрачный фон** (соответствует исходной картинке-обрезке). |
| `piterkolesa-logo-on-white.svg` | Тот же логотип на **белом фоне** с равномерными полями. |

## Цвета

- Чёрный: `#000000`
- Оранжевый: `#FD5406`

Спицы/диск колеса и внутренние просветы — это прозрачные области (negative
space), поэтому на белом фоне они выглядят белыми, а на прозрачном — пропускают
фон.

## Как сделано

Цветоразделённая трассировка (potrace) исходного PNG:

1. Изображение разложено на два слоя по цвету — полный силуэт (чёрный) и
   оранжевые области.
2. Каждый слой увеличен ×4 (LANCZOS) для субпиксельной точности границ и
   трассирован в гладкие кривые Безье.
3. Слои объединены: чёрный силуэт снизу, оранжевый поверх — без зазоров на
   стыках.

Результат проверен попиксельным сравнением с оригиналом (средняя разница ≈1.2 %,
расхождения только в 1px-сглаживании по краям).
