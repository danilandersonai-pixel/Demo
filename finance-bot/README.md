# 💰 Finance Bot — семейный учёт финансов в Telegram

Телеграм-бот для совместного учёта финансов на двоих: доходы и расходы,
загрузка чеков с распознаванием суммы (OCR), статистика с графиками,
бюджеты-лимиты и советы по экономии.

## Возможности

- ➕➖ **Приход и уход** — добавление операций по категориям в пару нажатий.
- 🧾 **Чеки с OCR** — пришлите фото чека, бот распознает сумму (Tesseract),
  останется лишь подтвердить категорию. Сумму всегда можно поправить вручную.
- 📊 **Статистика** — сводка доход/расход/баланс за сегодня/неделю/месяц/год/всё
  время и круговая диаграмма расходов по категориям.
- 🎯 **Бюджеты и лимиты** — месячный лимит на категорию, прогресс-бар,
  предупреждения при приближении (85%) и превышении лимита.
- 💡 **Советы по экономии** — анализ роста категорий, частых мелких трат,
  доли сбережений и крупнейших статей расходов.
- 👥 **Доступ для двоих** — бот пускает только Telegram ID из белого списка;
  учёт общий (оба видят и пополняют одну базу).

### 🤖 AI-режим (опционально, через OpenRouter)

Если задать `OPENROUTER_API_KEY`, включаются умные функции:

- 🗣 **Ввод текстом** — напишите «кофе 250» или «зарплата 50000 вчера», бот сам
  определит сумму, тип, категорию и предложит сохранить.
- 👁 **Умные чеки (vision)** — сумму, магазин и категорию с фото чека распознаёт
  vision-модель (точнее Tesseract); Tesseract остаётся как фолбэк.
- 💡 **Персональные советы** — рекомендации по экономии живым языком на основе
  ваших реальных трат.

Без ключа всё это просто выключено: бот работает на Tesseract и правилах.
Модель по умолчанию — `google/gemini-2.0-flash-001` (очень дёшево); меняется
через `OPENROUTER_MODEL`.

## Быстрый старт

### 1. Создайте бота

1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите **токен**.
2. Узнайте свой Telegram ID и ID второго пользователя у
   [@userinfobot](https://t.me/userinfobot).

### 2. Настройте окружение

```bash
cd finance-bot
cp .env.example .env
# отредактируйте .env: BOT_TOKEN и ALLOWED_USER_IDS (два ID через запятую)
```

### 3a. Запуск через Docker (рекомендуется)

Docker уже содержит Tesseract с русским языком — ничего ставить не нужно.

```bash
docker compose up -d --build
docker compose logs -f          # смотреть логи
```

База и чеки сохраняются в каталог `./data` (он смонтирован как volume).

### 3b. Запуск локально (Python)

Нужен установленный **Tesseract OCR** с русским языком:

```bash
# Debian/Ubuntu
sudo apt-get install tesseract-ocr tesseract-ocr-rus
# macOS
brew install tesseract tesseract-lang
```

Затем:

```bash
cd finance-bot
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m bot
```

> Без Tesseract бот продолжит работать, но при загрузке чека попросит ввести
> сумму вручную.

## Использование

- `/start` — главное меню.
- Кнопки **➕ Доход** / **➖ Расход** — добавить операцию.
- **Пришлите фото чека** — бот распознает сумму и предложит категорию.
- **📊 Статистика** — сводка и графики.
- **🎯 Бюджеты** — установить/удалить месячные лимиты.
- **💡 Советы** — рекомендации по экономии.
- **🧾 Последние операции** — список с командами `/del_<id>` для удаления.

## Архитектура

```
finance-bot/
├── bot/
│   ├── __main__.py        — запуск (python -m bot)
│   ├── main.py            — сборка Application, регистрация хендлеров
│   ├── config.py          — конфиг из .env
│   ├── database.py        — SQLite (aiosqlite): транзакции, бюджеты
│   ├── categories.py      — категории доходов/расходов
│   ├── keyboards.py       — инлайн-клавиатуры
│   ├── utils.py           — периоды, формат сумм, время
│   ├── handlers/          — диалоги и обработчики
│   │   ├── common.py      — авторизация, сохранение операции
│   │   ├── menu.py        — меню, помощь, последние, советы, удаление
│   │   ├── add_tx.py      — диалог добавления операции
│   │   ├── receipt.py     — диалог обработки фото чека (OCR)
│   │   ├── stats.py       — статистика и графики
│   │   └── budget.py      — бюджеты и лимиты
│   └── services/
│       ├── ocr.py         — распознавание суммы с чека
│       ├── charts.py      — круговые диаграммы (matplotlib)
│       └── advice.py      — аналитика и советы по экономии
├── requirements.txt
├── Dockerfile
├── docker-compose.yml
└── .env.example
```

Данные хранятся в SQLite (`data/finance.db`), фото чеков — в `data/receipts/`.
Учёт общий: операции от обоих пользователей попадают в одну базу.

## Безопасность

- Доступ строго по `ALLOWED_USER_IDS` — посторонние получают отказ.
- Секреты (`.env`) и данные (`data/`) исключены из git через `.gitignore`.
- Токен и база никуда не отправляются — всё крутится на вашем сервере.
