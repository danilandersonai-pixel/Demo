# CLAUDE.md — Кубокрафт

Руководство для работы с игрой в каталоге `minecraft/`. Это самостоятельный
проект: к свадебному сайту и к `ai-factory/` отношения не имеет.

## Что это

Воксельная песочница в духе Minecraft на чистом WebGL (WebGL2, с откатом на
WebGL1; шейдеры GLSL ES 1.0). Сборки, npm и внешних JS-библиотек нет. Снаружи
грузятся только Google Fonts (`Press Start 2P` и `Golos Text`) с фолбэками.
Весь контент — текстуры, облака, звуки — генерируется кодом при запуске.

## Команды

```bash
cd minecraft && python3 -m http.server          # превью → http://localhost:8000
for f in minecraft/js/*.js; do node --check "$f"; done   # проверка синтаксиса
```

Тестов и линтера нет. Живую проверку удобно делать через Playwright из
глобальной установки: Chromium в headless-режиме рисует WebGL через
SwiftShader с флагами
`--use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader`.
FPS там низкий (единицы кадров в секунду), поэтому скорость движения в тестах
не показательна. Из консоли доступен `KC.debug`: там есть `world`, `player`,
`state`, `play()`, `pause()` и `setTime(t)`.

## Архитектура

Скрипты подключаются по порядку и пишут в общий namespace `window.KC`:

| Файл | Отвечает за |
| --- | --- |
| `noise.js` | `KC.Noise` (n2, n3, fbm2), `mulberry32`, `hash2`/`hash3` |
| `blocks.js` | `KC.B` (id блоков), `KC.BLOCKS`, флаги `OPAQUE/SOLID/OCCLUDE/LIGHTBLOCK/CROSS`, атлас, иконки |
| `world.js` | `Chunk`, `World`: генерация, `getBlock/setBlock`, правки, `buildMesh` |
| `renderer.js` | `KC.Renderer`: программы, камера, отсечение по пирамиде видимости, `render(env)` |
| `game.js` | состояние, физика, ввод, подгрузка чанков, небо, частицы, звук, UI, сохранение |

Константы мира: `CS = 16`, `H = 96`, уровень моря `WL = 30`. Индекс блока в
чанке — `x + z*16 + y*256`. `hmap` — первая высота над верхним блоком,
перекрывающим небо (непрозрачные блоки и листва).

## Инварианты (важно при правках)

- **Генерация детерминирована и не зависит от порядка чанков.** Деревья
  соседних колонн считаются в запасной зоне `G = 3` блока, чтобы уклон у края
  совпадал с соседом. Ствол всегда перезаписывает листву, а листва ставится
  только в воздух. Если сломать это правило, на стыках чанков появятся кроны
  без стволов.
- **Правки игрока** хранятся отдельно (`world.edits`: `"cx,cz" → {индекс: id}`)
  и накладываются поверх генерации. Поэтому выгруженные чанки можно
  перегенерировать без потерь.
- **Мешер работает с паддингом** 18×18×(H+2): это копия чанка плюс соседи и
  слои сверху и снизу, поэтому проверки границ не нужны. Меш строится, только
  когда загружены все 8 соседей (`hasNeighbors`).
- **Грани** заданы в `FACES` осями U и V с условием `U×V = n`. Углы идут по
  CCW снаружи, работает отсечение задних граней. Диагональ квада проводится
  через более тёмную пару углов AO: для этого вершины сдвигаются на одну, общий
  индекс-буфер `0 1 2, 0 2 3` при этом не меняется.
- **Формат вершины:** 7 float (`x y z u v ao*shade sky`), константа
  `KC.FLOATS`. Итоговый свет считается в шейдере:
  `ao*(0.2 + 0.8*sky*day)`.
- **Проходы рендера:** небо → непрозрачные блоки и вырезанные (листва,
  стекло и растения с альфа-тестом) → частицы → облака → вода с сортировкой от
  дальних чанков к ближним → рамка выделения.
- **Радиусы подгрузки** (в чанках, `R` — дальность из настроек): меш строится
  до `R`, данные держатся до `R+1.5`, меш удаляется после `R+1.5`, данные —
  после `R+3.5`. Благодаря этому у каждого чанка с мешем есть все соседи.
- Первое действие мыши или сенсорной кнопки выполняется сразу по нажатию, а
  таймер в `updateActions` только повторяет его при удержании. Иначе короткий
  щелчок при низком FPS теряется.

## Соглашения

- Код в стиле ES5 внутри IIFE: `var`, объявления функций, `'use strict'`.
- Весь текст интерфейса на русском. Клавиши определяются по `e.code`, чтобы
  управление не зависело от раскладки.
- `localStorage` всегда оборачивается в `try/catch`. Ключи:
  `kubocraft.world.v1` (мир) и `kubocraft.settings.v1` (настройки). При смене
  формата сохранения нужно поднять версию в ключе.
- Интерфейс поддерживает `prefers-reduced-motion`: без частиц, без изменения
  FOV при беге, без облёта камеры на титуле.
- Новые блоки добавляются в `KC.B` и `BLOCKS`, плитка рисуется в `makeAtlas`
  (в атласе 64 места, занято 37), блок вносится в `INVENTORY`.
