## Задание 2 завершено целиком, включая все 4 бонуса

- №1 `--app`: отдельное окно без адресной строки (Chrome/Edge/Chromium,
  best-effort, фолбэк — обычный браузер).
- №2 «Подключённые устройства»: список живых SSE-подключений (💻/📱, IP,
  давность) на экране «Подключение», кнопка «Отозвать доступ» —
  rotate токена + обрыв чужих соединений (проверено: SSE оборван,
  старый токен → 403).
- №3 «Поделиться дайджестом»: navigator.share на телефоне, рядом с
  кнопкой скачивания.
- №4 `--tui`: живой статус в терминале, проверен на собственной сессии.

Финальная сверка перегнана после всех правок: 127 тестов, без --share
порт закрыт снаружи, обе раскладки без ошибок консоли, вкладка телефона
переживает перезагрузку.

## Известные ограничения

- Notification API и service worker на телефоне по http локальной сети не
  работают (ограничение браузеров) — сигнал дублируется звуком, вибрацией
  и бейджем; уведомления полноценны на localhost (Д-20).
- Оценка токенов приблизительная (Д-10), помечена «≈».
- «Спросить Клода» требует Claude Code CLI и расходует лимиты — выключено
  по умолчанию.
