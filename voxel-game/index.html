⛏ Воксель-мир

Мини-песочница в духе Minecraft. Чистый WebGL, без библиотек.

WASD — движение
Мышь — осмотр
Пробел — прыжок / вверх
Shift — бег / вниз
ЛКМ — сломать блок
ПКМ — поставить блок
1…9 / колесо — выбор блока
F — режим полёта
[ ] — дальность прорисовки
Esc — пауза

📱 На телефоне: левый джойстик — ходьба, правая часть экрана — обзор, кнопки справа — действия.

Нажми, чтобы начать.
