# HabitQuest — RPG-трекер жизни и привычек

Веб-приложение, которое превращает привычки и задачи в ролевую игру: выполняйте квесты, получайте опыт и золото, прокачивайте характеристики и покупайте себе награды. Вредные привычки и пропуски отнимают здоровье героя.

**Стек:** React 19 + TypeScript (strict), Tailwind CSS v4, Framer Motion, Lucide React, Vite. Бэкенда нет: всё состояние хранится в `localStorage` и сохраняется автоматически.

## Запуск

```bash
cd habitquest
npm install
npm run dev            # http://localhost:5173
```

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Dev-сервер с горячей перезагрузкой |
| `npm run typecheck` | Проверка типов TypeScript |
| `npm run build` | Production-сборка в `dist/` |
| `npm run build:single` | Всё приложение одним файлом `dist-single/index.html`, открывается без сервера |
| `npm run preview` | Просмотр production-сборки |

## Модули

1. **Персонаж (дашборд).** Имя, аватар-класс, уровень, полосы HP и XP, золото. Характеристики Сила / Интеллект / Дисциплина со своими уровнями и бонусами. Сводка дня, «горящие» квесты, дейлики на сегодня, летопись героя.
2. **Квесты.**
   - *Привычки* — многоразовые «+» и «−». «+» даёт XP и золото и всегда качает Дисциплину, «−» снимает HP. Опция «штраф за пропуск дня»: если за день ни разу не нажать «+», утром снимается половина урона.
   - *Дейлики* — обновляются раз в сутки, есть расписание по дням недели и серии (streak). Пропуск в запланированный день снимает HP и обнуляет серию. Выполнение можно отменить.
   - *Разовые квесты (to-do)* — сложность Легко / Средне / Эпично определяет награду; есть дедлайн и архив выполненных.
   - Быстрое добавление по Enter, полная форма, редактирование, удаление с подтверждением, перестановка.
3. **Магазин наград.** Свои награды с ценой и иконкой. Если золота не хватает, кнопка покупки заблокирована и показывает, сколько ещё нужно. Встроенное «Зелье здоровья» восстанавливает 15 HP.
4. **Журнал событий (Combat Log).** Лента внизу экрана с фильтрами: квесты, урон, покупки, повышения уровня, системные события.
5. **Настройки.** Симуляция нового дня (чтобы сразу увидеть механику дейликов), экспорт и импорт сохранения в JSON, сброс прогресса, справочник правил.

## Игровая механика

- **Уровни:** для 2-го уровня нужно 100 XP, дальше порог растёт на 25 (125, 150, 175…). Излишек опыта переносится. Новый уровень восстанавливает HP и даёт `уровень × 10` золота (только при первом достижении уровня).
- **Характеристики:** Сила — +5 к макс. HP и −2% урона за уровень (до 40%); Интеллект — +3% опыта за уровень; Дисциплина — +3% золота за уровень.
- **Криты:** шанс 10% получить награду ×1.5.
- **Серии дейликов:** +5% опыта за каждый день серии, максимум +50%.
- **Гибель:** при HP = 0 герой теряет уровень и 30% золота, затем возрождается с полным HP.
- **Смена суток** проверяется при запуске, каждые 30 секунд и при возвращении на вкладку.

Таблица наград по типам и сложности — в `src/game/constants.ts` (`REWARD_TABLE`).

## Дизайн-система

Стиль «Cyberpunk Web RPG Interface». Токены и общие классы — в `src/index.css`.

- **Фон:** космический `#0B0D17`, неоновая сетка из точек и линий, три медленно дрейфующих размытых пятна (фиолетовое, циановое, пурпурное).
- **Стекло:** `.glass` = `bg-white/[0.03] backdrop-blur-xl border-white/[0.08] shadow-2xl`; модалки — `.glass-strong`.
- **Индикаторы** (`ui/NeonBar.tsx`): HP `from-red-500 to-rose-600` пульсирует ниже 30%; XP `from-fuchsia-500 via-purple-600 to-indigo-600` показывает прибавку «наплывом»; золото (`GoldCounter`) — `from-amber-400 to-orange-500` с мерцающими искрами.
- **Карточки квестов:** полоса сложности слева (зелёная / синяя / фиолетовый неон), подъём и отблеск `.card-shine` при наведении, ромбовидные чекбоксы и круглые «+/−» со вспышкой.
- **Отдача:** кнопки сжимаются до 95% при нажатии, карточки появляются снизу при создании и смене вкладок, при повышении уровня вокруг профиля вспыхивает неоновая рамка (`LevelUpFlash`).
- **Шрифты:** Unbounded (заголовки), Exo 2 (текст), JetBrains Mono (все цифры).
- **Combat Log:** терминал с приглушённым зелёным текстом, тегами событий, построчной «печатью» и ультратонким скроллбаром.

## Архитектура

```
src/
├── types.ts                 — модель данных (GameState, задачи, события)
├── game/
│   ├── engine.ts            — игровой движок: чистые функции (state) → { state, events }
│   ├── constants.ts         — баланс, формулы прогрессии, подписи
│   ├── storage.ts           — загрузка/валидация/сохранение, экспорт/импорт
│   ├── seed.ts              — стартовые квесты и награды
│   ├── dates.ts, utils.ts   — даты игрового дня, склонения, id
│   └── icons.ts             — аватары, иконки наград и характеристик
├── hooks/useGame.ts         — связка движка с React: автосохранение, смена суток, эффекты
└── components/
    ├── ui/                  — кнопки, неоновые полосы, модалки, переключатели
    ├── layout/              — боковое меню, панель героя, журнал
    ├── dashboard/, quests/, shop/, settings/
    └── effects/             — всплывающие награды, экраны Level Up и гибели
```

Движок не знает о React и DOM: каждое действие игрока — чистая функция, которая возвращает новое состояние и список событий (запись в журнал, повышение уровня, гибель, всплывающие цифры). `useGame` применяет результат, сохраняет его в `localStorage` и превращает события в анимации. Всё, что читается из хранилища или импортируется из файла, проходит через `normalizeState`, поэтому повреждённые данные не ломают приложение.

Анимации учитывают системную настройку «уменьшить движение» (`MotionConfig reducedMotion="user"` плюс CSS-сброс).
