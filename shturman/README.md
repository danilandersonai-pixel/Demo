# ⛵ Штурман — панель-наставник для новичка в Claude Code

Вы запускаете Claude Code, он что-то печатает, файлы мелькают… и непонятно,
что вообще происходит? «Штурман» — локальная панель, которая работает рядом
с Claude Code и показывает **простым русским языком**:

- 🔍 что Клод делает прямо сейчас (читает, правит, запускает команды);
- 🗺 какие файлы есть в проекте и что только что менялось;
- 🌿 что происходит в git — без жаргона;
- 🔔 **когда Клод остановился и ждёт вас** — со звуком и уведомлением,
  чтобы можно было спокойно уйти за чаем и вернуться вовремя.

«Штурман» только наблюдает: он ничего не меняет в вашем проекте, git-команды
использует только читающие, а сервер слушает только ваш компьютер
(127.0.0.1) — наружу ничего не уходит. Интернет ему не нужен вовсе.

## Установка и запуск — 3 команды

Нужен только [Node.js](https://nodejs.org) версии 18 или новее (наверняка
уже стоит, раз работает Claude Code).

```bash
git clone <адрес-этого-репозитория>
cd shturman
node server.js --project /путь/к/вашему/проекту
```

Браузер откроется сам; если порт занят — «Штурман» сам возьмёт соседний
свободный. Адрес всегда виден в терминале (обычно <http://127.0.0.1:4517>).

Ещё удобнее:

- `npm install -g .` в папке shturman — и команда `shturman` работает в
  любой папке (а `npm start` — по-прежнему в папке пакета);
- `node server.js ярлыки` (или `shturman ярлыки`) создаст в текущей папке
  кликабельные **Штурман.bat** (Windows) и **Штурман.command**
  (macOS/Linux): дальше — просто двойной клик, без терминала;
- настройки (порт, последние проекты) сами живут в `~/.shturman.json`.

Полезные варианты запуска:

```bash
node server.js                      # наблюдать за текущей папкой
node server.js --project ~/my-app   # наблюдать за другой папкой
node server.js -p ~/a -p ~/b        # несколько проектов в одной панели
node server.js --share              # доступ с телефона (QR-код)
node server.js --no-open            # не открывать браузер самому
node server.js --port 4600          # явно выбрать порт
```

## Как открыть на телефоне

Сценарий: Claude Code пашет на компьютере, а вы лежите с телефоном.

1. На компьютере запустите «Штурман» с флагом `--share`:
   `node server.js --share` (или `shturman --share`).
2. В терминале появится QR-код (он же — на экране «📡 Телефон» в панели).
3. Убедитесь, что телефон в **той же Wi-Fi-сети**, что и компьютер.
4. Наведите камеру телефона на QR — откроется панель. Всё: лента, карта,
   git и сигнал «Клод ждёт» теперь в кармане. Вкладки внизу, свайп
   листает, словарь и карточки открываются шторкой снизу.
5. По желанию: «Добавить на главный экран» в меню браузера — «Штурман»
   станет похож на обычное приложение.

Не открывается? Частые причины: телефон в другой сети (мобильный
интернет вместо Wi-Fi), брандмауэр компьютера блокирует Node.js (разрешите
доступ в локальной сети), или роутер изолирует клиентов друг от друга
(режим «AP isolation» — выключите его или используйте другую сеть).

## Безопасность share-режима

- **Без `--share` наружу не видно ничего**: сервер слушает только
  127.0.0.1, с других устройств он недоступен в принципе.
- **С `--share`** каждый запрос обязан предъявить одноразовый токен —
  случайные 32 шестнадцатеричных знака, зашитые в ссылку из QR. Запрос без
  токена (или с неверным) получает отказ. Токен живёт, пока работает
  сервер: перезапустили — старая ссылка отозвана.
- Ссылку с токеном показывает только сам компьютер (экран «Подключение»);
  подключённый телефон раздать доступ дальше не может.
- Сервер в любом режиме **только читает** наблюдаемый проект: ни с
  телефона, ни с компьютера через панель нельзя ничего изменить.
- Не публикуйте ссылку с токеном за пределами домашней сети и не
  включайте `--share` в чужом/публичном Wi-Fi.

## Панель проверена на себе

Этот проект строил Claude Code — и «Штурман», едва научившись запускаться,
наблюдал за **собственной сессией сборки**: в ленте были видны все чтения,
правки и команды Клода, который в этот момент дописывал панель, пульс
считал его команды и токены, а карта подсвечивала файлы, которые он менял
секунду назад. Так что режим «смотрю, как Клод работает» — не теория,
а то, чем этот проект отлаживали.

## Сигнал «Клод остановился»

Главная функция для спокойствия: когда Клод заканчивает ход или надолго
замолкает, «Штурман» подаёт мягкий звуковой аккорд и (если разрешите)
показывает уведомление браузера — даже если вкладка не активна. Порог
тишины настраивается в «⚙ Настройки», там же есть кнопка «Проверить
сигнал». Уведомлениям нужно ваше разрешение — браузер спросит один раз.

## Два уровня зоркости

- **Уровень A** — если Claude Code вёл сессии в этой папке, «Штурман»
  читает его журналы (`~/.claude/projects/…`) и показывает полную картину:
  каждое действие, ошибки, токены, момент остановки.
- **Уровень B** — если журналов нет (или Claude Code ещё не запускался),
  панель всё равно полезна: живая карта файлов, лента изменений и git
  работают как обычно. Как только Claude Code начнёт сессию — «Штурман»
  сам переключится на уровень A.

Текущий уровень виден в шапке панели.

## FAQ — 5 частых вопросов

**1. «Штурман» может что-то сломать в моём проекте?**
Нет. Он ничего не пишет в вашу папку: файловая система — только чтение,
git — только читающие команды из фиксированного списка (`status`, `log`,
`diff` и подобные; `commit`, `push` и прочие изменяющие даже не могут быть
вызваны — это проверяется тестами). Единственное «действие» — опциональная
кнопка «Спросить Клода», и она тоже ничего не меняет в проекте.

**2. Мои данные куда-то отправляются?**
Никуда. Сервер слушает только 127.0.0.1 (ваш компьютер), внешних запросов
не делает, работает полностью офлайн. Закрыли терминал — всё остановилось.

**3. Панель пишет «уровень B» — что делать?**
Это значит, что журналы Claude Code для этой папки не нашлись. Проверьте,
что вы запустили «Штурман» с тем же путём проекта, в котором работает
Claude Code. Как только Клод начнёт сессию в этой папке, панель сама
переключится на уровень A — ничего перезапускать не нужно.

**4. Звука нет, уведомления не приходят.**
Зайдите в «⚙ Настройки» → «Проверить сигнал». Браузеры включают звук
только после первого клика по странице — просто щёлкните где-нибудь на
панели. Для уведомлений браузер должен спросить разрешение — если вы
запретили, разрешите уведомления для 127.0.0.1 в настройках сайта.

**5. Числа токенов — это точно?**
Нет, и панель этого не скрывает: это оценка по данным транскрипта
(значок «≈»). Она полезна, чтобы почувствовать масштаб («сессия уже
съела прилично»), но не для бухгалтерии — точные цифры знает только
биллинг Anthropic.

**6. Телефон не видит панель, хотя `--share` включён.**
Проверьте по порядку: телефон в той же Wi-Fi-сети (не на мобильном
интернете)? Брандмауэр на компьютере разрешает Node.js входящие
подключения в локальной сети? Ссылка открыта именно из свежего QR (после
перезапуска сервера старый токен не работает)?

**7. Почему на телефоне не приходят системные уведомления?**
Браузеры разрешают Notification API только на «защищённых» адресах
(https или localhost), а панель по локальной сети работает по http.
Поэтому на телефоне «Штурман» дублирует сигнал звуком, вибрацией и
бейджем «🔔» в заголовке — при открытой панели вы паузу не пропустите.
На самом компьютере (localhost) уведомления работают полноценно.

**8. Устанавливается ли «Штурман» как приложение?**
Да: на компьютере браузер предложит установку (иконка в адресной строке),
на телефоне — пункт «Добавить на главный экран». Если сервер выключен,
установленное приложение покажет не белый экран, а понятную страницу
«Сервер не запущен» с подсказкой, как его поднять.

## Бонусы

- **«Спросить Клода»** — у каждого события в деталях появляется кнопка
  «🤔 Спросить Клода, что это значит»: контекст события уходит в
  `claude -p`, короткое объяснение показывается прямо в панели. Это
  расходует ваши лимиты Claude, поэтому по умолчанию выключено —
  включается тумблером в «⚙ Настройки». Нужен установленный Claude Code
  CLI (команда `claude`). Единственный POST-запрос в приложении — и тот
  ничего не меняет в проекте.
- **Дайджест «Что мы сегодня сделали»** — в окне «🗓 Сессии» есть кнопка
  «📝 Скачать дайджест»: итоги сессии одним markdown-файлом (цифры,
  коммиты, хроника событий) — готовый дневник обучения.
- **Несколько проектов в одной панели** — укажите несколько папок:
  `node server.js -p ~/проект-один -p ~/проект-два`. В шапке появится
  переключатель; у каждого проекта своя лента, карта и git-панель, а
  сигнал «Клод остановился» работает для всех сразу и называет проект
  в уведомлении.
- **Мини-карта «Куда смотрит Клод»** — маленький граф над картой проекта:
  файлы, которые Клод недавно читал (синие) и правил (жёлтые), лучами от
  центра; след гаснет за пять минут. Одного взгляда хватает, чтобы понять,
  вокруг чего сейчас крутится работа. Клик по файлу — его карточка.
- **Подключённые устройства** — в share-режиме экран «📡 Телефон»
  показывает хозяину, кто сейчас смотрит панель (этот компьютер, телефоны
  по IP), и кнопку «🚫 Отозвать доступ»: токен меняется, старые ссылки и
  подключения мгновенно умирают.
- **`shturman --app`** — панель отдельным окном без адресной строки
  (если найден Chrome/Edge/Chromium) — ощущение обычного приложения.
- **`shturman --tui`** — компактный живой статус прямо в терминале:
  состояние Клода, счётчики, последние события. Для второго монитора или
  работы по SSH — браузер не нужен.

## Для любопытных: как это устроено

- Сервер — чистый Node.js (`node:http`), без единой обязательной
  зависимости; если рядом установлен `chokidar`, вотчер использует его,
  нет — работает собственный обходчик каталогов.
- Клиент — один `public/index.html` + ванильные JS/CSS, без сборки и CDN.
- Обновления летят в браузер через SSE (Server-Sent Events) с буфером
  последних событий — обновили страницу, а история на месте.
- Тесты: `node --test` в папке проекта (106 штук, фикстуры — реальные
  обезличенные фрагменты транскриптов в `tests/fixtures/`).
- Решения с обоснованиями — в `DECISIONS.md`, ход работы — в
  `PROGRESS.md`, история версий — в `CHANGELOG.md`.
