# «Твой урок» — модели LLM и себестоимость генерации презентаций

> Зафиксировано 23.07.2026 по итогам обсуждения. Цены за 1M токенов, курс ~80 ₽/$.

|---|---|---|

## Важные поправки к ТЗ v2 (раздел 5/8)

1. **`temperature` удалён из API** текущих Claude (Sonnet 5, Opus 4.8) — запрос с ним вернёт 400.
   Детерминированность схемы даёт structured output: `output_config.format` (json_schema)
   или `client.messages.parse()`. На Haiku 4.5 температура ещё работает.
2. **`maxLength` строк API не enforce'ит** — структуру/типы/enum гарантирует, строковые лимиты
   валидируются на клиенте (SDK) + наш пословный линтер (он всё равно точнее считает слова).
3. **Prompt caching** (нет в ТЗ): 5-слойный промпт (роль+профиль+ФГОС+схема) — стабильный
   префикс, `cache_control: {"type": "ephemeral"}` → повторные чтения ~0,1×. Batch API −50%
   для фоновой прегенерации.

## Себестоимость одной генерации

**Рабочий лист / конспект (~10 заданий):** ~3–4 ₽
(Sonnet 5 ~2,8 ₽ + судья Haiku ~0,8 ₽)

**Презентация 14–15 слайдов, стандарт (Kandinsky):** **~13 ₽**
| Компонент | ₽ |
|---|---|
| RAG по учебнику | ~0 |
| Outline (Sonnet 5: ~7K/1,2K ток.) | ~2 |
| Контент слайдов (Sonnet 5: ~12K вход с кэшем / ~6,5K выход) | ~7 |
| Судья 5 критериев + CoVe (Haiku) | ~2 |
| Ретраи 2–3 слайдов | ~2 |
| Картинки Kandinsky ×14 | 0 |

С YandexART вместо Kandinsky: +~21 ₽ → ~35 ₽ (убыточно на любом тарифе — только премиум/fallback).

**Презентация «премиум / на продажу»:** **~35–80 ₽**
- Текст на Opus 4.8: ~25–30 ₽
- Двойная валидация (методика + «интересность» для возраста): ~3 ₽
- Картинки: YandexART ×2 варианта с выбором ≈ 45 ₽ ИЛИ Kandinsky + VLM-проверка (Haiku vision) ≈ 7 ₽
- Анимации/переходы — НЕ пер-юнит затраты: разовая разработка мастер-шаблонов (PPTX only, PDF статичен)
- Продаваемое качество = + 5–10 мин ручной редактуры учителем

## Экономика vs тарифы

Выручка на генерацию: Стартовый 490₽/30 = 16,3 ₽ · Оптимальный 990₽/70 = 14,1 ₽ · Максимальный 1790₽/150 = 11,9 ₽.

Решения:
- Презентация списывает **2 кредита** (маржа ≥60% на всех тарифах, запас на конец интро-цены Sonnet 5).
- **Кэш картинок по хэшу промпта** — популярные темы генерятся тысячами учителей, платим один раз.
- Лимит картинок на free-тарифе (главный риск маржи — изображения, не текст).
