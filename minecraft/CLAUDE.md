# CLAUDE.md — Кубокрафт

Руководство для работы с игрой в каталоге `minecraft/`. Это самостоятельный
проект: к свадебному сайту и к `ai-factory/` отношения не имеет.

## Что это

Воксельная песочница в духе Minecraft с режимами выживания и творчества на
чистом WebGL (WebGL2, с откатом на WebGL1; шейдеры GLSL ES 1.0). Сборки, npm и
внешних JS-библиотек нет. Снаружи грузятся только Google Fonts с фолбэками.
Текстуры, модели и звуки генерируются кодом.

**Персонажи и мобы собственные.** Странник, упырь, костяной лучник, лесной паук,
а также свинья, бурёнка, овца и курица в своём стиле. Не копировать внешний вид
и имена персонажей Minecraft: Стива, Крипера, Эндермена, зомби в голубой
рубашке и так далее. Механики (крафт, руды, редстоун-подобная схемотехника)
брать можно, названия даём свои («искровая пыль», а не «редстоун»).

## Команды

```bash
cd minecraft && python3 -m http.server          # превью → http://localhost:8000
for f in minecraft/js/*.js; do node --check "$f"; done   # проверка синтаксиса
```

Тестов в репозитории нет. Проверять удобно двумя способами:

- **Node без браузера.** Для логики мира, симуляции и мобов загрузите модули с
  заглушками `window = global` и `document.createElement → { getContext: () =>
  null }`. Порядок: noise, textures, registry, world, models, entities, sim.
  Затем создайте `new KC.World(seed)`, вызовите `generate`, `Entities.init` и
  `Sim.init`. Случайные тики идут только в чанках с `mesh`, в тесте подставляйте
  `c.mesh = {}`.
- **Playwright** из глобальной установки. Chromium рисует через SwiftShader с
  флагами `--use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader`.
  FPS там низкий, а `dt` ограничен 0,1 с, поэтому игровое время идёт медленнее
  реального: ждите события через `waitForFunction`, а не таймером. Из консоли
  доступен `KC.debug` (`world`, `player`, `P`, `state`, `play`, `pause`,
  `open`, `close`, `setTime`, `setMode`, `save`).

## Архитектура

Скрипты подключаются по порядку и пишут в общий namespace `window.KC`:

| Файл | Отвечает за |
| --- | --- |
| `noise.js` | `KC.Noise` (n2, n3, fbm2), `mulberry32`, `hash2`/`hash3` |
| `textures.js` | `KC.TILE` (имя → индекс плитки), `makeAtlas` 256×256, `makeIcon`, `makeHudIcons`, трещины |
| `registry.js` | `KC.B`/`KC.I`, `BLOCKS`/`ITEMS`, флаги (`OPAQUE`, `SOLID`, `REPLACEABLE`…), `breakTime`, `drops`, `RECIPES`, `SMELT`, `matchRecipe` |
| `world.js` | `Chunk` (blocks + meta), `World` (генерация, `setBlock` с метаданными и правками, `collide`, `skyAt`, `blockLightAt`), мешер |
| `renderer.js` | программы блоков, сущностей, неба, облаков и линий; `render(env)`, отдельный проход для руки |
| `models.js` | коробочные модели с позами, `drawModel`, `drawBlockCube`, `drawSprite`, `Batch` |
| `entities.js` | `Ent`, физика (`move` со ступенькой 0,6), предметы, мобы (`KINDS`), ИИ, стрелы, динамит, падающие блоки, спавн |
| `sim.js` | тик: запланированные события, жидкости, опоры, случайные тики, печи, искровая сеть, поршни, взрывы, блок-сущности |
| `audio.js` | синтез звуков, `play(имя, x, y, z)` с затуханием и панорамой |
| `player.js` | `KC.Player`: движение, выживание, инвентарь (36 + 4 брони), добыча, бой, `use`, сон, рука и тело |
| `ui.js` | `KC.UI`: HUD и окна-контейнеры с курсором-стопкой, книга рецептов, палитра творчества |
| `game.js` | запуск, цикл (кадр + тики 20/с), управление, камера, подгрузка чанков, частицы, сохранение, меню |

Константы: `CS = 16`, `H = 96`, `WL = 30`. Индекс блока — `x + z*16 + y*256`.
Блоки имеют id от 0 до 255, предметы — от 256. Блок одновременно является и
предметом (`ITEMS[id].block`).

## Метаданные блоков (4 бита используются по-разному)

| Блок | meta |
| --- | --- |
| вода, лава | биты 0–2 — уровень (0 — источник), бит 3 — падающая |
| печь, сундук, тыквы, верстак, кровать | биты 0–1 — «взгляд» (0 +Z, 1 −X, 2 −Z, 3 +X); у печи бит 2 — горит |
| факел, искровой факел, рычаг, кнопка, лестница | биты 0–2 — направление на опору (порядок `DIRS`); бит 3 — «включено», у искрового факела — «погас» |
| поршень | биты 0–2 — направление (`DIRS`), бит 3 — выдвинут; головка хранит направление |
| дверь | биты 0–1 — взгляд, бит 2 — открыта, бит 3 — верхняя половина |
| провод | 0–15 — мощность сигнала |
| пшеница | 0–7 — стадия; пашня: бит 0 — влажная; лампа: бит 0 — горит |
| листва | бит 0 — берёза, бит 1 — поставлена игроком (не осыпается) |

Правки игрока хранятся как `id | meta << 8`. Порядок `DIRS`: 0 +X, 1 −X, 2 +Y,
3 −Y, 4 +Z, 5 −Z; противоположное направление — `d ^ 1`.

## Инварианты (важно при правках)

- **Генерация детерминирована и не зависит от порядка чанков.** Деревья
  соседей считаются в запасной зоне `G = 3`, ствол перезаписывает листву,
  листва ставится только в воздух.
- **Мешер** работает с паддингом 18×18×(H+2) и строит меш, только когда
  загружены все 8 соседей. Вершина — 8 float (`x y z u v тень небо свет`).
  Свет блоков — BFS в регионе 3×3 чанка от `chunk.emitterIndices()` в полосе
  высот вокруг светильников. Любое изменение рядом со светильником помечает на
  перестройку все 3×3 чанка.
- **Коллизии** считаются по коробкам (`World.collide`, `KC.collisionBox`),
  а не по целым клеткам: двери, кровати, сундуки и кактусы нестандартные.
  Выделение — по `KC.selectionBox`.
- **Слушатель `world.listener`** (его ставит `Sim`) реагирует на каждое
  изменение: планирует жидкости, проверку опор через тик, падение песка,
  блок-сущности и пересчёт искровой сети. `setBlock(..., quiet = true)`
  слушателя не зовёт — так делают сам `Sim` (мощность проводов, лампы, двери)
  и массовые правки в тестах.
- **Искровая сеть** пересчитывается в конце тика по `rsDirty`: провода вокруг
  изменений, мощность волной, затем приёмники. Искровой факел переключается с
  задержкой в 2 тика, поэтому «часы» не зависают.
- **Первое действие** (удар, установка) выполняется сразу по нажатию, таймеры
  лишь повторяют его при удержании. Кнопки, открывающие экраны на сенсоре,
  работают по `click`, а не по `pointerdown`: иначе догоняющий щелчок закроет
  окно.
- **Мобы** из выгружаемых чанков: мирные откладываются в `world.storedMobs`,
  враждебные удаляются. `world.animalChunks` не даёт заспавнить стадо повторно.

## Сохранение

Ключ `kubocraft.world.v2`. Внутри: `seed`, `mode`, `diff`, `edits`, `time`,
`tips`, `player` (позиция, здоровье, сытость, `inv`/`armor` как `[id, n, износ]`,
`spawn`), `bents` (печи и сундуки), `entities` (мирные мобы и предметы на
земле), `animalChunks`, `storedMobs`. Сохранение v1 (`kubocraft.world.v1`)
загружается как мир творчества. Настройки лежат в `kubocraft.settings.v1`.
`localStorage` всегда оборачивается в `try/catch`.

## Соглашения

- Код в стиле ES5 внутри IIFE: `var`, объявления функций, `'use strict'`.
- Весь текст интерфейса на русском. Клавиши определяются по `e.code`.
- Интерфейс поддерживает `prefers-reduced-motion`: без частиц, без изменения
  FOV, без облёта камеры на титуле.
- **Новый блок:** id в `KC.B`, `blk(...)` в `registry.js`, плитка в
  `textures.js`, при нестандартной форме — ветка в `emitShape` и коробки в
  `collisionBox`/`selectionBox`. **Новый предмет:** `item(...)` со спрайтом,
  рецепт через `shaped`/`shapeless`.
- **Новый моб:** запись в `KINDS` (`entities.js`), модель в `models.js`, поза в
  `buildRender`, голос в `audio.js`.
