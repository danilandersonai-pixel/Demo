# Прогресс

## Фаза 0 — каркас (готово)
- Изучены 3 референса, дизайн-система `~/vibefoundry-design`. Созданы `GDD.md`, `ART_BIBLE.md`, `PLAN.md`, `DECISIONS.md`.
- Vite 8 + TypeScript 7 (strict) + PixiJS 8.21 + Preact, Vitest 5, Playwright 1.60.
- Проверка: `npm run build` ✓, `npm test` ✓ (6 тестов), `npm run typecheck` ✓.

## Фаза 1 — мир (готово)
- Процедурный остров 256×256: симплекс-fbm + маска, пороги по квантилям высоты, реки, озёра, 15 биомов (включая красную зону и фиолетовую кристаллическую пустошь), месторождения 7 ресурсов, 14 точек «?», гнёзда врагов.
- Изометрия 2:1, чанки 32×32 с ленивой сборкой и отсечением, LOD-обзор на дальнем зуме, туман войны.
- Проверка: тест `worldgen.test.ts` (детерминизм, биомы, ресурсы у базы), скриншот в браузере.

## Фаза 2 — ядро Factorio (готово)
- Бур (2×2, выход на тайл перед собой), конвейеры (1 полоса, 4 слота/тайл, повороты, боковая подгрузка, пробки), подземные ленты, распределители (фильтры + round-robin), манипуляторы (цикл взять→повернуть→положить, берут только нужное зданию), плавильни (авто-рецепт по входу), сборочные цеха, химзаводы с нефтью из труб, склады, лаборатории.
- Энергосеть: столбы с радиусом соединения и зоной питания, сети как граф (union-find), 5 приоритетов, пропорциональное замедление при дефиците, аккумуляторы.
- Строительство призраками, строительные дроны летают с базы и забирают материалы со складов; снос ПКМ с возвратом материалов.
- Проверка: `tests/sim.test.ts` (руда→пластины→шестерни на реальных лентах, пробка, приоритеты при дефиците, сериализация), визуально в браузере.

## Фаза 3 — UI-оболочка (готово)
- Верхняя панель ресурсов с приростом/мин (как на изображении 2), день/время, скорости, настройки; задачи слева; мини-карта с рамкой обзора; панель инструментов (8 кнопок); меню строительства с миниатюрами, отрендеренными из процедурных текстур; панели тайла и здания; координаты + «Построить здесь»; тосты 4 типов; подсказки; главное меню и меню паузы; сохранения в IndexedDB (автосейв 60 с, 3 слота, экспорт/импорт JSON).
- Цепочка из 30 квестов через 4 эры с наградами и подсветкой кнопок в туториале.
- Проверка: реальный клик мышью по месторождению поставил призрак бура, дрон построил, квест «Первая добыча» закрылся с наградой (скриншот).

## Фаза 4 — FactoryScript (готово)
- Собственный лексер с INDENT/DEDENT, рекурсивный парсер → AST, интерпретатор с бюджетом операций (500 + 250 за эру), без `eval`/`new Function` (есть тест-сканер исходников).
- Язык: классы-агенты, `run`/`monitor`/`on_event`, `every = N`, if/elif/else, and/or/not, цепочки сравнений, in/not in, арифметика, локальные переменные, self-поля между запусками, списки/словари, for по коллекциям и range, while с бюджетом, тернарный оператор, литералы `30%`.
- API мира: `self.power/energy`, `stock`, `rate`, `consumption`, `buildings`, `count`, `time`, `is_night`, `alerts`; действия `enable/disable/shutdown`, `set_priority`, `route` (настраивает фильтры распределителей по достижимости через ленты и манипуляторы), `balance`, `set_recipe`, `limit`, `notify`, `dispatch`, `build`, `log`.
- Группы: именованные (рамкой), типы зданий, `<предмет>_production`, `<руда>_mining`, `all`. Неизвестные предметы/группы → предупреждение в логе агента (это и есть проявление галлюцинаций).
- Ошибки рантайма с номером строки → агент в статусе «Ошибка» + тост. Каждая операция тратит вычисления (с множителем техдолга).
- Проверка: 52 теста в `tests/script.test.ts` (парсинг, отступы, ошибки, бюджет, каждое действие API, сценарий из референса).

## Фаза 5 — вайб-панель, движок намерений, Git (готово)
- Офлайн-движок намерений RU+EN: нормализация, словари предметов/зданий/групп (с поправкой на то, что `\w`/`\b` в JS не видят кириллицу), разбиение на клаузы, условия (энергия с порогом/без, запас, скорость, ночь/день, враги), 31 шаблон намерений (`INTENT_TEMPLATES`), композиция нескольких правил в одном агенте.
- Кодогенератор: запрос №1 даёт ровно код с референса (тест сравнивает строку целиком), включая автоматический `EnergyManager`-монитор.
- Вайб-панель в 3 колонки как на изображениях 1/3: «Ты» (чат, адресат, примеры, стоимость в токенах), «AI Agent» (статус, чек-лист, код с подсветкой, дифф, уверенность, Принять/Редактировать/Отклонить/Песочница), «Версии / Git» + «Активные агенты» + «Ресурсы ИИ». В эре 1 — зелёный терминал.
- Git фабрики: коммиты с автором/тегом/диффом (LCS), теги Базовая/AI-оптимизация/Исправление бага/Катастрофа/Откат, rollback как новый коммит, полный снимок фабрики (стоит 4k контекста).
- Проверка: `tests/intent.test.ts` (10 обязательных запросов + 16 шаблонов + спец-намерения), `tests/vibe.test.ts` (критерий 4 целиком, токены, уточняющий вопрос, откат, дифф, техдолг, правка кода), клик «Принять» в браузере → v1.1.

## Фаза 6 — агенты, эры 1–2, галлюцинации, техдолг, Debugger (готово)
- 5 ролей + терминал, найм в AI Core за вычисления и токены, слоты по эрам, уровни/опыт, задачи с прогрессом и расходом вычислений, очередь задач, Orchestrator раскладывает цели на шаги.
- Галлюцинации: шанс = f(версия модели, заполнение контекста, техдолг, роль, уровень, исследования); 5 типов багов (неверный предмет, инверсия условия, дребезг, несуществующая группа, забытый else), которые проявляются в фабрике, а не подсвечиваются.
- Техдолг: +4…6 за принятие без песочницы, +1 с песочницей, 0 при зелёных CI-тестах, −15 за рефакторинг Optimizer'а; повышает шанс багов и расход вычислений на операции скриптов.
- Debugger сканирует каждые 30 с (по предупреждениям рантайма, дребезгу, статике), тост «⚠ Агент обнаружил ошибку в производственной цепочке» с «Показать» и «Предложить фикс».
- Катастрофа: падение производства > 40 % за минуту после коммита → автотег и тост «Rollback to vX», шанс бунта дронов.
- Песочница: два headless-клона (текущий код и ветка) 90 с по кускам без фриза UI, прогноз «Микросхемы: 84 → 112/мин», энергия, CI-тесты.
- Окно агентов с процедурными портретами-роботами и линией «Развитие ИИ».
- Проверка: `tests/vibe.test.ts` (5 типов мутаций, баг → Debugger → фикс → тег fix, песочница не трогает реальную фабрику и улучшает энергию), скриншоты.

## Фаза 7 — исследования, квесты, дроны, эра 3, Architect (готово)
- 51 технология в 4 пакетах, окно-дерево с узлами и связями, выбор цели ставит в очередь недостающие пререквизиты.
- 30 квестов через 4 эры (тест проверяет ≥ 25), первый в эре 1 подсвечивает нужную кнопку.
- 5 типов дронов: строительные, рабочие-разведчики (экспедиции к «?» с наградой), логистические (доставка сырья голодным цехам, разгрузка забитых выходов), инженеры (ремонт), боевые (атака врагов); сборка в окне «Логистика и дроны», автоматическая разведка.
- Architect: параметрическая линия (N цехов по рецепту и целевой скорости, ленты, манипуляторы, ЛЭП, трубы для химии), вставка призраками туда, куда укажет игрок, или рядом с базой; `build()` в скриптах.

## Фаза 8 — песочница/CI, угрозы, эра 4, Шпиль, финал, «Настоящий ИИ» (готово)
- CI-станция: тесты производства (скорость ≥, запас ≥, «энергия никогда не ниже X%»), панель в здании и запрос на естественном языке; проверка в песочнице; зелёные тесты = 0 техдолга.
- Угрозы: гнёзда в красной зоне, волны растут от загрязнения, техдолга и катастроф; турели, боевые дроны, автовосстановление призраками; бунт дронов после катастрофы до отката; мирный режим.
- Эра 4: автопилот Orchestrator'а (сам пишет и принимает скрипты), Индекс автономии, Шпиль Колонии, победа при автономии ≥ 90 % 10 минут → экран «От фабрики к цивилизации» с ночным видом колонии.
- Кат-сцены смены эр.
- «Настоящий ИИ»: официальный `@anthropic-ai/sdk` в браузере (`dangerouslyAllowBrowser`, заголовок direct-browser-access), модели Claude Haiku 4.5 (по умолчанию) / Sonnet 5 / Opus 5 (с серверными fallback'ами), системный промпт с грамматикой и сводкой фабрики, ответ проходит парсер, одна попытка самоисправления, затем офлайн-движок; ключ только в localStorage; SDK грузится отдельным чанком.
- Проверка: `tests/progression.test.ts` (эры 1→4, найм, автопилот, реактор, победа), `tests/vibe.test.ts` (отложенная LLM-генерация без сети, ключ не попадает в сохранение).

### Производительность (стресс-тест)
`tests/stress.bench.test.ts` строит 2001 здание (сборочные цеха + манипуляторы + столбы + реакторы) и 6240 лент с 10 000 предметов:

| Замер | Результат |
|---|---|
| Симуляция (Node, 600 тиков) | 1.58 мс/тик → запас ~630 UPS |
| Кадр в браузере до оптимизации | ближний 16.8 мс, средний 15.6 мс, дальний 28.6 мс |
| После: слои как независимые render groups Pixi | 4.5 / 14.4 / 9.7 мс |
| После: кадры лент и иконки предметов в общем атласе | **3.3 / 6.6 / 7.1 мс** (sim + обновление + отрисовка) |

Причина исходных тормозов: подмена текстур из разных источников (анимация лент, пул спрайтов предметов) заставляла Pixi v8 пересобирать инструкции всего мира (≈20 тыс. тайлов) каждый кадр. Итог: 60 FPS на стресс-тесте с запасом ×2.
