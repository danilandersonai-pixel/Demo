# Городок — веб-стратегия по мотивам TownsFolk

Фанатская браузерная реализация игровых механик мобильной игры
**TownsFolk** (Short Circuit Studio / MWM, iOS). Весь код, пиксель-арт
(рисуется процедурно на canvas) и тексты — оригинальные; из первоисточника
взяты только идеи механик.

## Как играть

```bash
cd townsfolk-game && python3 -m http.server
# → http://localhost:8000
```

Или просто открыть `index.html` в браузере — сборка и сервер не нужны.

## Механики (как в оригинале)

- **Туман войны.** Карта 13×13; террейн соседних клеток виден, но что на них —
  неизвестно, пока разведчик (занимает жителя на 1–2 дня) не сходит туда.
  Под туманом: клады, руины со знаниями, бонусные земли или дикие звери.
- **4 ресурса**: еда 🍞, производство ⚒️, золото 🪙, вера ✨ + жители 👥
  и очки знаний 🔬.
- **Стройка по террейну**: фермы/дома/церкви/рынки/таверны — на лугах,
  лесопилки — в лесу, шахты — только в горах, причалы — на воде.
- **Дань короне** каждые 12 дней, растёт с каждым разом. Можно трижды взять
  отсрочку (+25% к спросу). Нечем платить и отсрочек нет — колония потеряна.
  Выплатить 5 даней — победа.
- **Дерево технологий**: 8 технологий, каждое следующее открытие дороже в 1,5 раза.
- **Случайные события**: пожары, засухи, караваны, странники, моральные дилеммы.
- **Рогалик**: каждая партия — новая случайная карта.

## Файлы

- `index.html` — разметка и модальные окна
- `style.css` — интерфейс (тёмная «пиксельная» тема, мобильный портрет)
- `game.js` — вся логика одним IIFE без зависимостей; спрайты 16×16
  рисуются на offscreen-canvas при старте
