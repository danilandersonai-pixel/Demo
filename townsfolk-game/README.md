# Городок — веб-стратегия по мотивам TownsFolk

## Установка как приложение (PWA)

Игра — полноценное приложение: ставится на домашний экран, работает
на весь экран без браузера и **офлайн** после первого запуска.

- **iPhone/iPad**: откройте игру в Safari → кнопка «Поделиться» →
  «На экран “Домой”» → «Добавить». На домашнем экране появится иконка
  «Городок».
- **Android**: Chrome сам предложит «Установить приложение», либо
  меню ⋮ → «Добавить на главный экран».
- **Компьютер**: Chrome/Edge — значок установки в адресной строке.

Прогресс сохраняется автоматически. Деплой: push в ветку игры публикует
свадебный сайт в корень GitHub Pages, а игру — в подпапку `/game/`
(см. `.github/workflows/deploy-game.yml`).


Фанатская браузерная реализация игровых механик мобильной игры
**TownsFolk** (Short Circuit Studio / MWM, iOS). Весь код, пиксель-арт
(рисуется процедурно на canvas) и тексты — оригинальные; из первоисточника
взяты только идеи механик.

## Как играть

```bash
cd townsfolk-game && python3 -m http.server
# → http://localhost:8000
```

Или просто открыть `index.html` в браузере — сборка и сервер не нужны.

## Механики и стиль (как в оригинале)

- **Изометрическая карта** из пользовательского ассет-пака: ромбические
  тайлы с «толщиной» (луга, холмы, лес, горы, озеро), месторождения
  (золотая жила, рыбное место, строевой лес) и детальные постройки.
  Анимации: блики на воде, покачивающиеся «?» над туманом, песочные часы
  разведки, дым очагов, всплывающие цифры добычи.
- **Туман войны.** Карта 11×11; террейн соседних тайлов виден, но что на них —
  неизвестно, пока разведчик (занимает жителя на 1–2 дня) не сходит туда.
  Под туманом: клады, руины со знаниями, бонусные земли или дикие звери.
- **4 ресурса**: еда 🍞, производство ⚒️, золото 🪙, вера ✨ + жители 👥
  и очки знаний 🔬.
- **Стройка по террейну**: фермы/дома/церкви/рынки/таверны — на лугах,
  лесопилки — в лесу, шахты — только в горах, причалы — на воде.
- **Дань короне** каждые 12 дней, растёт с каждым разом. Можно трижды взять
  отсрочку (+25% к спросу). Нечем платить и отсрочек нет — колония потеряна.
  Выплатить 5 даней — победа.
- **Дерево технологий**: 8 технологий, каждое следующее открытие дороже в 1,5 раза.
- **Случайные события**: пожары, засухи, караваны, странники, моральные дилеммы.
- **Рогалик**: каждая партия — новая случайная карта.

## Файлы

- `index.html` — разметка и модальные окна
- `style.css` — интерфейс (тёмная «пиксельная» тема, мобильный портрет)
- `game.js` — вся логика одним IIFE без зависимостей; изометрический
  рендер с порядком художника по диагоналям
- `assets.js` — нарезанные из ассет-листа спрайты (data-URI)
- `manifest.webmanifest`, `sw.js`, `icons/` — PWA: манифест, офлайн-кэш,
  иконки приложения
