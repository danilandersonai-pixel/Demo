# AI-Factory: Automation Sandbox

Экономическая песочница-автоматизация в духе Factorio. Вы — главный инженер
завода ИИ-продуктов: добываете сырые данные, превращаете их в чистый код,
обучаете модели на GPU и продаёте их через SaaS-терминалы и суперкомпьютеры
AGI. Цель — фабрика, которая зарабатывает сама, без единого клика.

Стек: **React 19 · Tailwind CSS 4 · Framer Motion · Lucide React · TypeScript · Vite**.

## Как запустить

**Просто поиграть.** Откройте файл [`play.html`](play.html) в браузере — это
готовая сборка одним файлом, сервер и интернет не нужны (без интернета
шрифты заменятся системными).

**Разработка.**

```bash
cd ai-factory
npm install
npm run dev          # http://localhost:5173 с горячей перезагрузкой
npm test             # юнит-тесты движка + балансовая симуляция
npm run build:play   # проверка типов, сборка и обновление play.html
```

## Что на экране

| Модуль | Что делает |
| --- | --- |
| **Цех** (MOD-04) | Сетка 8×8: сначала открыта площадка 6×6, внешнее кольцо — после «Расширения цеха». Клик по пустой ячейке — меню постройки, клик по зданию — панель управления, улучшения, переноса и сноса. Неоновые ленты между соседями — прямые конвейеры. |
| **Склад** (MOD-01) | Запасы данных, кода и моделей с заполнением склада, энергия, вычисления и кредиты. Рядом с каждым ресурсом — дельта в секунду и разбивка ▲ выработка / ▼ расход / ⇄ продажа. |
| **Энергосеть** (MOD-02) | Нагрузка против генерации. Перегрузка обесточивает весь цех. |
| **Техдолг** (MOD-03) | «Мусор» в Блоках вайбкодинга и кнопка «Запустить ИИ-рефакторинг». |
| **НИОКР / Рынок / Рекорды** | Дерево из 15 технологий, график цены и биржа сырья, рекорды и 15 контрактов-целей. |
| **Журнал смены** | Лента событий: стройка, аварии, рынок, исследования. |

Управление: **Пробел** или **P** — пауза, **1 · 2 · 3** — скорость ×1/×2/×4,
**Esc** — закрыть окно или отменить перенос.

## Механики

- **Игровой цикл.** 1 тик = 1 секунда реального времени (×2 и ×4 ускоряют).
  Всё распределение считается от запасов на начало тика: дефицитный ресурс
  делится между потребителями пропорционально спросу, поэтому порядок зданий
  ничего не решает.
- **Логистика.** Общий склад с вместимостью; полный склад останавливает
  производителей. Хранилище даёт +100% базовой вместимости за уровень,
  «Холодное хранилище» удваивает всё. Сосед-поставщик нужного ресурса даёт
  +10% скорости (до +40%) — раскладка цеха имеет значение.
- **Энергосеть.** Каждое включённое здание тянет мегаватты. Нагрузка больше
  генерации — блэкаут всей фабрики. После «Умной энергосети» цех вместо этого
  замедляется пропорционально. Иногда случается «Квантовая нестабильность»:
  реакторы теряют 25% мощности, так что держите запас.
- **Вычисления.** GPU-кластеры дают PFLOPS для обучения и AGI; нехватка
  замедляет их пропорционально. Мощность делится по реальной загрузке: AGI без
  моделей или кластер без данных не отнимают PFLOPS у тех, кто может работать.
- **Техдолг.** Работающий Блок вайбкодинга набирает 21 п. п. долга в минуту;
  при 100% его КПД падает до 40%. Рефакторинг чистит все блоки сразу, «Код-ревью
  ботами» вдвое замедляет рост долга, «CI/CD-конвейер» чистит блоки сам.
- **Рынок.** Цена модели ≈ $300 × медленный индекс × хайп-волна × события
  («ИИ-лихорадка» ×1,6, «Утечка весов» ×0,65 и другие). Биржевой автомат
  сбывает текущие излишки данных и кода, не трогая резерв 25% вместимости и
  старые запасы, а при включённой автопродаже полный склад не останавливает
  выработку.
- **НИОКР.** Кредиты списываются сразу, чистый код лаборатория забирает по
  ходу работы наравне с Кластерами обучения — во время большого исследования
  производство честно проседает.
- **Улучшения Mk.I → Mk.X.** +50% выпуска и +30% энергии за уровень, цена
  улучшения удваивается. Перенос здания бесплатный, снос возвращает 50%.
- **Сохранения и офлайн.** Фабрика сохраняется в `localStorage` каждые 5 секунд
  и при закрытии вкладки. Пока игра закрыта, завод работает до 4 часов (кроме
  режима паузы) — при возвращении появляется отчёт.
- **Рекорды.** «Максимальный пассивный доход» (среднее за 10 с) и «Узлов
  запущено за всё время» хранятся отдельно и переживают сброс фабрики. Новый
  рекорд отмечается салютом. Накрутить их нельзя: в доход для рекорда продажа
  моделей идёт не больше их текущего выпуска (распродажа склада приносит деньги,
  но не рекорд), а узел засчитывается только после 30 секунд работы.

## Баланс

Базовые рецепты (Mk.I, без исследований и соседства):

| Здание | Вход → выход | Энергия | Цена | Рост цены |
| --- | --- | --- | --- | --- |
| Квантовый реактор | +24 МВт | — | $250 | +22% |
| Генератор сырых данных | → 3 ТБ/с | 3 МВт | $60 | +15% |
| Блок вайбкодинга | 3 ТБ → 2 KLOC/с | 5 МВт | $220 | +16% |
| GPU-кластер | +10 PFLOPS | 6 МВт | $500 | +18% |
| Кластер обучения LLM | 2 ТБ + 3 KLOC + 5 PFLOPS → 0,2 модели/с | 10 МВт | $1 200 | +18% |
| Экспортный терминал SaaS | продаёт до 0,4 модели/с | 4 МВт | $900 | +20% |
| Хранилище | +100% вместимости склада | 1 МВт | $400 | +30% |
| Суперкомпьютер AGI (2×2) | до 0,5 модели/с по цене ×10, 30 PFLOPS | 50 МВт | $1,5 млн | +50% |

Цепочка устроена так, что каждая ступень добавляет стоимость: единица данных
на бирже стоит $1, переработанная в код — около $3,3, в модель — около $9,
а через AGI — около $90. Числа проверены ботом-симуляцией в
`src/game/balance.test.ts`: «средний толковый игрок» делает первую продажу
примерно через минуту, выходит на $1 000/с к 15-й минуте, открывает цех 8×8
к 20-й, строит AGI примерно ко второму часу и закрывает всё дерево технологий
за 2,5 часа. Если меняете числа в `src/game/config.ts`, запускайте `npm test` —
тест упадёт, если темп игры заметно уедет.

## Устройство кода

```
ai-factory/
├── play.html               — готовая сборка одним файлом (npm run build:play)
├── index.html              — точка входа Vite для разработки
└── src/
    ├── game/               — движок без React
    │   ├── config.ts       — весь баланс: здания, рецепты, исследования, события
    │   ├── engine.ts       — тик симуляции, потоки, действия игрока
    │   ├── selectors.ts    — формулы и чтение состояния (цены, скорость, соседство)
    │   ├── goals.ts        — контракты-цели
    │   ├── records.ts      — рекорды и рубежи
    │   ├── save.ts         — localStorage с проверкой сохранений
    │   ├── engine.test.ts  — юнит-тесты механик
    │   └── balance.test.ts — бот-симуляция темпа игры
    ├── hooks/useGame.ts    — игровой цикл, автосейв, офлайн-прогресс, тосты
    ├── components/         — модули экрана (цех, склад, энергосеть, НИОКР…)
    └── ui/                 — панели, шкалы, модалки, иконки
```
