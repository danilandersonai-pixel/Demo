# CyberNet: Neon Syndicate

Микро-стратегия про управление ресурсами в стиле хакерского терминала. Вы руководите
подпольным синдикатом: строите солнечные панели, майнинг-фермы и серверные стойки,
изучаете технологии, отбиваетесь от хакеров и налоговой и стараетесь продержаться
как можно дольше, не обанкротившись.

**1 секунда = 1 игровой день.** Прогресс и рекорды сохраняются в браузере сами.

## Как запустить

### Сразу, без установки

Вся игра собрана в один файл `standalone/index.html` — его можно открыть в браузере
двойным кликом или по ссылке-превью:

```
https://raw.githack.com/danilandersonai-pixel/Demo/claude/cybernet-neon-syndicate-dazld5/cybernet-neon-syndicate/standalone/index.html
```

### Для разработки

Нужен Node.js 22+.

```bash
cd cybernet-neon-syndicate
npm install
npm run dev            # http://localhost:5173 — горячая перезагрузка
```

| Команда | Что делает |
| --- | --- |
| `npm run dev` | локальный сервер разработки |
| `npm run typecheck` | проверка типов TypeScript |
| `npm run build` | обычная сборка в `dist/` |
| `npm run build:standalone` | вся игра одним файлом в `standalone/index.html` |
| `npm run sim` | headless-симуляция баланса ботами (без браузера) |

## Правила коротко

- **Кредиты** — главная валюта. Их добывают майнинг-фермы. Каждый день списывается
  содержание зданий и накладные расходы, а инфляция их медленно растит.
- **Данные** генерируют серверные стойки. Нужны для исследований и дорогих построек.
  Хранилище ограничено; лишнее можно продать на дата-бирже по плавающему курсу.
- **Энергия** копится в хранилище. Потребителя нельзя построить без свободной мощности.
  Если запас упадёт до нуля — блэкаут: производство стоит, а содержание списывается.
- **Сетка сектора 6×6.** ИИ-Оптимизатор даёт +15% всем 8 соседним ячейкам — раскладка
  имеет значение. Здания улучшаются до 5 уровня, их можно отключать и демонтировать.
- **Каждые 30 дней** — глобальное событие: хакерская атака, солнечная вспышка, налоговая
  проверка, буря, обвал рынка и другие (всего 16). В пяти из них нужно выбрать ответ за
  10 дней, иначе сработает вариант по умолчанию.
- **Банкротство:** кредиты в минусе 5 дней подряд — игра окончена. Рекорды дней и
  капитала попадают в Зал славы; при побитии рекорда загорается неоновое уведомление.

Горячие клавиши: `Пробел` — пауза, `1` `2` `3` — скорость 1×/2×/4×, `H` — справка.

## Как устроен код

```
src/
├── game/                 — игровое ядро, без React (можно гонять в Node)
│   ├── config.ts         — все числа баланса, здания, исследования
│   ├── economy.ts        — выработка, множители, прогноз следующего дня
│   ├── rules.ts          — проверки «можно ли построить/улучшить/…» с причиной
│   ├── events.ts         — 16 событий и решения по ним
│   ├── engine.ts         — reducer: тик дня и все действия игрока
│   ├── storage.ts        — сохранение/загрузка localStorage с защитой от битых данных
│   └── rng.ts, format.ts, mutators.ts, types.ts
├── hooks/                — игровой таймер (useEffect + setInterval), автосохранение
└── components/           — 4 модуля командного центра, модальные окна, UI-примитивы
scripts/simulate.ts       — симуляция баланса ботами
```

Reducer — чистая функция: случайность идёт из сидированного генератора, семя которого
хранится в состоянии. Поэтому одинаковое состояние и действие всегда дают одинаковый
результат, а баланс можно проверять автоматически (`npm run sim`).

Стек: React 19, TypeScript, Vite, Tailwind CSS 4, Framer Motion, Lucide React.
