# Кубокрафт

Воксельная песочница в духе Minecraft прямо в браузере. Бесконечный
процедурный мир, в котором можно копать, строить и летать. Написана на чистом
WebGL, без библиотек, без сборки и без npm: текстуры и звуки генерируются
кодом, внешних картинок и аудиофайлов нет.

## Как запустить

```bash
cd minecraft && python3 -m http.server   # → http://localhost:8000
```

Можно открыть `index.html` и напрямую из файловой системы. Скрипты подключены
обычными `<script>`, без ES-модулей, поэтому `file://` тоже работает.

## Что есть в игре

- **Бесконечный мир.** Мир состоит из чанков 16×16×96 и подгружается вокруг
  игрока. У каждого мира свой сид.
- **Ландшафт и биомы:** равнины и леса (дуб и берёза), пустыни с кактусами и
  песчаником, заснеженные горы и тундра, моря, пляжи, пещеры-тоннели и гроты,
  уголь и железо в камне, трава, маки и одуванчики.
- **31 блок** в инвентаре, в том числе стекло, книжные полки, шерсть пяти
  цветов, золото и обсидиан.
- **Строительство:** можно ломать и ставить блоки, взять блок средней кнопкой
  мыши, удерживать кнопку для серии действий. На месте разбитого блока летят
  частицы, звук зависит от материала.
- **Движение:** ходьба, бег, прыжок, плавание, полёт и автопрыжок на
  ступеньки.
- **Свет и небо.** Грани затеняются в углах (ambient occlusion), а под
  перекрытиями, в пещерах и под кронами темнее. Сутки длятся 20 минут:
  квадратные солнце и луна, звёзды, закат, плывущие облака, туман на
  горизонте, синий оттенок под водой.
- **Сохранение.** Правки мира, позиция, время суток и хотбар автоматически
  сохраняются в `localStorage` этого браузера.
- **Телефон:** джойстик, осмотр свайпом, кнопки «Сломать», «Поставить»,
  «Прыжок» и «Полёт».

## Управление

| Действие | Клавиатура и мышь | Сенсорный экран |
| --- | --- | --- |
| Ходьба | `W` `A` `S` `D` / стрелки | джойстик слева |
| Осмотр | мышь (после щелчка по экрану) | свайп справа |
| Прыжок / вверх в полёте | `Пробел` | кнопка «вверх» |
| Бег / вниз в полёте | `Shift` | джойстик до упора вперёд / кнопка «вниз» |
| Полёт | `F` или двойной `Пробел` | кнопка с двойной стрелкой |
| Сломать блок | ЛКМ (удержание повторяет) | «Сломать» |
| Поставить блок | ПКМ | «Поставить» |
| Взять блок в руку | СКМ | — |
| Выбор блока | `1`–`9`, колесо | тап по хотбару |
| Все блоки | `E` | кнопка с сеткой |
| Координаты и FPS | `F3` | в настройках паузы |
| Пауза и настройки | `Esc` | кнопка паузы |

Если браузер не даёт захватить указатель мыши, игра сама переходит на
осмотр перетаскиванием.

## Устройство

```
minecraft/
├── index.html      — разметка: титул, HUD, пауза, инвентарь, сенсорные кнопки
├── style.css       — интерфейс поверх 3D-мира
└── js/
    ├── noise.js    — шум Перлина 2D/3D, ГПСЧ и хеши с сидом
    ├── blocks.js   — таблица блоков, процедурный атлас 16×16, иконки
    ├── world.js    — чанки, генерация ландшафта, правки игрока, мешер
    ├── renderer.js — WebGL: блоки, вода, небо, облака, частицы, рамка
    └── game.js     — игрок, физика, управление, подгрузка, звук, меню
```

Подробности для разработки описаны в [`CLAUDE.md`](CLAUDE.md).
