# Vibe Coding Journal

Одностраничный ежедневник вайб-кодинга. Никакого backend — данные хранятся в `localStorage` браузера.

## Запуск

Открой `index.html` в браузере. Всё.

Если нужен локальный сервер (например, чтобы избежать ограничений `file://`):

```bash
python3 -m http.server 8000
# открой http://localhost:8000
```

## Что внутри

- **Что кодил + инсайты** — главное поле для рефлексии дня.
- **Удачные AI-промпты** — коллекция промптов с заголовком и телом, можно добавлять сколько угодно.
- **Теги** — через запятую, используются для поиска.
- **Поиск** — по дате, тексту, тегам и промптам.
- **Экспорт / импорт** — JSON-бэкап. Импорт мёржит по `id`.

## Файлы

- `index.html` — разметка и шаблоны.
- `styles.css` — тема.
- `app.js` — логика, хранилище, рендер.
