# Бриф матча

Лендинг для студии свадебной флористики, стиль — ботанический люкс.

- Одностраничный статический сайт: чистые HTML/CSS/JS, без сборки и внешних библиотек.
- Язык контента — русский.
- Обязательные смысловые блоки на усмотрение дуэлянта, но лендинг должен продавать услуги студии (букеты невесты, оформление церемонии и банкета) и вести к заявке.
- Формат матча: **пробный, 2 раунда** (сокращено с 4 по README для экономии токенов).
