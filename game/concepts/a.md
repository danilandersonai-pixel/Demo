# Концепт A — «ПЕПЕЛ ЛИТАНИЙ» (Ash Litany)

**Рамка:** цифровая настолка-варгейм 1987 года. Клетчатое поле, отряды-миниатюры,
броски d6 с видимыми вероятностями, укрытия, мораль, жестокие потери.
Кампания — цепочка сценариев. Ядро — сам бой; всё остальное обслуживает его.

---

## 1. Лор (оригинальный, без IP GW)

Система умирающей звезды **Веспер-Крон**. Тысячу лет назад звезда начала гаснуть,
и человечество ответило верой: возникла **Держава Негасимой Свечи** — теократия,
которая жжёт в орбитальных кадилах миры-реликвии, чтобы «докормить» светило.
Каждый солдат — «фитиль»: его жизнь заранее отпета, смерть в бою — «догорание во славу».

Из тьмы остывших планет пришёл **Стеклянный Хор** — кремниевый рой-ксенос,
который кристаллизует мёртвых и поёт через них. Хору не нужна победа —
ему нужна тишина: каждый погибший солдат становится резонатором,
каждое поле боя — органом из стекла. Война идёт за **Кадильный Пояс** —
шесть миров, чьи погребальные костры ещё удерживают звезду от смерти.

Тон: свечи, копоть, литании, витражи против звенящего стекла и хрустального
многоголосия. Никакой надежды на «хеппи-энд» — только цена, которую платят.

## 2. Фракции

**Держава Негасимой Свечи** (игрок в кампании). Характер: линейная пехота,
залповый огонь, фанатичная мораль возле знамён и героев, но хрупкие тела.
Эстетика: бронза, воск, чёрные ризы, готические номера полков («33-й Огарочный»).

**Стеклянный Хор** (ИИ; доступен в «Стычке»). Характер: дешёвая масса + элитные
кристаллы, ближний бой, регенерация из трупов, мораль заменена «Резонансом»
(рой не бежит — он рассыпается, теряя связность). Эстетика: аметист, иней, эхо.

## 4. Боевая механика по шагам

Поле: квадратная сетка **9×14** (портрет, без зума). Местность на клетках:
руины (укрытие), воск/грязь (½ движения), костёр (нельзя войти), стекло Хора
(растёт по ходу миссии 6), возвышение (+1 к дальности проверки видимости).

**4.1 Структура хода (IGOUGO, дух 1987):** ход игрока → ход ИИ. Фазы:
Приказы героев → Движение → Стрельба → Рукопашная → Мораль. Активный отряд
выбирается тапом, фазы идут строго по порядку (панель фаз внизу экрана).

**4.2 Движение.** Подсветка достижимых клеток (BFS с ценой местности).
Бег: +Дв/2 клеток, но отряд не стреляет. Выход из контакта — только «отход»
с ударом вдогонку. Отряд занимает одну клетку (абстракция «подставки»).

**4.3 Стрельба.** Дальность оружия в клетках (стрелки 8, миномёт 4–12 навесом,
огнемёт 2, шипомёты 6). Видимость — трассировка по клеткам, руины блокируют
дальше первой. Бросается **Мдл кубов** (каждая модель — куб):
попадание на БС+ → ранение по таблице С vs Т (С>Т: 3+, С=Т: 4+, С<Т: 5+,
С≥2Т: 2+, 2С≤Т: 6) → спас-бросок Бр цели. Провал спаса = минус модель.
**Укрытие:** лёгкое +1 к Бр, руины +2 (макс 2+); огнемёт и навес игнорируют.
Потеря моделей режет число кубов отряда — потери жестоки и видимы.

**4.4 Видимые вероятности.** До подтверждения атаки — карточка:
«6 кубов → попадание 4+ (50%) → ранение 4+ → спас 5+ | ожидание: 1.9 убитых,
шанс сломать мораль: 34%». Считается точно из формул, не симуляцией.
Бросок анимируется «кубами на подносе» (CSS), результаты кликабельны для лога.

**4.5 Рукопашная.** Вход в соседнюю клетку = связывание. Бьют обе стороны:
сначала атакующий (кубы = Мдл, попадание РБ+), выжившие отвечают.
Проигравший (больше потерь) сразу тестирует мораль с −1 Лд.

**4.6 Мораль.** Тест 2d6 ≤ Лд, когда отряд потерял ≥25% моделей за фазу,
либо проиграл рукопашную, либо погиб герой в 3 клетках. Провал:
Держава — **бегство** на Дв к своему краю, отряд «сломлен» (не действует),
в начале своего хода ретест на восстановление (+2 если рядом Свеченосец/герой);
добежал до края — дезертировал навсегда. Хор — **осыпание**: теряет D3 моделей
стеклом на месте, но не бежит. Аура знамени/Камертона: +2 Лд в радиусе 3.

**4.7 Конец боя.** Выполнены условия сценария, либо одна сторона уничтожена/
разбежалась. Уцелевшие отряды Державы переходят в следующую миссию
с текущим составом (пополнение — за очки реквизиции, см. 6).

## 5. Кампания: 6 миссий Кадильного Пояса

1. **«Отпевание Ольты»** (мир-усыпальница). Обучающая оборона: 3 волны Осколков
   на линию баррикад. Условие: знамя не должно пасть.
2. **«Восковые поля»** (мир-свечня). Эскорт Реквием-расчётов через грязь-воск
   (½ движения у всех): дотащить 1 из 2 расчётов до алтаря за 8 ходов.
3. **«Витражный мост»** (шпиль-собор). Бой на узком мосту 3 клетки шириной:
   рукопашная давка, падение с моста при провале морали = гибель отряда.
4. **«Тихий хор»** (захваченный город). Ночь: видимость 4 клетки. Найти и убить
   3 Камертона; каждый живой Камертон каждый ход призывает D3 Осколков.
5. **«Кадило Севера»** (орбитальное кадило). Стекло растёт: каждый ход 2 случайные
   клетки становятся территорией Хора (лечит их юнитов). Удержать кадило 10 ходов.
6. **«Погребение звезды»** (финал). Дуэль армий + Первоголос воскрешает павших.
   Условие: Экзекутор лично должен добить Первоголоса в рукопашной. Эпилог зависит
   от суммы потерь за кампанию (три текстовые концовки — все мрачные, разной цены).

Отдельный режим **«Стычка»**: любая карта, набор армий по очкам, игрок за любую
фракцию против ИИ — закрывает реиграбельность и показывает Хор «изнутри».

## 6. Герои и прокачка между миссиями

Два героя Державы живут всю кампанию. Смерть героя = поражение миссии (рестарт).
За миссию — опыт (цели + убийства). Уровень (макс 4) → выбор 1 из 2 черт:

- Экзекутор: «Неугасимый» (+1 Бр) / «Глас казни» (приказ: отряд стреляет дважды,
  1 р/бой) / «Пламенная епитимья» (сломленные рядом восстанавливаются авто) / …
- Дьякон: «Прицельная проповедь» (+1 к попаданию отряду рядом) / «Освящённый
  порох» (−1 к спасу цели) / «Санитар веры» (1 модель отряда воскресает после боя) / …

Между миссиями — экран **«Реквизиция»**: очки за выполненные цели тратятся на
пополнение моделей в потрёпанных отрядах и покупку новых. Погибший целиком отряд
теряет «полковое имя» и ветеранскую метку (+1 Лд), новый приходит зелёным —
потери больно бьют по силе армии, это осознанная жестокость рамки.

## 7. Экраны и тач-управление (портрет)

Экраны: **Титул** → **Кампания** (вертикальная цепь из 6 свечей-миссий) →
**Брифинг/Реквизиция** → **Бой** → **Итоги миссии**. Плюс «Стычка» и «Летопись» (лог).

Экран боя (одна колонка, без зума, min-target 48px):
- верх (10%): ход/фаза, счёт целей, кнопка меню/лога;
- центр (~68%): поле 9×14, клетка ≈ 40–44px на 390px ширины; поле целиком
  влезает по высоте на типовых телефонах, на коротких — вертикальный скролл
  инерцией (панель фаз всегда прибита снизу);
- низ (22%): карточка выбранного отряда (статы, кубы-иконки по числу моделей)
  и кнопки фазы: «Идти/Бежать», «Стрелять», «В атаку», «Пропустить», «Конец фазы».

Тач-паттерн: тап по отряду → подсветка ходов/целей; тап по цели → модалка
предпросмотра с вероятностями → «Бросить кубы» (крупная кнопка) → анимация
подноса с кубами → результат. Долгий тап по любому юниту — его карточка.
Никаких драгов и жестов двумя пальцами; всё — одиночные тапы. Отмена — тап мимо.

## 8. Архитектура билда

```
game/final/  (или variants/a/)
├── index.html          — все экраны как <section data-screen>, переключение классом
├── css/styles.css      — дизайн-система (тьма/воск/бронза vs аметист), SVG-миниатюры
└── js/
    ├── data.js         — const-каталоги: UNITS, WEAPONS, TRAITS, MISSIONS, MAPS, TEXTS
    ├── rng.js          — mulberry32 с сидом (воспроизводимость, честный лог бросков)
    ├── engine.js       — чистые функции: legalMoves, lineOfSight, resolveShooting,
    │                     resolveMelee, moraleTest, expectedKills (для предпросмотра)
    ├── ai.js           — оценочный ИИ (см. ниже)
    ├── campaign.js     — состояние кампании, XP, реквизиция, концовки
    ├── ui.js           — рендер поля/панелей, обработка тапов, анимации кубов
    └── save.js         — localStorage
```

Юниты и миниатюры — инлайновые SVG-силуэты (свеча-солдат, кристалл и т.п.),
без внешних ассетов. Данные — plain-объекты; состояние боя — один объект
`battle` (grid, units[], turn, phase, log[]), сериализуемый целиком.

**Сохранения** (`localStorage["ash-litany-v1"]`): `{ver, campaign:{mission, roster,
heroes, requisition, chronicle}, battle?|null, settings, rngSeed}` — автосейв
после каждой фазы, поэтому бой переживает закрытие вкладки. Миграция по `ver`.

**ИИ (2 профиля: Хор-агрессор для кампании, Держава-стрелок для стычки):**
для каждого отряда перебор осмысленных действий (топ-N клеток по эвристике),
оценка = ожидание убитых (тот же `expectedKills`, что в предпросмотре — ИИ
и игрок считают одинаково) + вес целей миссии + штраф за выход из укрытия под
залп + бонус фокуса по уже потрёпанным отрядам. Никакого чтения будущих бросков.

## 9. Риски баланса и их гашение

1. **Доминация стрельбы (стоящий залп решает всё).** Гашение: дальность 6–8 клеток
   на поле высотой 14 + руины блокируют трассировку → до контакта 2–3 хода;
   Хор быстрее (Дв 5–6) и получает укрытие от собственного стекла. Тюнинг: авто-
   прогон engine без UI (node) — 200 симуляций стычек, целевой винрейт 45–55%.
2. **Спираль морали (одна неудача → лавина бегства).** Гашение: тест только по
   триггерам (не каждый ход), ретест с +2 у знамени, дезертирство только у края.
3. **Смерть героя = рестарт → фрустрация.** Гашение: у героев лучшие Бр/Т,
   автосейв по фазам, явное предупреждение в предпросмотре «герой под угрозой».
4. **Снежный ком потерь между миссиями.** Гашение: реквизиция масштабируется
   от понесённых потерь (проигравшему больнее, но не смертельно), у миссий есть
   минимальный гарантированный ростер.
5. **Эксплойт ИИ (выманивание по одному).** Гашение: Хор активируется «волнами»
   по связности (группа идёт вместе), у агрессора есть порог «не выхожу из
   укрытия, пока ожидание потерь > ожидания урона».
6. **Читаемость поля 9×14 на телефоне.** Гашение: клетка ≥40px, юнит = крупный
   силуэт + счётчик моделей; проверка на 360×640 как минимальном вьюпорте.

## 10. Почему это «дух 1987»

To-hit → to-wound → save тремя бросками, таблица С/Т, кубы по числу моделей,
знамёна и лидерство, шаблоны-АоЕ, IGOUGO с фазами, потери минусами моделей —
это грамматика ранней настолки, перенесённая в тач без упрощения до «шахмат
с процентами». Цифровое даёт то, чего не было за столом: честные вероятности
до броска, мгновенную математику и лог каждого куба.
