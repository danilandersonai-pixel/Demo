## Известные ограничения

Не баги, а осознанные границы — каждая пояснена в `DECISIONS.md`:

1. **Значка в системном трее нет** — приемлемой зависимости не нашлось
   (решение 41). Выключение, смена проекта и открытие панели живут кнопками
   в самой панели и в меню правой кнопки по папке.
2. **Ярлыки и пункты меню для Windows и macOS собраны и покрыты тестами по
   содержимому, но вживую прокликаны только на Linux** — другой системы под
   рукой не было. В `AUDIT.md` это отдельная таблица.
3. **Экран «Кто сейчас смотрит» вживую с несколькими устройствами не
   проверен**: в контейнере нет сетевого адреса, и экран показывает
   состояние «компьютер не в сети». API отдаёт записи о заходах.
4. **Подписи в графе внимания — 10px** (подписи к диаграмме, рядом «Список»).
5. **Переключатель проектов на телефоне** живёт в списке «⋯».
6. **Ключ доступа не шифрует трафик**: «Доступ с телефона» работает по http.
7. **QR-кодировщик узкий**: байтовый режим, уровень M, версии 1–10.
8. **Статистика правок из транскрипта приблизительная**, когда Claude Code не
   положил `structuredPatch`.
9. **Оценка токенов не равна биллингу** — только суммы из `usage`.
10. **Тепловой след живёт в браузере**: перезагрузка страницы его сбрасывает.
11. **Отдельное окно зависит от наличия Chromium-браузера** — если его нет,
    панель откроется обычной вкладкой.

без React и зависимостей:

- **тела карточек**: команда (`$ …` моноширинно), правка (мини-дифф до

- **живой статус**: «Выполняется…» с пульсом до прихода результата
  (не старше 10 минут), «Не получилось» при ошибке, успех молчит;
- **MCP по-русски**: «Клод обратился к сервису GitHub: list pull requests»;
- **починено по живой проверке**: привязка результатов в снимке (иначе всё
  пульсировало), контраст удалённых строк диффа (два тона коралла),
  двойные числа «примерно vs точно»;
- **провод**: длинные строки в `args` обрезаются (`wire.slimArgs`),
  целое — через `/api/event`.
