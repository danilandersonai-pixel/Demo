# 🧭 Штурман

**Панель-наставник для тех, кто только осваивает Claude Code.**

Вы запустили Claude Code, он что-то делает в терминале — быстро, много и не
всегда понятно. Штурман открывает рядом окно в браузере (или на телефоне) и
простым русским языком рассказывает: что происходит прямо сейчас, какие файлы
в проекте и что только что менялось, что творится в git, и — главное —
**звонит, когда Клод остановился и ждёт вашего ответа**. Можно спокойно уйти
за чаем и лечь с телефоном на диван.

Штурман только смотрит. Он ничего не меняет в вашем проекте, вызывает git
исключительно на чтение и по умолчанию доступен только с вашего компьютера.

## Установка и запуск

**Ни одной команды. Дважды щёлкнуть — два раза за всё время.**

### Шаг 1. Установить (один раз)

Откройте папку Штурмана и дважды щёлкните по файлу:

| Ваша система | Файл |
| --- | --- |
| Windows | **`Установить Штурман.bat`** |
| macOS, Linux | **`Установить Штурман.command`** |

Установщик сам найдёт Node.js, положит на рабочий стол ярлык **«Штурман»** с
иконкой и в конце напишет: «ГОТОВО. Ярлык «Штурман» на рабочем столе».

Заодно он спросит, добавить ли пункт **«Открыть Штурман здесь»** в меню
правой кнопки по папке. Ответ по умолчанию — «нет»; убрать пункт потом можно
переключателем в настройках панели.

> **Нет Node.js?** Установщик не станет ругаться непонятными словами: он
> объяснит, что это за программа, откроет страницу загрузки в браузере и
> спокойно закроется. Скачайте версию с пометкой LTS, поставьте обычным
> способом и щёлкните по установщику ещё раз.

Повторная установка ничего не ломает — она просто обновляет ярлык.

### Шаг 2. Запустить (каждый раз)

Дважды щёлкните по ярлыку **«Штурман»** на рабочем столе.

Через пару секунд откроется браузер с панелью. Никакого чёрного окна с
текстом не появится: на Windows запуск завёрнут в `wscript` (окна нет
вовсе), на macOS ярлык — это обычное приложение, на Linux — `.desktop` с
`Terminal=false`.

Второй клик по ярлыку **не поднимает второй Штурман** — он просто открывает
вкладку с уже работающей панелью.

### Шаг 3. Выбрать проект

Панель сразу показывает карточки папок, в которых недавно работал Клод: имя,
путь, когда была последняя сессия, сколько файлов. Нажмите на нужную.

Путь к папке печатать не нужно **никогда**. Если нужной папки в списке нет —
кнопка «Открыть другую папку» откроет системное окно выбора, а там, где его
нет, панель покажет свой обзор папок.

Галочка «Сразу открывать последний» уводит следующий клик по ярлыку прямо в
панель, минуя выбор.

### Как выключить

Кнопка **«Выключить Штурман»** в настройках панели, с подтверждением.
Искать, как остановить программу, не придётся, и Ctrl+C не нужен.

### Запуск при входе в систему

Переключатель «Запускать при входе в систему» в настройках. По умолчанию
выключен.

## Для тех, кому привычнее терминал

Это запасной путь, не основной. Всё, что ниже, — не обязательно.

```bash
node server.js                    # в текущей папке, порт подберётся сам
node server.js --project ~/проект # за другой папкой
node server.js --pick             # с экраном выбора проекта (так делает ярлык)
node server.js --check            # проверить окружение, если панель пустая
node server.js --help             # все флаги
npm install -g .                  # и потом просто `shturman`
```

Зависимостей нет вообще: ни `npm install`, ни сборки, ни интернета. Нужен
только **Node.js 18 или новее**.

## 📱 Как открыть на телефоне

Главный сценарий: Claude Code работает на компьютере, а вы смотрите с дивана.

**Шаг 1.** В панели на компьютере откройте **«Настройки»** и включите
переключатель **«Доступ с телефона»**. Перезапускать ничего не нужно, в
терминал ходить тоже.

**Шаг 2.** Тут же появится QR-код и ссылка. Наведите на код камеру телефона.

**Шаг 3.** Телефон предложит открыть ссылку — открывайте. Панель откроется
со всеми разделами: лента, карта, git, дневник.

**Шаг 4.** Чтобы Штурман звонил на телефон, нажмите в панели кнопку **🔔**
и разрешите уведомления. Браузеры не дают звучать и слать уведомления, пока
вы явно чего-нибудь не нажмёте.

**Шаг 5 (по желанию).** Меню браузера → «Добавить на главный экран». Штурман
станет обычным приложением с иконкой, без адресной строки.

> **Телефон и компьютер должны быть в одной сети Wi-Fi.** Если телефон в
> мобильном интернете, а компьютер в Wi-Fi — не сработает.

Тот же экран открывается кнопкой **«Открыть на телефоне»** в шапке (на
телефоне — под «⋯»). Там же список запасных адресов, если первый не
открылся, перечень подключённых устройств и кнопка «Сменить ключ».

Выключается тем же переключателем: панель снова становится видна только на
этом компьютере.

### Безопасность общего доступа — что именно защищено

Пока переключатель «Доступ с телефона» выключен — а по умолчанию он
выключен, — Штурман слушает **только** `127.0.0.1`: с других устройств он
недоступен в принципе, никакой ключ не поможет и не нужен.

Когда переключатель включён, панель становится видна в вашей локальной
сети, и тогда:

- при включении создаётся **одноразовый ключ** на 128 бит; он вшит в ссылку
  и в QR-код;
- любой запрос **без ключа получает отказ** — и страницу с объяснением, а не
  молчание;
- с самого компьютера ключ не спрашивается: панель на этом компьютере
  работает как раньше;
- ключ переезжает в куку при первом заходе, чтобы не болтаться в адресной
  строке;
- кнопка «Сбросить ключ доступа» мгновенно обрывает все выданные ссылки;
- Штурман **по-прежнему только читает**: изменить что-то в проекте с телефона
  нельзя, такой возможности в коде просто нет.

Чего ключ **не** делает, и это честно: трафик идёт по обычному http, без
шифрования. В домашней сети этого достаточно — задача ключа не пустить
случайного соседа по Wi-Fi, а не выстоять против целенаправленной атаки.
**В открытой сети — в кафе, аэропорту, коворкинге — «Доступ с телефона»
включать не стоит.**

## Что показывают панели

На компьютере все разделы видны сразу, в три колонки. На телефоне —
по одному, переключаются **нижними вкладками** или свайпом влево-вправо.
Раскладка меняется сама; функции везде одни и те же.

### 📰 Лента «Что происходит»

Каждое действие Клода — отдельной строкой, человеческим языком:

```
🔧 Клод запустил npm test — проверяет, работают ли тесты
📝 Клод изменил engine/game.js (+42 −7)
📖 Клод читает README.md
⛔ Ошибка: команда в терминале не сработала
🙋 Вы написали Клоду
```

- **«Просто / Подробно»** — в подробном режиме под каждой строкой видны сырые
  данные события: какой инструмент, с какими аргументами, что вернулось.
- **Клик по строке** открывает подробности: дифф файла (зелёное — добавлено,
  красное — удалено), вывод команды, сообщения об ошибках. На компьютере это
  панель справа, на телефоне — шторка снизу, которая смахивается пальцем.
- **Пауза** останавливает прокрутку, чтобы успеть прочитать.
- **Фильтры и поиск** — по девяти типам событий и по тексту.

Работу **помощника-субагента** видно отдельно: такие строки подписаны
«Помощник: …», сдвинуты и приглушены, а фильтр «🤝 помощник» показывает
только их.

### 🗺 Карта проекта

Живое дерево файлов. Только что изменённые подсвечиваются, и подсветка плавно
гаснет за полторы минуты — сразу видно, где кипит работа. Клик по файлу
открывает карточку: **что это за файл простыми словами**
(«package.json — паспорт проекта: зависимости и команды»), размер, когда
менялся, последний дифф. Есть поиск по имени.

### 🌿 Git

- Текущая ветка и **что она означает** одной строкой.
- Счётчик несохранённых изменений с объяснением, почему это важно.
- Список изменённых файлов — клик открывает дифф.
- Вкладка «История»: коммиты как линия времени с человеческими подписями.
- Значки **«?»** по всему интерфейсу открывают словарь: 62 термина, каждый
  объяснён в одном-двух предложениях. Термины подсвечены и прямо в ленте:
  пунктирное слово открывает пояснение шторкой, не уводя со страницы.

Если git в проекте нет — Штурман скажет об этом и продолжит работать без него.

### ❤️ Пульс сессии

Сколько файлов затронуто, сколько команд выполнено, сколько ошибок
встретилось, сколько длится работа, приблизительный расход токенов.

Рядом — **«Куда смотрит Клод»**: граф последних файлов. В центре тот, которым
он занят прямо сейчас; линия между двумя файлами означает, что Клод перешёл
от одного к другому подряд. Ниже — журнал прошлых сессий: можно открыть
вчерашнюю работу и разобрать спокойно.

### 🔔 Сигнал «Клод остановился»

Главная функция. Когда в работе Клода наступает тишина дольше 45 секунд
(порог настраивается) и он при этом договорил — Штурман:

1. зажигает картушку — главный прибор наверху: кольцо заливается латунью
   и начинает дышать;
2. подаёт короткий звуковой сигнал;
3. шлёт уведомление браузера — видно, даже если вкладка свёрнута;
4. на телефоне ещё и вибрирует;
5. меняет заголовок вкладки и ставит бейдж на иконку приложения.

Сигнал приходит **один раз** на каждую остановку — он не повторяется, пока
Клод не заработает снова.

### 📄 Итоги дня

Кнопка «📄 Итоги» собирает дневник в markdown: что вы просили, какие файлы
изменились, какие команды выполнялись, что пошло не так, какие новые слова
встретились. Можно скачать файлом, скопировать, а с телефона — отправить
через системное меню «Поделиться».

## Штурман видит сам себя

Это не фигура речи, а способ проверить, что всё работает. Штурман целиком
написан в Claude Code — и по ходу работы он показывал в ленте собственную
сборку: как Клод правит `app.js`, запускает тесты, ловит красный и чинит его.

Проверить у себя: запустите Штурман в любой папке, откройте панель, а в другом
окне терминала попросите Клода что-нибудь сделать в этой же папке. Через пару
секунд его действия начнут появляться в ленте.

## Два уровня работы

На каком уровне работает панель, написано в «Настройках» → «Откуда Штурман
берёт данные».

**Уровень A — «видно всё».** Штурман нашёл транскрипт вашей сессии Claude Code
(`~/.claude/projects/…/*.jsonl`) и читает его в реальном времени.

**Уровень B — «файлы и git».** Транскрипт не найден. Лента показывает
изменения файлов и события git; карта проекта, git-панель, словарь и пульс
работают как обычно.

Диффы есть на обоих уровнях: если файла нет под git, Штурман восстанавливает
построчные изменения из транскрипта и честно подписывает их «по транскрипту».

Уровень выбирается сам и **переключается на лету**. Обычная причина уровня B —
Штурман и Claude Code запущены в разных папках.

## FAQ

**1. Штурман может что-нибудь испортить в моём проекте?**
Нет. Он не создаёт, не меняет и не удаляет файлы в наблюдаемой папке. Все
вызовы git проходят через белый список читающих команд — `commit`, `add`,
`checkout` и прочие пишущие отвергаются самим кодом. Даже собственные
настройки Штурман хранит в вашем домашнем каталоге, а не в папке проекта,
чтобы не оставлять следов в `git status`. Это проверяется отдельными тестами,
в том числе в режиме общего доступа.

**2. Кто-то сможет увидеть мою панель?**
Пока «Доступ с телефона» выключен — никто: сервер слушает только
`127.0.0.1`, с других устройств соединение вообще не устанавливается. С
включённым переключателем панель видна в вашей локальной сети, но только по
ссылке с ключом; всё остальное получает отказ. Подробности — в разделе
«Безопасность общего доступа» выше.

**3. Почему сигнал молчит, хотя Клод явно остановился?**
Три обычные причины. Во-первых, вы ещё не нажали «🔔» — до первого нажатия
браузер не разрешает звук и уведомления. Во-вторых, панель может быть на
уровне B: без транскрипта не по чему определять затишье. В-третьих, порог по
умолчанию 45 секунд. Порог меняется в «Настройках».

**4. Точный ли счётчик токенов?**
Нет, и он честно подписан как приблизительный. Числа берутся из поля `usage`
в транскрипте. С фактическим счётом в вашем тарифе они могут расходиться,
поэтому Штурман не показывает ни денег, ни процентов от лимита.

**5. Панель пустая, в настройках «записи сессии не нашлось». Что делать?**
Не гадайте — откройте **«Настройки» → «Откуда Штурман берёт данные»**: там
написано, какая папка наблюдается, нашёлся ли транскрипт и что мешает. Самая
частая причина — Штурман и `claude` смотрят в разные папки; лечится кнопкой
**«Сменить проект»** в шапке, без терминала. (Кому привычнее консоль — та же
проверка подробнее: `node server.js --check`.)

**6. На телефоне открылась страница «Штурман не запущен».**
Значит, приложение установлено на телефон, а сервер на компьютере выключен —
панель показывает то, что происходит там. Нажмите ярлык «Штурман» на
компьютере и вернитесь: страница проверяет связь сама каждые пять секунд.

**7. Ссылка из QR-кода не открывается на телефоне.**
Проверьте, что телефон в той же сети Wi-Fi, а не в мобильном интернете. Если
сеть та же, попробуйте запасные адреса — они перечислены на экране
«Подключение»: у компьютера может быть несколько сетевых интерфейсов, и
камера могла считать адрес виртуального (Docker, VPN), до которого телефону
не достучаться.

## Флаги командной строки

Ни один из них не нужен для обычной работы: всё это есть в панели кнопками.
Список — для тех, кто запускает Штурман из терминала или из своего скрипта.

| Флаг | Что делает |
| --- | --- |
| `--project <путь>` | папка, за которой следим (по умолчанию — текущая); можно повторять |
| `--pick` | показать экран выбора проекта (так делает ярлык на рабочем столе) |
| `--port <номер>` | порт панели (по умолчанию 4517; занят — возьмётся соседний) |
| `--share` | сразу открыть доступ по локальной сети (то же, что переключатель «Доступ с телефона») |
| `--app` | открыть панель отдельным окном браузера, без адресной строки |
| `--tui` | компактный статус прямо в терминале, без браузера |
| `--install-shortcuts` | положить в папку «Штурман.bat» и «Штурман.command» |
| `--force-new` | поднять ещё одну копию, не мешая уже запущенной |
| `--check` | проверить окружение и выйти |
| `--idle <секунды>` | через сколько тишины считать, что Клод ждёт (45) |
| `--no-open` | не открывать браузер |
| `--ask` | включить кнопку «Спроси Клода» (расходует ваши лимиты) |
| `--debounce <мс>` | склейка событий файловой системы (220) |
| `--poll <мс>` | период пересканирования в резервном режиме (3000) |
| `--tail-only` | читать транскрипт с момента запуска, без истории |
| `--force-poll` | не пользоваться системным наблюдением за файлами |
| `--quiet` | не печатать баннер |
| `--help` | справка |

Настройки запоминаются в `~/.shturman.json`: порт, тема, звук, порог сигнала
и список последних проектов. **Флаг всегда сильнее сохранённой настройки.**

### Необязательно: мгновенный сигнал через хук

Штурман определяет остановку по затишью — это работает без настроек, но с
задержкой. Если хочется сигнал в ту же секунду, добавьте хук **вручную** в
`.claude/settings.json` вашего проекта (сам Штурман туда не пишет):

```json
{
  "hooks": {
    "Stop": [{
      "hooks": [{
        "type": "command",
```

## Дизайн

Панель выглядит так, как выглядит, не случайно. Опорная мысль:
**это приборная панель наблюдателя** — Штурман сидит рядом с пилотом, читает
приборы и спокойно говорит, что происходит. Отсюда всё остальное.

### Принципы

1. **Цвет — это состояние, а не украшение.** Пока Клод работает, панель
   почти бесцветна. Цвет появляется, только когда что-то произошло.
2. **Один принцип разделения — воздух и подложка.** У панелей нет рамок.
   1px-линия осталась ровно в двух местах, где несёт смысл: поле ввода и
   дифф.
3. **Главное — крупно и сверху.** Прищурьтесь: на каждом экране должно
   остаться видно ровно одну вещь.
4. **Никакого КАПСА с разрядкой.** Иерархию делают размер, вес и цвет.
5. **Движение объясняет, а не развлекает.** Один оркестрованный момент —
   запуск приборов; всё остальное короткое и сдержанное. При
   `prefers-reduced-motion` движения нет вовсе, и ни одна функция от этого
   не теряется.

### Палитра — шесть цветов

| Цвет | Роль |
| --- | --- |
| `#0b1417` глубина | фон: тёмное стекло с зеленоватым отливом, не чёрный |
| `#16242a` корпус | подложка прибора |
| `#e7eeee` свет | текст и графика |
| `#e2a44b` **латунь** | **единственный акцент. Означает «нужен ты»** |
| `#5fbfa3` ходовой | идёт работа, всё чисто, добавлено |
| `#f4877c` тревога | ошибка, удалено, связь потеряна |

Светлая тема — не инверсия: там прохладная бумага вместо стекла, а латунь
из светящейся становится гравированной (`#8a5a12`), иначе она не проходит
контраст. Всё остальное получено из этих цветов через `color-mix`; хардкода
цвета вне `public/tokens.css` нет, и это проверяется тестом.

Шрифты только системные — панель работает офлайн. Показания приборов
набраны **старостильными цифрами Georgia**: разновысокие цифры на крупном
кегле читаются как гравированная шкала.

### Фирменный элемент — картушка

Картушка — вращающийся круг магнитного компаса. Пока судно идёт, она живёт;
когда судно встало — замирает. Это ровно семантика главного показания
Штурмана, поэтому она и стала прибором:

| Состояние | Движение | Цвет | Форма |
| --- | --- | --- | --- |
| **Работает** | дуга обходит круг за 3 с | ходовой зелёный | кольцо со светящейся дугой |
| **Ждёт вас** | кольцо дышит, 1,6 с | **латунь** | диск залит, вокруг свечение |
| **Тихо** | нет | приглушённый | пустое тонкое кольцо |
| **Нет связи** | нет | тревога | кольцо пунктиром |

Три независимых канала различения — движение, цвет и форма — дают
прочитать состояние **с трёх метров, боковым зрением и не различая цветов**.

### Где посмотреть

- Живая витрина всех компонентов, состояний и токенов: откройте
  **`/design.html`** на работающей панели.
- Система целиком, с обоснованиями и ревизией на штампы —
  [DESIGN.md](DESIGN.md).
- Что было до редизайна и почему — [DESIGN-AUDIT.md](DESIGN-AUDIT.md).
- Как Штурман разговаривает — [COPY.md](COPY.md).

### Оформление под себя

В «Настройках» есть три готовых сочетания — **Ночь**, **День**, **Фокус** —
и отдельно тема (авто / тёмная / светлая) и плотность
(**Просторно / Компактно**). Компактный режим умножает только воздух: кегли
и зоны касания остаются прежними, а событий на экран влезает примерно на
треть больше.

## Как это устроено

Без зависимостей и без сборки: сервер на стандартной библиотеке Node.js,
клиент — один HTML плюс ванильные JS и CSS. Одна и та же разметка на телефоне
и компьютере, раскладку меняет только CSS.

## Тесты

```bash
npm test          # 336 проверок

# путь новичка целиком, с секундомером (нужен Chromium):
node tests/manual/newbie.js        # установил → кликнул → выбрал → увидел ленту

# ручные проверки интерфейса:
node server.js --port 4517 --quiet --no-open &
node tests/manual/audit-v2.js      # ревизия функций, ожидается 32/32
node tests/manual/design-probe.js  # контраст, кегли, зоны касания, клавиатура
node tests/manual/design-motion.js # движение, reduced-motion, отзывчивость
node tests/manual/design-shots.js  # снимки всех экранов на 1500 и 360
```

Проверяются: разбор JSONL на реальных обезличенных фрагментах транскриптов,
разбор вывода git, перевод на человеческий язык, дебаунс, пути Windows и Unix,
детектор остановки, конфиг, подбор порта, определение адресов в локальной
сети, ключ доступа, генерация QR — а также всё, что появилось ради запуска
кликом: замок одного экземпляра, список проектов из `~/.claude/projects`,
чтение и запись настроек, содержимое ярлыков и пунктов меню для Windows,
macOS и Linux, разбор стоп-сигналов — и сквозные сценарии:
вотчер, git на настоящем репозитории, HTTP, доступ по сети с ключом и без,
и обещание «в наблюдаемом проекте ничего не изменено». Отдельная группа
следит за дизайн-системой: все токены объявлены в обеих темах, в
`components.css` и `styles.css` нет ни одного цвета значением, а в `app.js`
нет ни одной русской строки — вся речь идёт через словарь.
