## Сделано

- Разведка среды; `DECISIONS.md` (Д-1…Д-12).
- `lib/`: debounce, paths, git (парсеры + read-only раннер), transcript
  (поиск каталога, парсер JSONL, tailer), humanize, glossary (31 термин),
  filedoc, tree, sse (буфер 300), pulse (статистика + детектор остановки),
  cli.
- `server.js`: HTTP на 127.0.0.1, маршруты `/`, `/events` (SSE),
  `/api/state|tree|file|diff|commit|git|glossary|sessions|session|pulse`;
  уровень A/B, защита от `../`.
- `public/`: index.html + style.css + app.js — лента (фильтры, поиск, пауза,
  Просто/Подробно, клик → детали), карта с гаснущим «тепловым следом» (60 с),
  git-панель (ветка + смысл, счётчик, таймлайн, упрощённый дифф), пульс,
  словарь с «?»-метками, настройки (звук/уведомления/порог), тур 5 шагов,
  пустые состояния. Скриншот в браузере проверен, консоль чистая.
- Живой тест на себе работает: панель показывает текущую сессию сборки.
- Пульс берёт таймстампы из транскрипта (честная длительность после
  перезапуска), клиент не пищит при загрузке, если Клод уже стоял.
