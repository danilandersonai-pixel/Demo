# Конкурс концепций — рабочий инструмент поверх идей арены

`/contest` — производственный вариант `/arena`: соревнование оставлено там,
где оно приносит пользу (разнообразие концепций и жёсткое сравнение),
и убрано там, где жгло токены впустую (блеф, декларации, приватные планы,
многораундовая война).

## Отличия от арены

| | `/arena` (шоу) | `/contest` (работа) |
|---|---|---|
| Цель агента | обыграть соперника | максимум по критериям заказчика |
| Разнообразие | доктрины поведения | принудительно разные концепт-рамки |
| Информационная игра | блеф, ложные манёвры | запрещена |
| Итог | победитель + разбор драмы | синтез: победитель + трофеи проигравших |
| Доводка | нет | цикл критик → доводчик до «ПРИНЯТО» |
| Критерии | фиксированные фронты | выводятся из брифа, утверждает пользователь |

## Запуск

```
/contest лендинг для студии свадебной флористики, стиль — ботанический люкс
```

Пайплайн: критерии и рамки (с подтверждением пользователя) → 3 параллельных
варианта → вердикт судьи с трофейным списком → синтез в `contest/final/` →
до 2 циклов доводки критиком → сдача.

## Файлы

- `contest/rules.md` — правила и принципы (выводы из эксперимента с ареной)
- `.claude/commands/contest.md` — оркестратор `/contest`
- `.claude/agents/contest-builder.md` — строитель (режимы «вариант» и «доводка»)
- `.claude/agents/contest-judge.md` — судья (режимы «конкурс» и «критик»)
- `.claude/agents/contest-synthesizer.md` — синтезатор финала

Результаты прогона: `contest/brief.md`, `criteria.md`, `verdict.md`,
`variants/a|b|c/`, `final/`.

## Цена

Полный прогон ≈ 3 полноценные сборки + 1–3 вызова судьи + синтез + доводка.
По токенам сопоставимо с ареной на 2 раунда, но весь расход идёт в продукт.
Для экономии можно сократить число вариантов до 2 (правь Ф1 в
`.claude/commands/contest.md`).
