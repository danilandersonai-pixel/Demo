# COPY.md — как Штурман разговаривает

> Этап 3 задания 3. Все слова интерфейса лежат в одном файле —
> `public/copy.js`. В `public/app.js` нет ни одной русской строки, и это
> проверяется тестом. Здесь — правила, по которым эти слова написаны, и
> разбор переписанных мест.

---

## 1. Кому мы говорим

Человеку, который **впервые видит Claude Code** и не обязан знать ни слова
из нашего мира. Он не «пользователь системы», он просто рядом с работающим
инструментом и хочет понимать, что происходит.

Отсюда тон: **спокойный, ровный, на равных**. Не служебный, не
восторженный, не извиняющийся. Так говорит опытный сосед по столу, который
не считает вопрос глупым.

---

## 2. Шесть правил

### 2.1 Говорим о том, что делает человек, а не о том, что делает программа

Настройка называется по своему результату для человека, а не по механизму
внутри.

| Было | Стало | Почему |
| --- | --- | --- |
| Уведомления браузера | **Показывать уведомления** | Человек управляет уведомлениями, а не «настраивает Notification API». Слово «браузера» ничего ему не даёт |
| Звуковой сигнал | **Подавать звук** | Глагол вместо существительного: понятно, что произойдёт |
| Через сколько тишины считать, что Клод ждёт | **Сколько ждать перед сигналом** | Короче и про его выбор, а не про наш алгоритм |
| О наблюдении | **Откуда Штурман берёт данные** | Прямой ответ на вопрос, который человек задаёт |
| Режим ленты | **Лента** | Слово «режим» ничего не добавляет |
| Тема оформления | **Оформление** | То же самое |

### 2.2 Кнопка называет действие и сохраняет имя до конца сценария

Человек нажал «Открыть на телефоне» — и дальше везде видит те же слова.
Никаких «Подключение» на кнопке, «Доступ по сети» в заголовке и «Share-режим
активен» в результате.

| Сценарий | Кнопка | Пока идёт | После |
| --- | --- | --- | --- |
| Телефон | Открыть на телефоне | Открываю… | **Открыто на телефоне** (и заголовок экрана тоже) |
| Ключ | Сменить ключ | Меняю ключ… | Ключ сменили |
| Доступ | Закрыть доступ | Закрываю… | (экран возвращается в состояние «Открыть на телефоне») |
| Итоги | Скачать файлом | — | Скачано |
| Итоги | Скопировать | — | Скопировано |
| Событие | Спросить Клода | Спрашиваю… | Спросили |

### 2.3 Ошибка говорит, что случилось и что делать, и не извиняется

Никаких «Упс», «К сожалению», «Что-то пошло не так». И никакого молчания
вроде «Ошибка 500».

| Было | Стало |
| --- | --- |
| Нужен ключ доступа | **Ссылка без ключа доступа. Отсканируйте QR-код на компьютере ещё раз — он выдаст новую ссылку.** |
| Сервер ответил ошибкой 500 | **Штурман ответил ошибкой 500. Посмотрите окно терминала, где он запущен.** |
| Не удалось прочитать папку проекта. | **Папку не видно.** Штурман не смог прочитать папку проекта. Проверьте, что она на месте и открыта на чтение. → кнопка «Попробовать снова» |
| Дифф получить не удалось. | **Правки не пришли. Откройте файл на карте проекта — там та же картина.** |
| связь потеряна… | **Нет связи.** Окно Штурмана в терминале закрылось или компьютер уснул. |
| Не получилось: `<текст>` | **Не вышло: `<текст>`. Попробуйте ещё раз или перезапустите Штурман.** |

### 2.4 Пустой экран — приглашение, а не сообщение о горе

У каждого пустого экрана есть **причина**, **следующий шаг** и (почти
всегда) **кнопка**. Одинаковых текстов для разных причин не бывает.

| Где | Причина | Заголовок | Кнопка |
| --- | --- | --- | --- |
| Лента | событий ещё не было | Пока тихо | Показать тур |
| Лента | фильтр ничего не выбрал | В этом фильтре пусто | Показать всё |
| Лента | поиск ничего не нашёл | Ничего не нашлось | Очистить поиск |
| Карта | папка не читается | Папку не видно | Попробовать снова |
| Карта | поиск пуст | Такого файла нет | Очистить поиск |
| Карта | в папке нет файлов | Показывать нечего | — |
| Git | git не заведён | Git здесь не заведён | — |
| Git | всё сохранено | Всё сохранено | Открыть историю |
| Git | коммитов нет | История пустая | — |
| Пульс | никуда не смотрел | Пока никуда | — |
| Пульс | прошлых сессий нет | Это первая сессия | — |
| Словарь | слово не нашлось | Такого слова нет | Показать все слова |
| Телефон | компьютер не в сети | Компьютер не в сети | Проверить снова |

До редизайна три первых случая показывали **один и тот же** текст «Пока
тихо. Штурман подключился и ждёт первых действий», и в двух случаях из трёх
это была неправда (см. `DESIGN-AUDIT.md`, место 3).

### 2.5 Один элемент — одна работа

- Кнопка либо **делает**, либо **объясняет**. Пояснение живёт под ней
  отдельной строкой, а не в скобках внутри.
- Заголовок раздела не пытается быть подсказкой: «Git», а не «Git — система
  контроля версий».
- Значок «?» рядом со словом делает ровно одно: открывает статью словаря.
- Картушка показывает состояние. Кнопка «Понятно» отпускает сигнал. Раньше
  оба дела делала одна карточка в углу.

### 2.6 Терминов в интерфейсе нет — они в словаре

Слова `commit`, `stash`, `upstream`, `токен`, `транскрипт`, `хук` не
появляются в тексте без значка «?». Внутри интерфейса используем обычные
слова:

| Термин | Как говорим |
| --- | --- |
| коммит | **сохранение** (в истории проекта) |
| закоммичено | **сохранено** |
| dirty / несохранённые изменения | **правки есть на диске, но не в истории** |
| транскрипт | **запись сессии Клода** |
| токены | **токены** + «?» (объяснить одним словом нечестно) |
| upstream | **origin/ветка**, без слова upstream |
| SSE / поток | **связь** |
| share-режим | **доступ с телефона** |
| субагент | **помощник Клода** |
| cache read | **из памяти** |

## 3. Мелочи, которые заметны

- **Многоточие в процессе**: «Открываю…», «Спрашиваю…», «Собираем итоги…» —
  всегда с настоящим многоточием `…`, не тремя точками.
- **Тире** — длинное `—` с пробелами; в диапазонах — короткое.
- **Кавычки** — «ёлочки». Внутри цитат — „лапки“.
- **Ё** пишем: «ждёт», «затронуто», «нашлось».
- **Числа** не склеиваются с единицей: «45 с», «3 мин 12 с», «9,8 КБ».
- **Склонения по числу** — через `COPY.words`: `коммит / коммита / коммитов`.
  Логика склонения в коде, формы слов в словаре.
- **Точка в конце** ставится в предложениях и не ставится в заголовках,
  подписях приборов и названиях кнопок.
- **Заглавная только первая буква.** Ни одного слова капсом.

## 4. Устройство словаря

`public/copy.js` — один объект `window.COPY`, разбитый по местам интерфейса:

| Группа | Что в ней |
| --- | --- |
| `app` | Имя, заголовок вкладки, заголовок при сигнале |
| `rose` | Слова картушки: четыре состояния и пояснения к ним |
| `tabs` | Короткие имена нижних вкладок (в 90px должно влезать) |
| `head` | Кнопки шапки |
| `feed` | Лента: фильтры, пауза, три пустых экрана |
| `map` | Карта проекта |
| `git` | Git: ветка, история, три пустых экрана |
| `pulse` | Приборы, внимание, прошлые сессии |
| `event` | Карточка события, «Спросить Клода» |
| `file` | Карточка файла |
| `diff` | Правки |
| `glossary` | Словарь новичка |
| `digest` | Итоги сессии |
| `connect` | Телефон, ключ, устройства |
| `settings` | Все настройки |
| `more` | Список под «⋯» |
| `alarm` | Сигнал и его демонстрация |
| `archive` | Просмотр прошлой сессии |
| `tour` | Пять шагов тура |
| `welcome` | Приветствие первого запуска |
| `errors` | Ошибки связи и доступа |
| `common` | Закрыть, назад, загружаем, попробовать снова |
| `units` / `words` | Единицы измерения и формы слов для склонения |

Строки с подстановкой — функции: `C.feed.paused(n)`, `C.git.ahead(a, b, c)`,
`C.settings.idleNote(sec)`. Так подстановка остаётся частью фразы и её видно
целиком при переводе или правке.

### Как это проверяется

`tests/design-tokens.test.js`:

1. **В `app.js` нет русских строковых литералов** — вся речь идёт через
   словарь. Комментарии (они по-русски) из проверки исключаются.
2. **Каждый путь `C.x.y`, встречающийся в коде, существует в словаре** —
   опечатка в ключе не доживёт до браузера.
3. **Каждый `data-copy` в разметке разрешается в строку** — пустых подписей
   на экране не бывает.
4. **В словаре нет неиспользуемых веток** — мёртвые формулировки не копятся.

Исключения, оговорённые сознательно: `<title>` и `<meta description>` в
`index.html`, текст `<noscript>` и страница `offline.html`. Все три должны
работать до того, как выполнится хоть одна строка JavaScript.

## 5. Что переписано целиком

Ниже — места, где изменилась не формулировка, а сам подход.

### Состояние Клода

| Было | Стало |
| --- | --- |
| «Клод работает» (чип 12px) | **Работает** + строка «что именно делает» |
| «ждёт вас · 1 мин 20 с» | **Ждёт вас** + «молчит 1 мин 20 с — можно отвечать» |
| «сессия затихла» | **Тихо** + «Сессия закончилась. Панель продолжает следить за папкой.» |
| «ждём действий» | **Наготове** + «Клод ещё ничего не делал в этой папке.» |
| «нет связи с Штурманом» | **Нет связи** + «Окно Штурмана в терминале закрылось или компьютер уснул.» |

Каждое состояние теперь называется **одним словом** — его видно с трёх
метров — и объясняется второй строкой, которую читают вблизи.

### Уровень наблюдения

Чип «уровень A · видно всё» / «уровень B · файлы и git» из шапки убран.
Буква A или B новичку не говорит ничего. В настройках это стало строкой
«Откуда Штурман берёт данные» с человеческим ответом: «Читает запись сессии
Клода — видно каждое действие» или «Записи сессии не нашлось — видны только
файлы и git».

### Приветствие

Раньше первый запуск сразу начинал тур с шага «Лента „Что происходит“».
Теперь сначала одна спокойная карточка: **«Штурман на месте.** Он смотрит,
что делает Клод, и рассказывает это простыми словами. Ничего в вашем проекте
не меняет — только читает.» — и два честных выхода: «Показать за пять шагов»
и «Разберусь сам».

### Список «Ещё»

Каждый пункт получил пояснение из одной строки: раньше человек видел шесть
названий и угадывал, что за ними. Теперь «Словарь — 43 непонятных слова
простым языком», «Итоги сессии — что просили, что менялось, чем закончилось».
