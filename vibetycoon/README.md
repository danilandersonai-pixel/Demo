# VibeTycoon: AI Automation Simulator

Обучающая игра-песочница про экономику ИИ-агентов. Вы собираете конвейеры из
ИИ-агентов, подбираете модели и промты, пишете автоматизации через
ИИ-ассистента и боретесь с тех-долгом. Цель игры — полностью автономная
система, которая зарабатывает без вашего участия.

**1 секунда = 1 час рабочего времени.** Прогресс, открытые технологии и
рекорды сохраняются в `localStorage`.

## Как запустить

Самый простой способ — открыть готовую сборку `dist/index.html` двойным кликом:
это один автономный файл, ему не нужны ни сервер, ни интернет.

Для разработки:

```bash
cd vibetycoon
npm install
npm run dev        # http://localhost:5173
npm run build      # пересобрать dist/index.html (один файл)
npm run simulate   # прогнать баланс экономики в консоли, без браузера
```

Стек: React 18, Tailwind CSS 4, Framer Motion, Lucide React, Vite
(+ `vite-plugin-singlefile`, чтобы сборка была одним HTML-файлом).

## Чему учит игра

| Механика | Урок |
| --- | --- |
| Длина системного промта | Промт отправляется с **каждой** задачей: длинный промт = меньше задач в час и больше затрат на токены. Слишком короткий — нерелевантные ответы и галлюцинации. Оптимум обычно 600–1500 токенов; кэширование промтов сдвигает его вверх. |
| Температура | Уникальность ответов растёт линейно, а риск ошибок — квадратично (`0.5 + 1.5·T²`). Копирайтеру высокая температура выгодна, поддержке — нет. |
| Выбор модели | Fast LLM не тянет сложные задачи (на код-ревью решает ~15% и выдаёт мусор). Reasoning LLM убыточна на дешёвых тикетах, но окупается там, где ошибка стоит $450. |
| Тех-долг | Каждая фича «на вайбе» добавляет долг: агенты медленнее, токены дороже (до ×1.6), модули приносят меньше, выше 72% падает прод. Лечится рефакторингом (Vibe Clean). |
| Инфраструктура | Каждая модель занимает TFLOPS. При перегрузке все агенты замедляются пропорционально. |

## Модули экрана

1. **Метрики** — баланс, Compute (TFLOPS), токены в секунду, качество
   автоматизации, тех-долг, стабильность, прогноз дохода, график по часам и
   юнит-экономика часа.
2. **Песочница Архитектора ИИ** — агенты с анимированным потоком данных,
   редактор (модель, длина контекста, температура) с прогнозом «было → станет»,
   серверы и API-ключи, дерево технологий.
3. **Модуль Вайбкодинга** — команды автоматизации, режимы «Вайб» и
   «Тщательно», окно «ИИ пишет код…» и кнопка «Рефакторинг ИИ (Vibe Clean)».
4. **Терминал логов и инцидентов** — работа агентов, галлюцинации с советом,
   что подкрутить, перегрузки, падения прода, действия автоматизаций.

Справа от терминала — чек-лист автономии, рекорды и ИИ-наставник.

## Цель и рекорды

Полная автономия засчитывается, когда одновременно:

- построены мониторинг, автопилот температуры, автоскейлер, авто-рефакторинг
  и хотя бы один уровень Guardrails;
- 48 часов без критических галлюцинаций;
- средний чистый доход за 24 часа — не меньше $400/ч;
- 24 часа без ручных действий (смена скорости не считается).

Рекорды — «Максимальный пассивный доход в час» (среднее за 6 ч) и «Самая
стабильная система» (часы без критических галлюцинаций) — хранятся в
`localStorage` и переживают новую партию. При побитии рекорда показывается
неоновый баннер.

Горячие клавиши: **пробел** — пауза, **1 / 2 / 3** — скорость 1×, 2×, 4×.

## Устройство кода

```
src/
├── game/
│   ├── config.js    — все константы баланса: модели, задачи, серверы, технологии, модули
│   ├── engine.js    — чистый движок: tick() = 1 игровой час, действия игрока, прогнозы
│   ├── format.js    — форматирование денег и игрового времени
│   ├── storage.js   — сохранение партии и рекордов в localStorage
│   └── snippets.js  — «сгенерированный код» для окна вайбкодинга
├── components/      — панели интерфейса
└── App.jsx          — игровой цикл, события, сохранение, горячие клавиши
scripts/simulate.mjs — прогон стратегий для проверки баланса
```

Движок не зависит от React: UI и `npm run simulate` используют одни и те же
формулы, поэтому прогноз в редакторе агента совпадает с тем, что реально
происходит в игре.
