# Новый сайт за 15 минут

Переиспользуемый шаблон свадебного сайта-приглашения. Весь контент вынесен в
один файл `config.js`. Без сборки, без npm, без внешних библиотек — чистый
HTML/CSS/JS. Меняете данные → страница рендерится из них автоматически
(`assets/js/render.js`), визуал и анимации трогать не нужно.

---

## 1. Правим `config.js`

Открываете `config.js` и заполняете под свою свадьбу. Разделы:

- **`couple`** — имена (`name1`, `name2`), монограммы (`monogram1`,
  `monogram2`), амперсанд `amp`, хэштег `hashtag`. Из этого собираются имена в
  Hero, монограммы навигации/прелоадера, фавикон, футер.
- **`event`** — `dateISO` (`"YYYY-MM-DD"`), `startTime`/`endTime` (`"HH:MM"`),
  `utcOffset` (смещение часового пояса города от UTC; Москва/СПб = 3), `city`.
  Из этого считаются обратный отсчёт, даты во всех текстах и метки
  календаря (.ics + Google Calendar).
- **`meta`** — `title` (вкладка браузера), `description`, `themeColor`, `lang`.
- **`hero`** — `kicker`, `sub`, `ctaText`, две фоновые фотографии.
- **`countdown`** — `kicker`.
- **`gallery`** — массив из **4** кадров (`image`, `alt`, `roman`, `caption`,
  `tilt`, `parallax`). Раскладка в CSS рассчитана на 4 фото.
- **`story`** — Love Story, массив пунктов (`year`, `title`, `text`, `image`,
  `alt`, `tilt`, `parallax`). Карточки сами чередуются слева/справа.
- **`program`** — тайминг дня (`time`, `datetime`, `title`, `description`).
- **`locations`** — адреса (массив). `address` — **полный
  человекочитаемый адрес** (НЕ url-encoded). Из него render строит карту Яндекса
  и кнопки маршрутов (Яндекс/Google). `zoom` — масштаб карты.
- **`details`** — дресс-код (с палитрой `swatches`), подарки, фото/видео
  (Telegram), фотозона (`booth.images` — 2 фото).
- **`rsvp`** — заголовки, `lead`, `endpoint` (Formspree), все подписи формы в
  `labels`, тексты успеха в `success`. **Имена полей формы не трогать.**
- **`flowers`** — подписка на цветы вместо букетов (`url`, `cta`, `qr`,
  `caption`).
- **`colors`** — палитра. Переопределяет CSS-переменные `:root` через JS.

Тексты могут содержать `&nbsp;` и другие HTML-сущности — они рендерятся как
есть.

---

## 2. Кладём фото и видео

Складываем файлы в `assets/img/` и `assets/video/` с такими именами (или
правим пути в `config.js`):

| Файл                              | Назначение                         |
|-----------------------------------|------------------------------------|
| `assets/img/photo-01.jpg` … `04`  | Hero + галерея + Love Story         |
| `assets/img/booth-01.jpg`, `-02`  | Фотозона (2 кадра)                  |
| `assets/img/dress-code.jpeg`      | Палитра дресс-кода                  |
| `assets/img/qr.jpeg`              | QR подписки на цветы                |
| `assets/img/intro-poster.png`     | Постер интро-видео                  |
| `assets/video/intro.mp4`          | Интро-видео (единственный источник) |

Фавикон генерируется из инициалов автоматически (винный фон + золотая
монограмма). Файл `favicon.svg` остаётся как фолбэк.

---

## 3. Вручную обновить og/twitter и og:url в `index.html`

Соцсети **не исполняют JS**, поэтому карточку шаринга правим руками. В `<head>`
файла `index.html` 6 строк (помечены комментарием
«Правьте вручную под новый сайт»):

- `og:title`, `og:description`, `og:image`, `og:url`
- `twitter:title`, `twitter:description`, `twitter:image`

`og:image`/`twitter:image` — **абсолютный** URL на ваш GitHub Pages
(например `https://<user>.github.io/<repo>/assets/img/photo-01.jpg`).

---

## 4. Публикация

**Вариант А — локально:** просто открыть `index.html` в браузере. Для
корректной работы (видео/шрифты) лучше через локальный сервер:

```bash
cd wedding-template && python3 -m http.server
# → http://localhost:8000
```

**Вариант Б — GitHub Pages:**
1. Создать репозиторий и запушить содержимое папки.
2. Settings → Pages → Source: **GitHub Actions** (либо Deploy from a branch).
3. При необходимости разрешить ветку в окружении `github-pages`.

---

## 5. Чек-лист перед рассылкой

- [ ] Имена, дата, время, город в `config.js` верны.
- [ ] `event.utcOffset` соответствует часовому поясу города (метки календаря).
- [ ] Адреса в `locations` полные — проверить карты и кнопки маршрутов.
- [ ] Все фото на месте (нет «битых» картинок).
- [ ] Ссылки рабочие: Telegram, подписка на цветы, QR.
- [ ] **RSVP endpoint вставлен** в `config.rsvp.endpoint` (иначе форма в
      демо-режиме — ничего не отправляет). Завести форму на
      [Formspree](https://formspree.io), скопировать endpoint.
- [ ] Обновлены og/twitter и `og:url` в `index.html` (п. 3).
- [ ] Проверить обратный отсчёт и «Добавить в календарь» (.ics + Google).
- [ ] При заметных правках стиля/скрипта поднять `?v=N` у `styles.css`/
      `main.js` в `index.html` (кэш-бастинг).

---

## Ограничения

- Галерея настроена на **4 фото** (раскладка CSS завязана на nth-child).
- Для отправки RSVP нужен Formspree endpoint в `config.rsvp.endpoint`.
- Интро-видео — один источник `assets/video/intro.mp4` (+ постер).
- Любая новая анимация обязана быть выключена в
  `@media (prefers-reduced-motion: reduce)` — это требование проекта.
