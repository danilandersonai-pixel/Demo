# Свадебный сайт-приглашение — шаблон

Премиальный **статический** сайт-приглашение на свадьбу. Чистые HTML/CSS/JS —
без сборки, без npm, без внешних библиотек. Весь контент вынесен в один файл
`config.js`, страница рендерится из него (`assets/js/render.js`); вёрстка,
стили и анимации — общие.

## Превью

```bash
cd wedding-template && python3 -m http.server
# → http://localhost:8000
```

Либо просто откройте `index.html` в браузере.

## Как сделать свой сайт

Правьте только `config.js` (имена, дату, тексты, адреса, фото, палитру),
положите свои фото в `assets/img/` и видео в `assets/video/`, обновите
og/twitter-теги в `index.html`.

Полная пошаговая инструкция и чек-лист — в **[TEMPLATE.md](TEMPLATE.md)**
(«Новый сайт за 15 минут»).

## Структура

```
.
├── config.js                 — ЕДИНСТВЕННЫЙ файл с контентом (правят под свадьбу)
├── index.html                — разметка с data-bind / <template>
├── favicon.svg               — фолбэк-фавикон (основной генерится из инициалов)
├── TEMPLATE.md               — гайд «Новый сайт за 15 минут»
└── assets/
    ├── css/styles.css        — дизайн-система, секции, анимации, адаптив
    ├── js/render.js          — рендер контента из config.js (до main.js)
    ├── js/main.js            — клиентская логика (таймер, reveal, форма…)
    ├── img/                  — фото, дресс-код, QR, постер интро
    └── video/                — интро-видео (intro.mp4)
```
