# VibeFoundry — арт-библия

Источник правды по цвету и типографике — дизайн-система `~/vibefoundry-design/tokens.json` (собрана 26.09.2026 пипеткой с тех же трёх референсов). Здесь — что взято из каждого референса и как это превращается в процедурную графику.

## 1. Что взято из референсов

### Изображение 1 — ключевой арт + вайб-кодинг
- Ночная/закатная башня-колония с кольцами и голубыми полосами → **Шпиль Колонии** (финальное мегасооружение): высокая многоярусная башня, светящиеся кольца, антенна.
- Панель вайб-кодинга: чат-пузырь пользователя → ответ ИИ с зелёными галочками → окно `automation.py` с нумерацией строк и подсветкой → плашка «✓ Код сгенерирован ИИ». Повторено 1:1 в `ui/vibe`.
- 5 карточек агентов (Architect/Coder/Debugger/Optimizer/Orchestrator) с цветными тегами ролей — синий, голубой, красный, зелёный, фиолетовый.
- Линия «Развитие ИИ»: терминал → AI Core → дрон → колония — используется в панели агентов и в экранах перехода эр.
- Git для фабрики: `v1.0 Базовая фабрика`, `v1.1 AI оптимизация`, `v1.2 Баг`, `v1.3 Катастрофа` с цветными круглыми иконками (зелёный, зелёный, янтарный, красный) и «← Rollback to v1.1».

### Изображение 2 — стратегическая карта
- Верхняя панель ресурсов: иконка + название (капс-подпись мелко) + значение моно + прирост «+320/мин» зелёным. Энергия: «980 MW / +120 MW».
- Справа сверху: солнце, «День 32 / 14:26», кнопки ⏸ ▶ ⏩ ⏭ и шестерёнка.
- Задачи слева: активная карточка с зелёной рамкой и галочкой, остальные с пустыми кружками.
- Мини-карта с компасом, рамкой видимой области и кнопками «+»/«−».
- Легенда (база, ресурс, месторождение, важная точка, враг, неизвестная область) и переключаемые биомы с плашками-цветами.
- Панель тайла внизу слева (превью, описание, ресурсы «Высокое/Среднее», рекомендация), внизу справа — превью + «X: 1243 Y: 876» + «Построить здесь».
- Нижняя панель инструментов: 8 квадратных кнопок, активная — с голубой заливкой.
- Облака по краям карты, маркеры-ромбы/круги с подписями.

### Изображение 3 — лист ассетов
- 12 зданий, у каждого свой силуэт → см. таблицу §4.
- 5 роботов: белый квадрокоптер (рабочий), серо-белый гуманоид (инженер), тёмный грузовой (логистика), чёрно-красный (боевой), жёлто-чёрный экскаватор-робот (строительный).
- 12 иконок ресурсов: серый слиток железа, медный кристалл, белый кристалл кремния, чёрная капля нефти, голубые кристаллы редкоземов, зелёный кристалл урана, зелёная молния энергии, голубой куб вычислений, синий цилиндр-стек контекста, золотой жетон токенов, голубой куб-голограмма данных, куб-нейросеть весов.
- 6 тайлов-кубиков: луг, лес, горы, озеро, холмы, равнина — «объёмные кубики с краем» → наши тайлы имеют верх-ромб и две боковые грани.
- 4 уведомления: жёлтое (⚠ ошибка в цепочке), синее (новая технология), зелёное (оптимизировано +23 %), красное (нехватка энергии).
- Стиль: постапокалипсис / научная фантастика / индустриальный / техно-эстетика / уютный реализм.

## 3. Типографика

- **Exo 2** 600–700 — логотип, заголовки окон, названия зданий.
- **IBM Plex Sans** 400–600 — весь HUD-текст (кириллица).
- **IBM Plex Mono** 400–600 — числа (tabular-nums), код FactoryScript, метки-капс 11px с трекингом 1.6px.
- Минимальный кегль 12px, без теней у текста. (Промпт предлагал Inter + JetBrains Mono — заменено на шрифты утверждённой дизайн-системы, см. DECISIONS.)

## 4. Процедурные здания (изометрия 2:1, тайл 64×32 px в мире)

Все здания рисуются кодом (Pixi Graphics → RenderTexture) из «коробок» с тремя гранями: верх светлее, левая грань — средняя, правая — тёмная (свет с северо-запада). Металл `#2A3440`, бетон `#5A5F63`, ржавчина `#8C5A34`, стекло `#10394F`. Эмиссивные детали рисуются отдельным слоем «огней» (аддитивно, светятся ночью).

| Здание | Силуэт |
|---|---|
| База (HQ) 5×5 | широкий бетонный цоколь, центральная башня с голубым кольцом и антенной, посадочная площадка дронов |
| Электростанция 3×3 | корпус + две градирни-цилиндра, из которых идёт пар, янтарные окна |

| Аккумуляторная станция 2×2 | ряд цилиндров с зелёными индикаторами заряда |
| Ядерный реактор 5×5 | купол + градирня, зелёное свечение |
| Бур (сборщик ресурсов) 2×2 | тёмная рама, вращающийся бур, жёлтые полосы, пыль |

## 5. Атмосфера

- День: тёплый, слегка золотистый свет; ночь: синее умножение, светятся окна, ленты, кольца.
- Частицы: пар градирен, дым плавилен, искры, пыль буров.
- Вода: мягкое мерцание бликов.
- Облака по краям стратегической карты.
- Цель — «уютный реализм»: картинка живая, а не дебаг-сетка.
