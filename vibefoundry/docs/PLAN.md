## Архитектура (кратко)

```
          +-------------------+        +-------------------+
 input -> |  Game (main loop) | -----> |  Renderer (Pixi)  |  читает состояние,
          |  60 UPS fixed     |        |  интерполяция     |  ничего не пишет
          +---------+---------+        +-------------------+
                    |
                    v
          +-------------------+        +-------------------+
          |  Sim (детерм.)    | <----> | ScriptRuntime     |  FactoryScript,
          |  world / entities |        | (интерпретатор)   |  бюджет операций
          |  belts / power    |        +-------------------+
          |  drones / AI res  |
          +---------+---------+        +-------------------+
                    |                  |  Vibe: intents,   |
                    +----------------> |  agents, Git,     |
                                       |  sandbox (клон)   |
                                       +-------------------+
 UI (Preact, DOM) — подписан на store, перерисовка ~8 Гц, команды шлёт в Game.
```

- Симуляция не знает о Pixi/DOM → её можно клонировать для песочницы и гонять в тестах.
- Все числа — в `src/data/*`.
- Предметы на лентах — в плоских типизированных массивах `BeltStore`.
