# 🕹 Вайб-Кодер: Легенда Продакшена

Мобильная пиксельная RPG про мир вайб-кодинга. Чистые HTML/CSS/JS —
**без сборки, без npm, без зависимостей**. Работает офлайн, сохраняется
в `localStorage`.

## Сюжет

Кодоземье — мир, где программы давно никто не пишет руками: их выращивают
вайбом, промптами и верой в лучшее. На рассвете упал Продакшен — из старого
монолита вырвался **Демон Легаси** (800 000 строк без единого теста) и
окопался в Башне Продакшена.

Ты — **Джун**, начинающий вайб-кодер из деревни Гит-Хилл. Чтобы открыть
ворота башни, нужно собрать три артефакта:

| Артефакт | Где | Как |
|---|---|---|
| 💎 Кристалл Чистого Промпта | Лес Легаси (восток) | принеси Промпт-Ведьме Светящийся Гриб Контекста |
| 🔑 Ключ Мержа | Пещера Конфликтов (север за лесом) | победи босса — Великий Мерж-Конфликт |
| 🎫 Токен Доступа | Болото Дедлайнов (юг) | пройди квиз Духа Стековерфлоу (или переживи его гнев) |

Побочный квест: найти сбежавшего кота Дебаггера для джуна Маши.

## Геймплей

- **5 зон**: деревня Гит-Хилл, Лес Легаси, Пещера Конфликтов, Болото
  Дедлайнов, Башня Продакшена (враги там усилены).
- **Пошаговые бои**: атаки-промпты, скиллы (Рефактор, Дебаг, Вайб-волна,
  Полный рерайт), предметы, кофе-брейк (защита + фокус), побег.
- **Прокачка** до 10 уровня, новые скиллы по уровням.
- **Экономика**: байткоины ₿, магазин у Баристы Гоши (кофе, энергетики,
  пицца, уточка-дебаггер для гарантированного побега).
- **Сохранения**: автосейв при смене зоны + ручное в меню (localStorage).
- **Управление**: на телефоне — экранный D-pad и кнопка A; на десктопе —
  WASD/стрелки, `E`/`Enter` — действие, `Esc` — меню.

## Запуск

```bash
cd vibe-coder-rpg && python3 -m http.server   # → http://localhost:8000
```

Или просто открыть `index.html` в браузере — внешних ресурсов нет.

## Структура

```
vibe-coder-rpg/
├── index.html            — разметка и все UI-оверлеи
├── favicon.svg           — пиксельная иконка
└── assets/
    ├── css/style.css     — стили HUD, диалогов, боевого меню, тач-контролов
    └── js/game.js        — весь движок одним IIFE:
                            тайлы и спрайты рисуются кодом (без картинок),
                            карты — текстовые сетки, диалоги — async/await,
                            бой — пошаговый цикл, звук — WebAudio-чиптюн
```

Проверка синтаксиса перед коммитом:

```bash
node --check vibe-coder-rpg/assets/js/game.js
```
